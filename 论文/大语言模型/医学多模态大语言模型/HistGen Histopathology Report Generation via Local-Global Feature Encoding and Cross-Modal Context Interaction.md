# HistGen: Histopathology Report Generation via Local-Global Feature Encoding and Cross-Modal Context Interaction

## 基本信息

- 中文题目：HistGen：基于局部–全局特征编码与跨模态上下文交互的组织病理报告生成
- 作者：Zhengrui Guo、Jiabo Ma、Yingxue Xu、Yihui Wang、Liansheng Wang、Hao Chen
- 来源：MICCAI 2024
- 任务：输入病理全切片图像（Whole Slide Image，WSI），生成组织病理报告，并考察所学切片表示能否迁移到癌症分型和生存分析。
- 链接：[论文原文](https://papers.miccai.org/miccai-2024/387-Paper0796.html) · [官方代码](https://github.com/dddavid4real/HistGen) · [数据集](https://huggingface.co/datasets/david4real/HistGen)

## 摘要

组织病理学是癌症诊断的金标准，临床报告对于解读和理解这一过程至关重要，并为癌症治疗和患者护理提供指导。利用深度学习自动生成组织病理报告，有望显著提高临床效率，减轻病理医生撰写报告时繁重且耗时的工作负担。为推动这一进展，我们提出了 HistGen，这是一个由多实例学习支持的组织病理报告生成框架，并提供了首个用于评估的基准数据集。受诊断和报告撰写流程的启发，HistGen 包含两个精心设计的模块，旨在从局部和全局两个粒度对齐全切片图像（WSI）与诊断报告，以改善报告生成。为此，我们开发了局部–全局层次编码器，从区域到整张切片的角度高效聚合视觉特征。同时，我们提出跨模态上下文模块，显式促进不同模态之间的对齐与交互，有效弥合全切片图像的长视觉序列与相应高度概括的报告之间的差距。全切片报告生成实验表明，所提出的模型大幅优于最先进的模型。此外，将模型在癌症分型和生存分析任务上微调后，其表现也优于最先进的方法，展现出较强的迁移学习能力。数据集和代码可在此获取。

## 研究背景

组织病理报告把整张切片的观察结果归纳成若干条描述。以肿瘤切片为例，某些图像块能看出细胞形态，判断异常的分布还需比较不同区域。训练数据只提供整张切片及其报告，通常没有标注某句描述对应哪些图像块。

直接对所有图像块计算全局注意力，开销会随图像块数量迅速增加。HistGen 先在区域内汇总信息，再在区域之间交换信息。视觉编码和报告解码还会读取同一组可学习的上下文向量，使两个模态能在报告生成目标下共同训练。

### 任务定义与视觉特征提取

一张全切片是一个多实例学习的包，组织图像块是其中的实例。输入为图像块序列 $I=(x_1,\ldots,x_n)$，输出为报告词元序列 $Y=(y_1,\ldots,y_T)$。这里用整份配对报告监督生成，无需为每个图像块提供标签。

作者先用 CLAM 分割组织、裁出图像块，再为每块提取一个 1,024 维视觉向量。特征提取器是 ViT-L，用 DINOv2 的自监督方法在超过 55,000 张公开 WSI 的约 2 亿个图像块上预训练。该阶段只用图像学习形态特征，图文配对用于后续报告模型的训练。

图像块向量先由跨模态上下文模块（CMC）补充，再由局部与全局层次编码器（LGH）压缩成区域向量序列。报告前缀也经过同一个 CMC，最后由解码器读取区域向量来预测下一个词元。

### 局部–全局层次编码器（LGH）

LGH 先在小范围内建模，再比较不同区域，最后将比较结果送回局部。实验将区域大小设为 96，即一次区域内注意力处理一组图像块和相应的区域词元。

1. **区域内汇总。** 将图像块序列分组，给每个区域加入位置编码和一个可学习的区域 token。区域内 Transformer 对这一组 token 做自注意力。局部编码后的区域 token $r_i$ 汇总第 $i$ 个区域的信息。
2. **全切片交互。** 从各区域取出 $r_1,\ldots,r_N$，加上区域位置编码，再用 WSI 级 Transformer 计算更新后的区域 token $\tilde r_1,\ldots,\tilde r_N$。全局注意力在区域之间计算，序列长度由图像块数缩短为区域数。
3. **全局信息回到局部。** 将 $\tilde r_i$ 放回第 $i$ 个区域，再进行一次区域内编码，让局部图像块读取更新后的区域 token。随后用注意力池化压缩该区域，得到一个区域向量 $h_i$。

用 $X_i'$ 表示首次局部编码后的区域内图像块特征，上述过程可以概括为

$$
(\tilde r_1,\ldots,\tilde r_N)=E_{\mathrm{global}}(r_1,\ldots,r_N),
\qquad
h_i=\operatorname{AttnPool}\!\left(E_{\mathrm{local}}([X_i';\tilde r_i])\right).
$$

生成报告时，解码器通过交叉注意力读取完整的**区域向量序列** $(h_1,\ldots,h_N)$。做癌症分型和生存分析时，再将区域向量池化为一个切片级表示，供下游预测头使用。

### 跨模态上下文模块（CMC）

CMC 的记忆矩阵由模型学习。官方实现默认包含 2,048 个 512 维向量。可将一次读取理解为：输入一个视觉向量或文本嵌入，计算它与记忆条目的匹配程度，再把选中的条目加权汇总。两边查询的内容不同，读取的是同一个矩阵，条目没有预先定义为某种病理概念。

1. **视觉侧先抽样查询。** 按 MICCAI 正式版和公开实现，沿图像块序列均匀选取一批位置，将对应特征作为查询。每个查询经多头注意力在记忆中挑出得分最高的一组条目，用加权求和得到读出向量。公开训练入口的记忆检索参数默认是每个注意力头保留前 32 项。
2. **将查询结果回填视觉序列。** 原始图像块特征再通过注意力读取这批读出向量，把结果残差加回原序列，然后进入 LGH。抽样减少的是直接查询记忆的次数，原图像块序列继续参与视觉编码。
3. **文本侧逐 token 查询。** 报告前缀的每个 token 嵌入都直接查询同一个记忆矩阵，读出的上下文残差加回文本嵌入，随后进入解码器。

以 $\mathcal R(q,C)$ 表示用查询 $q$ 从共享记忆 $C$ 中读出向量，官方实现的两条增强路径可写为

$$
P=\mathcal R(\operatorname{UniformSample}(X),C),
\qquad
X'=X+\operatorname{Attn}(X,P,P),
\qquad
E'=E+\mathcal R(E,C).
$$

其中 $X$ 是投影后的视觉序列，$P$ 是视觉侧从记忆读出的上下文，$E$ 是报告前缀的嵌入。推理时 CMC 的矩阵参数固定，不同输入会取出不同上下文。R2Gen 的关系记忆则是一份随当前报告前缀逐步更新的状态。

### 训练与推理

解码器由 **3 层 Transformer** 组成，使用 **8 个注意力头**、**512 维隐藏状态**。生成第 $t$ 个 token 时，掩码自注意力读取报告前缀，图文交叉注意力读取编码后的区域向量。训练时输入真实前缀，以交叉熵最大化配对报告的条件概率。

$$
\mathcal L=-\sum_{t=1}^{T}\log p_\theta(y_t\mid I,y_{<t}).
$$

推理时，从起始 token 开始逐步生成，以已经生成的 token 作为下一步前缀。论文使用 **束宽为 3 的 Beam Search**。

## 实验

### 数据集与评价指标

- 报告生成：从 TCGA 诊断报告 PDF 提取原始文本，用 GPT-4 清洗和摘要，再按病例 ID 匹配 WSI。正式论文报告 **7,753 组 WSI–报告配对**。报告质量使用 BLEU-1 至 BLEU-4、METEOR 和 ROUGE-L 评价。
- 数据版本：论文实验章节给出的训练、验证、测试比例为 **80% / 10% / 10%**。官方代码仓库后续说明，重新清洗并发布的报告标注使用 **70% / 10% / 20%**。引用结果和复现实验时应区分这两套口径。
- 下游任务：癌症分型使用 UBC-OCEAN、Camelyon、TUPAC16 三个外部数据集，以准确率和 AUC 评价。生存分析使用 BRCA、STAD、KIRC、KIRP、LUAD、COADREAD 六个 TCGA 队列，以 C-index 评价。

### 报告生成结果

作者比较了 ResNet-50、CTransPath 和病理预训练 DINOv2 ViT-L 三种视觉特征提取器。以普通 Transformer 为例，三种特征对应的 BLEU-4 分别为 **0.042、0.082、0.157**。下表固定使用论文预训练的 DINOv2 ViT-L，比较后续报告生成架构。

| 方法 | BLEU-1 | BLEU-4 | METEOR | ROUGE-L |
| --- | ---: | ---: | ---: | ---: |
| R2Gen | 0.274 | 0.071 | 0.102 | 0.234 |
| Transformer | 0.382 | 0.157 | 0.162 | 0.316 |
| R2GenCMN | 0.381 | 0.157 | 0.164 | 0.313 |
| HistGen | **0.413** | **0.184** | **0.182** | **0.344** |

在相同视觉特征下，HistGen 相比普通 Transformer 的 BLEU-4 提高 **0.027**，ROUGE-L 提高 **0.028**。

### 模块消融

| 配置 | BLEU-4 | METEOR | ROUGE-L |
| --- | ---: | ---: | ---: |
| 基础 Transformer + 池化 | 0.163 | 0.166 | 0.316 |
| 基础模型 + CMC | 0.173 | 0.173 | 0.332 |
| 基础模型 + CMC + LGH | **0.184** | **0.182** | **0.344** |

基础模型的 BLEU-4 为 0.163，加入 CMC 后为 0.173；保留 CMC 再加入 LGH 后为 0.184。实验未报告仅使用 LGH 的配置，因此第二步的增益只说明 LGH 在已有 CMC 时的作用。

### 迁移结果与评价边界

癌症分型时，HistGen 在三个外部数据集上的平均准确率和 AUC 分别为 0.827、0.915，表现最好的对比基线 ABMIL 为 0.809、0.913。六个生存分析队列的平均 C-index 为 0.628，对比方法中的最高平均值为 0.618。这个差距出现在跨队列均值上，单个队列仍有其他方法领先。

报告生成结果衡量生成文本与参考报告的匹配程度；癌症分型和生存分析则检验切片表示的迁移表现。两类结果不能回答同一个问题。要判断报告是否漏报病灶、分级是否正确，或某句描述能否对应到图像位置，需要分别设计评价。
