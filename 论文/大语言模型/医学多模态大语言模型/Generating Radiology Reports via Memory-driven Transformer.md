# Generating Radiology Reports via Memory-driven Transformer

## 基本信息

- 中文题目：基于记忆驱动 Transformer 的放射学报告生成
- 作者：Zhihong Chen、Yan Song、Tsung-Hui Chang、Xiang Wan
- 来源：EMNLP 2020
- 模型：R2Gen
- 任务：根据胸部 X 光图像生成自由文本放射学报告。
- 链接：[论文原文](https://aclanthology.org/2020.emnlp-main.112/) · [开源代码](https://github.com/cuhksz-nlp/R2Gen)

## 摘要

医学影像常用于临床实践和临床试验中的诊断与治疗。撰写影像报告耗时，经验不足的放射科医生在撰写时也容易出错。因此，自动生成放射学报告的需求十分迫切，它可以减轻放射科医生的工作负担，从而推动临床自动化，也是人工智能应用于医学领域的一项重要任务。

本文提出使用记忆驱动的 Transformer 生成放射学报告，其中设计了关系记忆来记录生成过程中的关键信息，并使用记忆驱动的条件层归一化将记忆融入 Transformer 的解码器。

在两个常用的放射学报告数据集 IU X-Ray 和 MIMIC-CXR 上的实验结果表明，我们提出的方法在语言生成指标和临床评估两方面均优于以往模型。特别是，据我们所知，这是首项报告 MIMIC-CXR 上的生成结果的研究。进一步分析还表明，我们的方法能够生成包含必要医学术语的长篇报告，并形成有意义的图像与文本注意力映射。

## 研究背景

胸片报告通常要分别描述肺野、胸膜和心纵隔轮廓，并注明某些异常是否存在。以“无胸腔积液，也未见气胸”为例，模型既要从胸片中获取证据，也要知道报告已经描述过哪些发现。R2Gen 研究能否在解码器中维护一份随文本更新的记忆，以便生成后续词元时继续使用前文。

视觉端由 CNN 和 Transformer 编码器构成。论文比较的改动位于解码器：用关系记忆汇总报告前缀，再将记忆用于调整每个解码子层的归一化参数。

## 主要方法

### 任务定义与总体框架

<img src="Z:\Public\images\image-20261109203914638.png" alt="image-20261109203914638" style="zoom:50%;" />

输入是一张或多张胸部 X 光图像，输出是一份报告。ResNet-101 先提取空间特征图，再把各位置的 2,048 维特征排列成序列 $X=(x_1,\ldots,x_S)$。视觉 Transformer 用自注意力交换不同位置的信息，输出 $H=(h_1,\ldots,h_S)$。这组视觉向量在生成过程中固定，作为解码器交叉注意力的键和值。

将报告记为 $Y=(y_1,\ldots,y_T)$。在生成 $y_t$ 前，掩码自注意力读取前缀 $y_{<t}$，交叉注意力读取胸片特征。此时关系记忆 $M_t$ 已用上一词元更新，可以通过层归一化影响当前的解码表示。一份报告从初始记忆开始生成，记忆随前缀递推。

### 关系记忆（RM）

关系记忆用固定大小的矩阵 $M_t$ 汇总已处理的报告前缀。默认配置有 3 个记忆槽，每槽 512 维，注意力使用 8 个头。槽位没有预设的医学含义。以生成“无胸腔积液”为例，模型每处理一个新的词元，都可以更新槽内的表示，并将更新后的状态用于预测后续内容。

令 $e_{t-1}$ 表示上一词元的嵌入。每个注意力头以旧记忆为查询，以旧记忆和 $e_{t-1}$ 的拼接作为键和值的来源：

$$
\begin{aligned}
Q &= M_{t-1}W_Q,\\
K &= [M_{t-1};e_{t-1}]W_K,\\
V &= [M_{t-1};e_{t-1}]W_V.
\end{aligned}
$$

默认配置下，每个头包含 **3 个查询位置和 4 个键值位置**。每个记忆槽都能读取三个旧槽和刚进入的 token，因此这一步同时处理槽之间的关系和新信息。多头注意力的输出经残差连接及前馈网络处理后，得到候选记忆 $\widetilde M_t$。

得到候选记忆后，模型再决定各维保留多少旧值、写入多少新值。遗忘门和输入门均由旧记忆及上一词元嵌入计算，分别控制公式中的两项。

$$
M_t
= \sigma(G_t^{f})\odot M_{t-1}
+ \sigma(G_t^{i})\odot \tanh(\widetilde M_t)
$$

其中 $G_t^{f}$ 和 $G_t^{i}$ 是两个门的未激活值，$\sigma$ 为 Sigmoid，$\odot$ 为逐元素乘法。更新后的 $M_t$ 一方面用于当前步的解码，另一方面传给下一步继续更新。由此，较早的 token 可以通过记忆状态影响后续生成，记忆矩阵大小也固定为 $3\times512$。

### 记忆驱动的条件层归一化（MCLN）

标准 LayerNorm 将隐藏向量标准化，再用固定参数 $\gamma$ 和 $\beta$ 逐维缩放和平移。R2Gen 让这一变换随报告前缀变化：把 $M_t$ 的各行拼成 $m_t$，用两个独立的 MLP 分别计算缩放增量和偏移增量。

$$
\begin{aligned}
\widehat\gamma_t &= \gamma + \operatorname{MLP}_{\gamma}(m_t),\\
\widehat\beta_t &= \beta + \operatorname{MLP}_{\beta}(m_t),\\
\operatorname{MCLN}(r_t,M_t) &= \widehat\gamma_t\odot\operatorname{Normalize}(r_t)+\widehat\beta_t.
\end{aligned}
$$

这里的 $r_t$ 是送入该归一化层的隐藏向量，$\operatorname{Normalize}$ 表示按该向量自身的均值和标准差进行标准化。模型权重在推理时固定，随生成步变化的是 MLP 根据记忆算出的增量。

每层解码器在三个位置使用 MCLN，分别对应三个子层。

| 位置 | 当前记忆如何参与后续计算 |
| --- | --- |
| 掩码自注意力之后 | 调整报告前缀的隐藏表示。该表示随后作为图文交叉注意力的查询，因此记忆可以影响模型从胸片的哪些位置读取信息。 |
| 图文交叉注意力之后 | 调整已经融合图像信息的隐藏表示，再送入前馈网络。 |
| 前馈网络之后 | 调整当前层的输出，供下一解码层继续处理。最后一层的表示用于预测下一 token。 |

消融实验中的 **BASE + RM** 则保留标准解码层，在预测下一 token 前将记忆直接拼接到 Transformer 输出。完整模型将记忆作用的位置提前到各解码子层，因此也能在读取图像特征之前调整查询表示。

### 训练与推理

训练时，将真实报告的 token 序列右移后送入解码器，每个位置使用真实前缀预测当前位置的 token。模型最小化所有目标 token 的负对数似然，即交叉熵损失。

$$
\mathcal L=-\sum_{t=1}^{T}\log p_{\theta}(y_t\mid I,y_{<t})
$$

视觉提取器从 ImageNet 权重初始化，Transformer 随机初始化。论文采用 Adam，视觉提取器的初始学习率为 $5\times10^{-5}$，其余参数为 $10^{-4}$，每轮乘以 0.8。

推理时，模型从起始 token 出发，用已生成的前缀递推更新记忆。论文使用 **束宽为 3 的 Beam Search**，每一步保留累计得分最高的 3 条候选序列。候选前缀不同，对应的记忆状态也随之不同。

## 实验

### 数据集与指标

- IU X-Ray：公开胸片报告数据集，共 7,470 张图像、3,955 份报告。论文按 7:1:2 划分训练、验证和测试集，实验以同一患者的两张胸片作为输入。
- MIMIC-CXR：规模更大的胸片报告数据集。实验采用官方数据划分，论文表 1 报告测试集包含 3,269 份报告。
- 文本指标：BLEU-1 至 BLEU-4、METEOR、ROUGE-L，用于比较生成报告和参考报告的文本匹配程度。
- 临床标签指标：在 MIMIC-CXR 上，用 CheXpert 从报告中抽取标签，比较生成报告与参考报告在 14 类胸部病变及支持装置标签上的一致性，报告精确率、召回率和 F1。

### 消融实验

论文比较了基础 Transformer、在输出端直接拼接 RM 的模型，以及通过 MCLN 将 RM 接入解码器内部的完整模型。下表摘录原文表 2 的五次运行平均结果。

| 指标 | 基础 Transformer | RM 拼接到输出端 | RM + MCLN |
| --- | ---: | ---: | ---: |
| IU X-Ray · BLEU-1 | 0.396 | 0.444 | **0.470** |
| IU X-Ray · BLEU-4 | 0.135 | 0.141 | **0.165** |
| IU X-Ray · ROUGE-L | 0.342 | 0.364 | **0.371** |
| MIMIC-CXR · BLEU-4 | 0.090 | 0.095 | **0.103** |
| MIMIC-CXR · ROUGE-L | 0.265 | 0.265 | **0.277** |
| MIMIC-CXR · 临床标签 F1 | 0.228 | 0.249 | **0.276** |

直接拼接 RM 已经提高了多项得分，接入 MCLN 后提升更明显。以 MIMIC-CXR 为例，完整模型相较基础模型的临床标签精确率从 0.331 变为 0.333，召回率从 0.224 提高到 0.273。这组结果的变化主要体现在召回率。

### 结果解读

两种记忆接入方式使用相同的关系记忆模块。只在输出端拼接记忆时，它参与下一词元预测；用 MCLN 时，记忆还可在读取图像前调整交叉注意力的查询。表中结果支持后者在这两组数据上的接入方式。

CheXpert F1 衡量报告中的标签是否匹配。即使病变类别相同，也可能在位置、范围和程度上出现错误，这些差异需要更细的评估。R2Gen 后来被用作 HistGenVLM 相关研究的对照模型；胸片输入与全切片输入的规模不同，HistGen 还需在解码前汇总大量局部组织图像块。
