# VIST-GPT: Ushering in the Era of Visual Storytelling with LLMs?

## 基本信息

- VIST-GPT：大语言模型引领视觉叙事时代？
- Arxiv

## 摘要

视觉叙事是一个跨学科领域，结合了计算机视觉与自然语言处理，旨在从图像序列中生成连贯的叙事。本文提出了一种新颖的方法，利用多模态模型的最新进展，特别是对基于 Transformer 的架构和大规模多模态模型进行适配，以完成视觉叙事任务。借助大规模视觉叙事（VIST）数据集，我们的 VIST-GPT 模型能够生成具有视觉依据且上下文恰当的叙事内容。我们指出传统评估指标（如 BLEU、METEOR、ROUGE 和 CIDEr）在此任务中的局限性，并转而采用 RoViST 和 GROOVIST 这两种新型无参考指标，专门用于评估视觉叙事在视觉依据性、连贯性和非冗余性方面的表现。这些指标能更细致地评价叙事质量，与人类判断高度一致。

## 研究背景

- 传统**图像描述**（image captioning）多针对单张图，只回答“画面里有什么”，很难表达故事性、人物情绪和事件发展。
- **视觉讲故事**（Visual Storytelling，VIST）要求模型对一串相关图片生成连贯、自然、有人情味的故事：既要与图像内容对齐，又要在多句之间保持情节连贯、避免重复。现有方法在视觉对齐、连贯性和评测指标上都有不足。

## 主要方法

### 结构

#### 双视觉编码器：

- 使用图像编码器（CLIP ViT-L/14）提取每张图片的空间视觉特征；
- 使用视频编码器（InternVideo2）把 5 张图当成 5 帧“视频”来处理，建模图像序列中的时间与上下文关系；
- 两路特征共同为后续故事生成提供更丰富的视觉语义信息。

#### 视觉-语言（V-L）适配器：

- 用若干 MLP 层将视觉编码器输出的特征映射到语言模型的嵌入空间；
- 充当“接口”，保证大语言模型可以把这些视觉特征当作自己的输入 token 来处理，而不用改动视觉编码器结构。

#### Token 池化：

- 对大量视觉 token 进行池化压缩（如平均/注意力池化），减少 token 数量以适配 LLM 的上下文长度限制；
- 同时尽量保留对整体场景和关键物体的关键信息，平衡“信息量”和“计算成本”。

#### 大语言模型：

- 采用轻量级指令微调模型 **Phi-3-mini-4k-instruct** 作为文本生成核心；
- 冻结视觉编码器和适配器，仅对 LLM 做 LoRA 微调，使其学会利用视觉信息写出连贯故事；
- 在推理时配合不同的解码设置（温度、beam 数等），得到两个版本：
    - **VIST-GPT v1**：设置偏向多样性，故事更有创意；
    - **VIST-GPT v2**：设置偏向稳定和结构清晰，每张图对应一句话、整体更规整。

### 训练策略

- 使用 **VIST 数据集**：每个样本包含 5 张图片及对应的 5 句人类故事文本，作为监督信号。
- 训练目标为标准的**自回归语言建模**（下一个 token 预测），给定视觉特征和前文文本，让模型生成整段故事。
- 训练时：
    - 将 5 张图经过双视觉编码器和 V-L 适配器，得到一串视觉 token；
    - 视觉 token 与文本 prompt、故事文本拼接在一起输入 LLM；
    - 通过 LoRA 对 LLM 权重进行微调，其余模块冻结，降低训练成本并提高稳定性。
- 推理阶段通过精心设计的 **prompt**（例如明确要求生成 5 句、每句对应一张图）约束生成格式，同时调整温度、top-k、beam size 等超参数，平衡**创造性**与**可靠性/对齐度**。
