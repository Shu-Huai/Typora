# 大模型与向量数据协同：进展与展望

## 向量数据管理

### 度量空间下支枢点的统一向量表征

#### 研究动机

- 多模态数据类型多样，需要借助统一的表征模型以刻画不同数据的结构特征
- 利用基于三角不等式的剪枝策略，可以避免大量的距离计算开销，从而提高索引和查询的性能
- 度量空间下支枢点统一映射还面临支枢点选择策略复杂和距离计算开销大的问题

#### 技术贡献

- 提出一种基于幂律分布的支枢点选择算法
- 综述了现有通用度量空间上的支枢点选择算法，并在不同实际应用场景下对其进行性能测试，以探索最优的支枢点选取策略
- 将支枢点映射后空间的距离分布可视化

### 基于 NVMe 固态硬盘的导航图向量索引

研究动机：传统的导航图索引多基于内存环境，但随着数据规模的扩大，转向存储硬盘面临着性能不匹配的问题。尤其是在 NVMe 固态硬盘上，存在存储局部性差和磁盘 I/O 特性不匹配的问题，导致检索效率较低。

展示了如何在磁盘上布局数据并优化索引的查询策略，解决磁盘局部性带来的性能问题。

### 基于 GPU 的向量检索加速优化

研究动机：GPU 的硬件加速方法可以大幅度提升向量检索性能，尤其在大规模数据面临内存死锁问题时，GPU 能有效缓解内存瓶颈。

## 向量数据库赋能 LLM 推理

- 提出了基于多向量表示、重要性挖掘、图索引和联合查询的多模态查询框架
