# 操作系统中的进程有哪几种状态？

## 回答重点

进程状态可以用去银行办业务来理解：排队等叫号、正在柜台办理、去旁边补材料。对应操作系统就是**就绪、运行、阻塞**，但完整生命周期通常包含 5 到 7 种状态。

基础五种状态：

- **新建态**：进程刚创建，操作系统正在分配 PID 和 PCB。
- **就绪态**：已经具备运行条件，等待 CPU 调度。
- **运行态**：正在占用 CPU 执行指令。单核 CPU 同时只能运行一个进程，多核可以并行运行多个。
- **阻塞态**：等待 I/O、信号量、锁或其他事件，事件完成前即使 CPU 空闲也不能继续执行。
- **终止态**：进程正常执行完毕或异常退出，资源被回收。

状态转换流程：

1. 新建态初始化完成后进入就绪态。
2. 就绪态被 CPU 调度后进入运行态。
3. 运行态时间片用完或被抢占后回到就绪态。
4. 运行态等待 I/O 或事件时进入阻塞态。
5. 阻塞态等待的事件完成后回到就绪态。
6. 运行态执行完毕或异常退出后进入终止态。

## 扩展知识

### 状态转换的触发条件

- **就绪 → 运行**：CPU 调度器选中进程，将其从就绪队列取出执行。Linux 默认使用 CFS 调度器，按虚拟运行时间进行调度。
- **运行 → 就绪**：时间片耗尽，或更高优先级进程到达并抢占 CPU。
- **运行 → 阻塞**：进程主动等待 I/O、信号量或锁，例如 `read` 系统调用等待磁盘数据。
- **阻塞 → 就绪**：等待的事件完成，例如磁盘数据读完、收到信号或锁释放。解除阻塞后要先进入就绪队列，不会直接运行。

### 僵尸进程和孤儿进程

**僵尸进程**：子进程已经终止，但父进程还没有调用 `wait` 读取退出码。此时子进程的 PCB 和 PID 仍被占用，`top` 或 `ps` 中状态为 `Z`。僵尸进程不消耗 CPU 和内存，但过多会耗尽 PID。可以让父进程正确处理 `SIGCHLD`，或终止父进程后由 init 进程回收。

**孤儿进程**：父进程先退出，子进程仍在运行。操作系统会将其托管给 PID 为 1 的 init 进程，子进程终止后由 init 自动回收资源。孤儿进程本身通常没有危害。

## 面试官追问

#### 提问：进程从阻塞态能直接变成运行态吗？

回答：不能，必须先回到就绪态排队。等待事件完成后，操作系统只是把进程放回就绪队列，什么时候真正获得 CPU 由调度器决定。

#### 提问：怎么查看 Linux 系统里进程的状态？

回答：使用 `ps` 或 `top`。`ps aux` 的 `STAT` 列中，`R` 是运行态，`S` 是可中断睡眠，`D` 是不可中断睡眠（通常等待磁盘 I/O），`Z` 是僵尸，`T` 是停止态。`top` 可以实时查看状态变化。

#### 提问：什么是不可中断睡眠，跟普通阻塞有什么区别？

回答：不可中断睡眠是 `D` 状态，进程通常在等待不能被打断的磁盘 I/O，收到信号甚至 `kill -9` 也不能立即唤醒，只能等 I/O 完成。普通阻塞通常是 `S` 状态，可以被信号唤醒。大量 `D` 状态进程通常意味着磁盘或 I/O 负载存在问题。
