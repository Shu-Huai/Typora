# 什么是物理地址，什么是逻辑地址？

## 回答重点

**物理地址**是内存条上真实存在的位置，CPU 最终通过它访问内存芯片。

**逻辑地址**是程序运行时看到、由 CPU 生成的地址，程序员和编译器使用的都是逻辑地址。操作系统通过页表把逻辑地址映射到物理地址，程序无需知道数据实际存放位置。

每个进程拥有独立逻辑地址空间，因此不同进程的 `0x1000` 可以映射到不同物理地址，实现内存隔离。

地址转换流程：

1. 程序访问逻辑地址，例如 `0x000A1234`。
2. CPU 将地址交给 MMU。
3. MMU 查页表得到物理页框号，拼接页内偏移得到物理地址。
4. CPU 根据物理地址访问内存。

## 扩展知识

### 为什么需要两套地址

早期程序直接使用物理地址，必须知道加载位置，程序之间容易冲突，一个错误地址还可能覆盖操作系统内存。逻辑地址让每个程序都像从 0 地址开始、独占完整内存，操作系统在后台将不同进程的逻辑地址映射到不同物理区域。

### 地址转换的核心组件

**MMU** 是 CPU 中负责地址转换的硬件，接收逻辑地址、查询页表并输出物理地址。

**页表**由操作系统维护，记录逻辑页号到物理页框号的映射。每个进程有自己的页表，进程切换时，操作系统把新页表基地址写入 CPU 的 `CR3` 寄存器。

### 分段和分页

分段按代码段、数据段、栈段等逻辑功能划分，段大小不固定，逻辑地址由段号和段内偏移组成，容易产生外部碎片。

分页把逻辑地址空间和物理内存切成固定大小的页和页框，通常每页 4KB，逻辑页可以映射到任意物理页框，内存管理更灵活。Linux 和 Windows 主要使用分页。现代 x86-64 虽保留分段形式，但段基址通常设为 0、段限长设为最大，实际主要依赖分页。

### 逻辑地址的好处

1. 程序可以加载到物理内存任意位置，不需要修改代码。
2. 进程之间隔离，野指针通常只能导致当前进程异常。
3. 支持虚拟内存，物理内存不足时可将页面换到磁盘，逻辑地址空间可以大于物理内存。

## 面试官追问

#### 提问：TLB 是什么，为什么需要它？

回答：TLB 是 CPU 内部的页表高速缓存。若每次地址转换都访问内存页表，一次数据访问可能变成两次内存访问；TLB 命中时可以直接得到物理地址，避免查页表，现代 CPU 命中率通常很高。

#### 提问：多级页表为什么比一级页表节省内存？

回答：一级页表很大，32 位系统 4KB 页大小时单个进程的页表约 4MB。多级页表把页表本身也分页，只为实际使用的地址范围分配下级页表，能显著减少占用；64 位系统通常使用四级页表。

#### 提问：用户态程序能直接访问物理地址吗？

回答：正常不能，用户态地址都要经过 MMU 和页表翻译，未映射地址会触发异常。Linux 的 `/dev/mem` 可让 root 程序直接访问物理内存，主要用于硬件调试或驱动开发，生产环境通常会禁用，避免安全风险。
