# 什么是限流？有哪些常见的限流算法？ - 面试鸭 | 2026最新面试题+详细答案解析

限流是指在一段时间内限制系统处理请求的数量，用于防止流量过大导致系统过载或崩溃。常见的限流算法有以下 4 种：

1. **固定窗口限流**：将时间固定分割成不同的时间段，每个时间段限制流量。这个方法实现简单，但缺点是限流时段固定，容易在临界处出现突发流量。

   例如，1 秒内限流 5 次：如果第一秒的 1.5～2.0 秒放行了 5 个请求，而第二秒的 2.0～2.5 秒又放行了 5 个请求，那么在 1.5～2.5 秒这一秒内实际放行了 10 个请求，远大于限流 5 次的标准。

2. **滑动窗口限流**：为了解决固定窗口限流的缺点，滑动窗口不使用固定时间段，而是从第一个请求开始计时，并在后续时间段内进行限流；超过该时间段后清零，等待下一个请求重新开始计算限流时段。

3. **令牌桶限流**：和进程通信中的 `Semaphore` 信号量类似，维护 N 个令牌，让多个进程或线程争抢令牌。抢到令牌的请求可以放行；未抢到的请求需要等待其他进程释放令牌，且有空闲令牌后再争抢。令牌数量可自定义。

4. **漏斗限流**：以恒定的速率放行请求。当请求到达时，漏斗按固定速率放行；如果堆积的请求超过漏斗容量，则后续请求会被拒绝。这种方式处理过程平滑，但无法很好地处理突发流量。
