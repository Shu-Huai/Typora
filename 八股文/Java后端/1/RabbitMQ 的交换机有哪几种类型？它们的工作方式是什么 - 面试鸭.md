# RabbitMQ 的交换机有哪几种类型？它们的工作方式是什么？ - 面试鸭 | 2026最新RabbitMQ 面试题+详细答案解析

## 回答重点

RabbitMQ 的交换机主要有四种类型：Direct、Fanout、Topic、Headers。

1）Direct 交换机会根据消息的路由键（routing key）精确匹配绑定键（binding key），只有完全匹配的消息才会被转发到对应的队列。
2）Fanout 交换机会将接收到的每一条消息广播到所有绑定到它的队列，而不考虑路由键。
3）Topic 交换机会根据消息的路由键和绑定键的模式匹配（支持通配符）来决定消息的流转路径。`*` 可以匹配一个单词，`#` 可以匹配零个或多个单词。
4）Headers 交换机根据消息的头部属性（headers）来路由，而不是基于路由键。这种交换机提供更加复杂和灵活的路由策略。

## 扩展知识

RabbitMQ 是一个流行的消息队列系统，可以帮助实现异步通信和任务解耦。它的四种交换机类型各有特点，适合不同的场景。

1）Direct 交换机：
适合需要精确匹配的场景。比如日志系统，它可以根据不同的日志级别（INFO、DEBUG、ERROR）将日志消息路由到不同的队列进行处理。

2）Fanout 交换机：
适合广播消息，比如社交媒体的消息推送，同一条消息需要发送给所有关注者。它的缺点是无法根据消息内容进行有选择的路由，所有绑定的队列都会接收到消息。

3）Topic 交换机：
非常灵活，适合需要根据特定模式进行消息路由的场景。比如，订单系统中，匹配用户所在地区和订单类型的队列进行处理。`quick.orange.rabbit` 可以匹配 `quick.*.rabbit` 或 `*.orange.*` 这样的模式。

4）Headers 交换机：
最复杂也最强大，可以根据消息头部的多个属性进行路由。适合需要更复杂路由逻辑的场景。比如不同部门处理的邮件系统，可以根据邮件的多个头部信息结合判断，路由到不同的处理队列。
