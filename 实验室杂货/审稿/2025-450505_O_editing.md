# 2025-450505_O_editing

这篇论文提出了一种融合特征菌与机器学习的分段 PMI 推断模型。研究基于“破溃点”理论，通过对108只裸鼠在18个时间点的肠道菌群进行高时间分辨率测序与分析，并以此为基础建立分段建模策略。相较传统整体建模，分段模型在R²、MAE等指标上均表现出更优性能。该研究为微生物法医学在死亡时间推断中的应用提供了新的建模思路与技术路径。有以下建议修改的问题。

1. $\beta$ 多样性分析中，图上显示，0-103H 和 113-240H 的数据有一定程度上的重叠，并不能很好地将其区分开。作者也并未在文中分析这一点。
2. 1.3 和 1.4 小节的标题为“测序数据分析”以及“随机森林分析”，但这两节的主要内容实际上是对于使用方法的描述，也不涉及实验数据和实验结果的分析。
3. 在摘要中，作者提到其基于随机森林构建的分类算法，准确率高达 100%。但在正文中没有对于这个指标的详细分析。同时，100% 准确率在实践中略显异常，可考虑引入混淆矩阵、ROC 曲线等进一步展示分类模型的可靠性，避免过拟合的质疑。
4. “裸鼠肠道菌群死后不同时间点相对丰度”图的标号有误。
5. 2.3 节中，对于“分段回归模型”的构建方法的描述有些模糊，建议修改。
6. 为了更好地体现本文的创新性，建议补充相关研究综述，并突出本研究与前人工作的区别与创新点。
