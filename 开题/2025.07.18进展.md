# 2025.07.18 进展

## 研究主题

#### 医学图像数据增强

对应我们的问题，拆解为三层结构：

1. **图片级**：在每张图片的 patch 中使用 MIL 提取特征
2. **组级**：对应一个文本 embedding 有多个图片，对这些图片做跨图 MIL，输出为一个**组特征表示**。
3. **Mixup 增强**：对**组特征表示**进行 Mixup，合成新的组表示；而标签 $y$ 为两个文本 embedding 的线性组合或使用**双侧 Mixup 策略**

#### 主动学习框架的引入

对于多模态大语言模型的图文对齐，将文本 embedding 视为确定不变的，训练图像特征提取器和特征空间对齐。

此时，可以计算每个样本与已知文本 embedding 的最近邻余弦相似度，相似度越低，越不确定，越需要人工标注。

或者可以使用 MC Dropout，计算 embedding 的方差，作为不确定度指标

#### MixUp-MIL: Novel Data Augmentation for Multiple Instance Learning and a Study on Thyroid Cancer Diagnosis

- 主题：在 MIL 框架中引入 Mixup 策略，用于提升在甲状腺癌组织切片图像分类中的表现
- 代码：[https://gitlab.com/mgadermayr/mixupmil](https://gitlab.com/mgadermayr/mixupmil)
- 数据集：[https://gitlab.com/mgadermayr/mixupmil/-/tree/main/datasets?ref_type=heads](https://gitlab.com/mgadermayr/mixupmil/-/tree/main/datasets?ref_type=heads)

#### Pseudo‑Bag Mixup Augmentation for MIL‑Based WSI Classification

- 主题：基于伪 bag 划分的 Pseudo-bag Mixup 数据增强方法
- 代码：[https://github.com/liupei101/PseMix](https://github.com/liupei101/PseMix)
- 数据集：TCGA

#### MDAL: Modality-difference-based active learning for multimodal medical image analysis

- 将 LLM 用作示例选择器，在无需初始标注数据的情况下选择高价值训练样本
- 代码：[https://github.com/PEASEC/ActiveLLM](https://github.com/PEASEC/ActiveLLM)
- 数据集：AG-News（Hugging Face）、SST-2（Hugging Face）等
