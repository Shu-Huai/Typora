# 2026.04.08 组会进展

## 多模态大模型算法研究和实验进展

### 总体算法流程计划

1. 构建 patch level 的图像特征提取器
2. 构建 slide level 的图像特征提取器
3. 图像特征接入 LLM，构建多模态死因推断 LLM

### patch level 特征提取器

- 使用知识蒸馏
- 将通用医学图像上预训练的 UNI2 模型（ViT Giant）中的知识，在心脏数据上训练，蒸馏到更小规模模型上，以进行专有领域迁移，并降低计算资源开销。
- 目前测试的有 ViT-Small、ViT-Base、ViT-Large、ResNet18、ResNet50、Resnet34。
- 使用**特征蒸馏**，即：优化UNI2（教师模型）和小模型在输出特征上的相似度和MSE。
- 我们采用的任务是：在 patch level 的尺度上，训练分类任务，判断该 patch 所属类别（红细胞、脂肪细胞、心肌、背景、基质、血管），以让特征提取器学到更多细节结构信息
- 起初是在 3 分类任务上进行的，但由于任务简单，各个实验方案之间拉不开差距（准确率都在 0.97-0.99），因此在 6 分类上进行
- 每个类别大约 3000 个样本，总数大约在 16000

### slide level 特征提取器

```mermaid
flowchart LR
    A[slide] --> B[切成 patch]
    B --> C[利用上一步的特征提取器提特征]
    C --> D[聚合成 slide level 特征]
    D --> E[分类]
```

- 在此基础上，进一步做了 slide level 特征提取器
- 流程是：slide -> 切成 patch -> 利用上一步的特征提取器提特征 -> 聚合成 slide level 特征 -> 分类
- 使用 CLAM 作为聚合模型
- 尝试了多种 CLAM 的参数，选取其中相对最好的一组作为对比实验的固定参数
- 分类任务
  1. 该切片是**心脏病致死**还是**非心脏病致死**（非心脏病致死也可能有心脏病）——每个类别 50 个样本，总 100
  2. 该切片**有心脏病**还是**没有心脏病**——正例 36、负例 25
- 5 折交叉验证
- 4个 patch level 提取器：ViT-Small、ViT-Base、ResNet18、Resnet34
- 3 种 patch level 提取器的训练方式
  1. 先知识蒸馏，后冻住骨干网络，仅训练分类头，对应表中 **kd**
  2. 先知识蒸馏，后同时训练骨干网和分类头，对应表中 **joint**
  3. 先知识蒸馏，后冻住分类头，仅训练骨干网络，对应表中 **cls**
