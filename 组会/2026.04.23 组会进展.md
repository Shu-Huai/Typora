# 2026.04.23 组会进展

## 干了什么

- 将切片数据分为左心室和右心室
- 分别对两部分数据做 CLAM 训练和测试
- 由于左右心室在病理切片中的形态、在病变中的反映程度不同，因此模型的表现也不同

## 结果

| 部位       | 模型         | 提取器       | ACC        | AUC        |
| ---------- | ------------ | ------------ | ---------- | ---------- |
| 左心室     | CLAM         | ViT-Base     | 0.7837     | 0.8246     |
| 右心室     | CLAM         | ViT-Base     | 0.7284     | 0.7819     |
| 左心室     | CLAM         | ResNet34     | 0.7315     | 0.7672     |
| 右心室     | CLAM         | ResNet34     | 0.6889     | 0.7834     |
| **左心室** | **TransMIL** | **ViT-Base** | **0.8061** | **0.8328** |
| 右心室     | TransMIL     | ViT-Base     | 0.7453     | 0.8177     |
| 左心室     | TransMIL     | ResNet34     | 0.7224     | 0.7591     |
| 右心室     | TransMIL     | ResNet34     | 0.7068     | 0.7645     |

- 左心室整体上比右心室更适合作为心源性死亡判别的病理切片来源
- TransMIL 整体优于 CLAM，尤其在左心室上优势最明显。
- ViT-Base 提取器明显优于 ResNet34，提取器选择对性能影响很大
