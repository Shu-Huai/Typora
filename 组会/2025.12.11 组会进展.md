# 2025.12.11 组会进展

## 目标

从 WSI 图像数据 + 诊断本文数据，生成诊断文本

## 数据

- 纯文本数据：1300 条
- 图文对数据：14 条，每条若干个图像，共计 171 张图片

## 技术路线

### 总体

<img src="http://public.file.lvshuhuai.cn/images\7b4bbc13-329e-4eb6-acb2-52b7634ff8eb.png" alt="7b4bbc13-329e-4eb6-acb2-52b7634ff8eb" style="zoom:33%;" />

### 文本大模型

使用 PEFT 参数高效微调技术（LoRA、Prefix Tuning、Prompt Tuning），在纯文本数据上训练 Qwen 文本模型

### 图文对齐

参考 CLIP 的对比学习方式，采用双塔架构，将图像与文本在特征空间对齐

<img src="http://public.file.lvshuhuai.cn/images\569df6a7-2c27-49be-92fb-419813837211.png" alt="569df6a7-2c27-49be-92fb-419813837211" style="zoom:33%;" />

将图像切分为小 patch，使用 ResNet 作为初始特征提取器，用 CLAM 的无监督部分

三种对齐方案：

1. 方案 A 将数据以**切片**的粒度进行组织，将切片与文本直接对齐——数据量大
2. 方案 B 将数据以**案例**的粒度进行组织，将同一案例所有图像 patch 合成为一个，同时做了随机降采样
3. 方案 C 将数据以**案例**的粒度进行组织，将同一案例所有图像经过 CLAM 后，使用 Transformer 融合

### 检索式生成

- 受 SongCi 启发，能够将图像特征编码与简短的病理诊断特征编码计算相似度
- 通过遍历比较该图像与每个已知诊断的相似度能够实现图像到文本的可靠输出
- 图像 → `z_img_proj` → 在一堆已知诊断文本向量里做最近邻搜索 → 选相似度最高的那几段文本当“结果”
- 近似多分类问题
- 输出 Top $K$ 个结果

<img src="http://public.file.lvshuhuai.cn/images\908900fe-d84f-45a0-8010-3c9e021d0641.png" alt="908900fe-d84f-45a0-8010-3c9e021d0641" style="zoom: 25%;" />

### 因果大模型生成

- LLaVa 的技术路线
- 把图像向量映射成若干“前缀 token”，接到 Qwen 的输入里，**微调 Qwen 作为图像条件生成模型**。
- 图像 → 若干“视觉 token embedding” → 作为 Qwen 的前缀 token → 拼接指令 → 生成
- `[视觉信息] + "请根据上述病例的病理图像，简要描述主要异常与诊断结论。"`

## 实验数据

### 文本侧微调

- 24GB 显存
- 中文数据
- **Qwen 2.5-7B 在 1300 条数据上 LoRA 微调效果最佳**

| 基座模型        | 数据量（条） | 方法          | 平均相似度分数 | BERTScore F1 |
| --------------- | ------------ | ------------- | -------------- | ------------ |
| Qwen 2.5-7B     | < 200        | prompt 工程   | 0.8027         | 0.7935       |
| Qwen 2.5-7B     | < 200        | lora          | 0.6722         | 0.6511       |
| **Qwen 2.5-7B** | **≈ 1300**   | **lora**      | **0.8696**     | **0.8844**   |
| Qwen 2.5-7B     | ≈ 1300       | prompt tuning | 0.7801         | 0.7352       |
| Qwen 2.5-7B     | ≈ 1300       | prefix tuning | 0.7592         | 0.7487       |

| Qwen 2.5-VL     | < 200        | prompt 工程   | 0.7516         | 0.7564       |

### 检索式生成

- 由于样本数太少，如果划分为 80/20 的数据集测试，测试集样本只有 3 个，难以形成科学的实验结果
- 这里选择在长文本（器官检验描述）上训练，在短文本（诊断结果）上推理
- 另外，样本数少的情况下，R@5 和 R@10 也不太有意义
- R@1: 64.28%
