## NewsStories: Illustrating Articles  with Visual Summaries

- 现有的视觉-语言模型（如 CLIP）大多假设 **“一张图 ↔ 一条短 caption”** 且是强字面对应，这在新闻、百科、博客等真实场景里并不成立——一篇长文往往配多张图、甚至视频，图和文之间只是“示意/象征性”对应。
- 提出了一项新的任务——从文本到多图的检索，以证明模型的多模态理解能力
- 和我的任务高度相关

### NewsStories 数据集

- 数据模态：NewsStories 同时包含**新闻文章（含标题、日期等元数据）、图片和新闻视频及音频**三种模态。
- 时间范围：从 2018 年 10 月到 2021 年 5 月，基于 CommonCrawl 等来源抓取新闻网页及其媒体链接。
- 先对文章做文档表示学习，对特定时间窗内的文章进行层次聚类，将内容相似的文章聚成初始故事簇；
- 再基于命名实体进行二次聚类：用 SpaCy 抽取实体，并通过命名实体感知的文本编码器获得实体向量，对同一簇内所有实体向量做平均，得到“故事簇向量”，再对这些向量做聚类合并可能共享图片的故事簇。
- 最终，每个故事簇包含：若干相关文章 + 这些文章中出现的所有图片（以及视频链接，用于后续扩展）。

- 媒体源过滤：作者只保留来自**一个独立机构评估的 46 家主流媒体**的文章和链接（如 BBC、CNN、Fox News 等），显著降低噪声并提高文本、图片质量。
- 请人工对故事簇的质量做**文章相关性**、**图文相关性**、**评估的正确性**做打分

### 用视觉摘要为文章配图

作者将任务形式化为：**在给定若干候选“图像集合”的前提下，为一篇文章检索出最相关、最能“视觉总结”其内容的一组图片**，即“文章 → 图像集合检索”。

<img src="http://public.file.lvshuhuai.cn/images\image-20251203132011899.png" alt="image-20251203132011899" style="zoom:50%;" />

- 设一个故事包含相关文章集合 $A$ 与图片集合 $I$（大小为 $|I| = N_I$），目标是让每篇文章 $L \in A$ 与其整个图片集合 $I$ 的语义相似度最大。文本编码器 $f_{\theta_L}$ 将文章或句子编码为向量集合 $x$，图像编码器 $g_{\theta_I}$ 将每张图编码为向量 $y_i$。
- 检索时，模型需要输出一个“汇聚后的图像集合表示”，既能体现集合内部各图之间的互补关系，又要与文本表示对齐。

#### 现有对齐目标

作者首先复现并扩展了几类已有的图文对齐目标，用于文章↔多图任务：

- **单图-文本 InfoNCE 对比学习（CLIP 风格）**
  - 假设一对 {图像 $y$、文本 $x$} 为正样本，其它图或文为负样本；
  - 损失是标准的 InfoNCE：让正样本相似度最大，负样本最小；在多图场景下，先计算文本与集合中每张图的相似度，再取平均作为“文章-集合”相似度。
- **MIL-NCE（多示例对比学习）**
  - 将一组图视为一个 “bag”，对一个文本 $x$ 与图集合 $\{y_i\}$ 的相似度通过对所有图相似度做 softmax/求和来近似最大值；
  - 直观上是对齐“文章 ↔ 集合中最代表故事的那张图”，但没有细粒度句子层面对齐。
- **PCME 软对比（概率嵌入）**
  - 把每个图像/文本建模成一个概率分布，采样多次得到一组嵌入，计算图-文匹配为“所有采样对的平均匹配概率”；
  - 再用 soft 对比损失优化，使真实匹配对的概率高、非匹配对概率低。
- **图像集合聚合方式**
  - **Mean pooling**：直接对集合中所有图像向量取平均，作为集合表示；
  - **Transformer 聚合**：把多张图的特征送入图像 Transformer，让自注意力在图片之间建模上下文，再用 [CLS] 或平均得到集合向量。实验表明，相比只看单图，对图片集合做这种聚合可以显著提升检索性能，但 Transformer 相比简单平均只提升约 1%。

#### 多示例学习——句子到图像（MIL-SIM）

为更细粒度地对齐“文章中的不同语义片段 ↔ 集合中的不同图片”，作者提出 **MIL-SIM（Multiple Instance Learning – Sentence to Image）**：

- **核心假设**：集合中的每一张图片，至少应该与文章中的某一句话语义对应；因此应该在**句子级**建立对齐，而不仅仅是“全文 ↔ 单图”。
- **句子编码与伪标签生成**：
  - 先用 NLTK 把文章切成句子并编码为句向量集合 $L = \{x_1, \dots, x_{N_L}\}$；
  - 对于正样本图像集合 $I = \{I_1,\dots, I_{N_I}\}$ 中的每张图片 $y_i$，计算它与所有句子 $x_l$ 的相似度，取最大值 $\max_l x_l^\top y_i$ 作为“该图 ↔ 该文章中最相关句子”的得分，并用 InfoNCE 对这对图-句进行对比学习；
  - 在负样本构造时，从其他故事簇中挑选与该图最高相似度的句子作为难负例，并整体降低图-句损失权重，以减轻误对齐噪声。
- 仅靠图-句对齐容易被噪声图片干扰，因此再引入 **文章级 InfoNCE 损失**：
  - 对于一篇文章，将所有句向量平均得到文章向量 $L_f$；
  - 对于一个图像集合，将所有图向量平均得到集合向量 $I_f$；
  - 用 InfoNCE 约束 $I_f$ 与 $L_f$ 相似度最大化，保证整组图整体与文章语义吻合。

#### 最终损失

$$
\mathcal{L}_{\text{MIL-SIM}} = \sum_{b=1}^{B} \text{InfoNCE}(I_f^{(b)}, L_f^{(b)})\;+\; \lambda \sum_{b=1}^{B} \sum_{i=1}^{N_I} \text{InfoNCE}(I_{b,i}, L_b)
$$

其中第一项是 **文章↔图像集合级别** 对齐，第二项是 **单图↔整篇文章（通过其最相关句子）** 的细粒度对齐，$\lambda$ 控制二者权重。

def article_level_info_nce(image_bag_emb: torch.Tensor,
                           article_emb: torch.Tensor,
                           tau: float = 0.07) -> torch.Tensor:
    """
    文章级 InfoNCE:
    """
    B, D = image_bag_emb.shape
    image_bag_emb = F.normalize(image_bag_emb, dim=-1)
    article_emb = F.normalize(article_emb, dim=-1)

    logits = (image_bag_emb @ article_emb.t()) / tau  # [B, B]
    labels = torch.arange(B, device=image_bag_emb.device)
    loss = F.cross_entropy(logits, labels)
    return loss

def mil_sim_loss(img_emb: torch.Tensor,
                 sent_emb: torch.Tensor,
                 sent_mask: torch.Tensor,
                 lambda_img_sent: float = 0.1,
                 tau: float = 0.07) -> Dict[str, torch.Tensor]:
    B, N_I, D = img_emb.shape

    # ===== 文章级聚合 =====
    # 文章向量 L_f：对有效句子 mean
    sent_mask_f = sent_mask.unsqueeze(-1)  # [B, N_L, 1]
    sent_sum = (sent_emb * sent_mask_f).sum(dim=1)     # [B, D]
    sent_count = sent_mask_f.sum(dim=1).clamp(min=1.0) # [B, 1]
    article_emb = sent_sum / sent_count                # [B, D]

    # 图像集合向量 I_f：对所有图 mean（论文就是简单 mean pooling）
    image_bag_emb = img_emb.mean(dim=1)                # [B, D]

    loss_article = article_level_info_nce(image_bag_emb, article_emb, tau=tau)
    loss_img_sent = mil_sim_image_sentence_loss(img_emb, sent_emb, sent_mask, tau=tau)
    total_loss = loss_article + lambda_img_sent * loss_img_sent

    return {
        "loss": total_loss,
        "loss_article": loss_article.detach(),
        "loss_img_sent": loss_img_sent.detach()
    }
