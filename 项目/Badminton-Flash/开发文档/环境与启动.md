# 环境与启动

本文说明新开发者如何从零把前后端跑起来，包括环境要求、依赖启动顺序、常见启动错误。

本文不讨论配置项含义，见 [[开发文档/配置说明|配置说明]]。不讨论生产部署，见 [[开发文档/构建发布与压测|构建发布与压测]]。

源码范围：后端 `pom.xml`、`src/main/resources/application*.yml.example`；前端 `package.json`、`vite.config.ts`、`.env.development*`。

## 环境要求

| 组件 | 版本要求 | 说明 |
|---|---|---|
| JDK | 23 | pom 里 `maven.compiler.release=23` |
| Maven | 3.9+ | |
| MySQL | 8+ | 驱动 9.4.0 |
| Redis | 6+ | 默认用 database 2 |
| RabbitMQ | 3.12+ | virtual-host 用默认 `/` |
| Node.js | 20+ | 前端 |
| npm | 10+ | 前端 |

## 依赖启动顺序与后端启动

顺序：MySQL（3306）→ Redis（6379，database 2 无需预建）→ RabbitMQ（5672）→ 后端（25001）→ 前端（10096）。

后端启动时 `spring.sql.init.mode=always` 自动执行 `schema.sql`（建表）和 `data.sql`（初始化 config 表 + root 管理员）。数据库 `badminton_flash` 由连接串 `createDatabaseIfNotExist=true` 自动创建，无需手工建库。

```bash
# 仓库根目录
cp src/main/resources/application.yml.example src/main/resources/application.yml
cp src/main/resources/application-dev.yml.example src/main/resources/application-dev.yml
# 修改两个文件里的数据源、Redis、RabbitMQ、token.privateKey、jasypt.encryptor.password
mvn spring-boot:run
```

启动成功标志：`/doc.html` 打开 Knife4j 接口文档。真实配置文件被 .gitignore 排除，每个开发者本地自己维护一份。

## 前端启动与本地联调

```bash
npm install
npm run dev
```

开发模式走 Vite 代理，`/auth`、`/user`、`/browse`、`/reserve`、`/pay`、`/admin` 转发到 `VITE_DEV_PROXY_TARGET`（默认 http://localhost:25001）。

注意 `.env.development` 里写的是 `http://lvshuhuai.cn:25001`，指向远程后端。本地联调时要改成 localhost 或者确认远程服务可用。

联调步骤：

1. 用 `POST /auth/register` 注册一个学生账号，或直接用 root 管理员（密码见 [[开发文档/配置说明|配置说明]] 里 data.sql 的说明）
2. 管理员登录后，在管理面板建一个场次，或者用 `POST /admin/session` 手工创建
3. 用 `POST /admin/warmup/{sessionId}` + `POST /admin/open/{sessionId}` 手动预热开闸（跳过定时等待）
4. 学生账号抢 `POST /reserve/`，轮询 `GET /reserve/result/{traceId}`
5. 支付走 mock：管理员调 `POST /pay/wechat/mock-success/{outTradeNo}`，或配置 `wechat.pay.autoMockSuccess=true` 等 1.5 秒自动成功

curl 示例见 [[接口/接口总览|接口总览]]。

## 常见启动错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 数据库连接失败 | 连接串/账号/密码错，或 MySQL 没启动 | 查 `application-dev.yml`，检查 3306 |
| Redis 连接失败 | host/port 错，database 不存在 | Redis 的 database 不需要预建；查 6379 |
| RabbitMQ 连接失败 | host/port/virtual-host 错 | 查 5672，确认 `/` vhost 存在 |
| 所有接口 TOKEN_INVALID | 请求头不是 `Authorization: Bearer <token>` | 严格按格式带 Bearer 前缀 |
| 预约返回 UNGATED | 场次未开闸 | 走手动 warmup + open，或等到 flashTime |
| 预约返回 OUT_OF_STOCK | 该 slot 库存为 1，已被抢 | 换 slot 或取消别人的订单 |
| 预约返回 DUP_REQ | 本人已抢过该 slot，或上次请求残留 | 等补偿或换 slot |
| 启动时报加密相关错误 | jasypt 配置与密文不匹配 | 见 [[开发文档/配置说明|配置说明]] |
| `mainClass` 相关打包错误 | 旧版本 pom 缺主类配置 | 当前 pom 已配置 `spring-boot-maven-plugin` mainClass，拉最新代码 |
