# 接口契约

![](http://public.file.lvshuhuai.cn/images\derived-state-machine-1786601764741-4.svg)

接口是前端、Gateway、业务服务之间的稳定边界。本文按数据类型说明契约规则，不罗列每个 Controller 的全部方法；具体路径以 `src/apis` 和各模块 Controller 当前源码为准。

## 请求类型

### JSON 请求

列表、详情、配置、刷新和进度使用 JSON。参数中的 ID 表示数据库业务对象，不能传 NAS 绝对路径。时间字段必须说明单位，Movie/Series 的位置使用秒输入、微秒内部计算；Book 的页码、EPUB CFI、Music 的秒数不能混成一个字段。

### 二进制请求

PDF、EPUB、TXT、音频、图片、thumbnail、HLS playlist 和 m4s 使用原生媒体响应。客户端根据 Content-Type、Content-Range、Accept-Ranges 和状态码处理，不能经过统一 JSON response wrapper。

### WebSocket

WebSocket 只传递长任务状态和刷新通知，不承载主数据查询。消息必须包含 requestId 或资源身份、状态、错误信息和必要的版本；客户端重连后应重新查询结果，不能假设 socket 历史消息会补发。

### 内部调用

Feign 调用 LLM、Spider、OSS 时传递业务 requestId 和资源 ID。内部服务返回的错误要能区分超时、限流、认证失败、空结果和协议变更，业务模块决定降级行为。

## 响应规则

### JSON 包装

普通接口使用公共 `Response<T>`。`code` 表示稳定错误类别，`message` 面向用户，日志保留更完整的 requestId、资源 ID 和异常。前端不能以 HTTP 200 作为业务成功的唯一判断。

### 媒体状态

Movie/Series prepare 返回 sessionId、playUrl、variant、duration、resumePosition、heartbeatInterval、subtitle 和 status。`PREPARING` 表示可以重试媒体请求，`FAILED` 必须带 errorCode，不能把失败响应伪装成另一个画质的成功。

### 分页结果

分页响应包含 records、current、size、total 等字段，排序必须稳定。列表页不应从卡片标题推断详情 ID；所有进入详情、播放、文件或进度的请求都使用后端返回的稳定 ID。

### 空值语义

空数组表示没有子项，null 表示字段不存在或未生成，错误码表示无法读取。接口文档必须区分“暂无字幕”“字幕读取失败”“电影没有文件”三种情况。

## 资源契约

### 文件身份

Movie 使用 movieFileId，Series 使用 seriesEpisodeFileId，Book 使用 bookId 加文件类型，Music 使用 musicFileId 或 trackId，Picture 使用 pictureFileId。不能使用跨模块同名的 `fileId` 让前端猜资源类型。

### URL 生成

后端返回相对 Gateway URL，前端统一通过 `service.ts` 或 blob helper 加上运行时 API base。服务器绝对路径、Windows 盘符和本地缓存目录不能出现在 JSON 或浏览器 URL。

### 认证

普通 API 由统一 HTTP 拦截器带 token；媒体和 WebSocket 也必须有明确的认证方式。下载 Blob 不能绕过 token，WebSocket 重连必须重新读取当前 token。

### Range

Music 音频、Book PDF 和可恢复下载使用 Range。服务端必须支持合理的单段 Range，并对非法区间返回 416；前端不要把 206 当成异常，也不要在收到 416 后无条件从 0 重试。

## 业务契约

### 刷新

刷新接口只负责提交任务和返回 admission 结果。最终状态通过状态接口或 WebSocket 获取；重复请求应返回已有任务或明确拒绝。前端按钮状态不能成为后端的唯一去重机制。

### 进度

心跳请求包含用户上下文、具体媒体身份、位置、variant 或阅读格式。暂停、关闭、切换清晰度和切集都要有最后一次有效写入；服务端根据资源时长校验位置，迟到旧请求不能回退新位置。

### 派生任务

总结、插图、封面、thumbnail、embedding 和外部 metadata 都返回 requestId 或资源状态。前端显示 PENDING/RUNNING/FAILED 时，仍可读取已有的主数据和旧成功结果。

### 删除移动

文件操作接口传数据库 ID、目标父目录或新名称，不传任意绝对路径。成功响应表示数据库和文件系统已达到约定阶段；补偿中的操作必须返回可诊断状态，不能返回空成功。

**版本规则**

#### 字段扩展

新增 JSON 字段优先保持向后兼容；删除、改类型或改变单位需要前后端同时发布，或增加新字段。前端未知字段必须忽略，后端不能依赖旧客户端一定发送新字段。

#### 媒体协议

HLS playlist、segment URL、subtitle JSON 和 prepare 状态属于同一播放契约。改变 session 字段或起始时间语义时，必须同步 Movie、Series 前端和后端，不能只改一个模块。

#### 配置接口

配置列表返回 key、当前值、可选值和校验错误；敏感配置只返回是否已配置，不回显明文。前端保存前做基础格式校验，后端仍是最终校验者。

#### 兼容策略

Gateway 路由、服务名和前缀改变时先保留兼容入口，再迁移前端。旧路径不能静默指向不同资源，否则会出现“页面能开但数据串模块”的隐蔽错误。
