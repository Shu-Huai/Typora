# 图书刷新数据库

本文说明 `Media-Center-Book` 如何把书籍目录同步为 Book、BookFile、Author、Publisher 等数据库对象。公共准入和一致性规则见 [[总体设计/刷新数据库设计|刷新数据库设计]]，实体边界见 [[模块文档/Book/模块设计|图书模块设计]]。

## 刷新入口

### 管理请求

`AdminServiceImpl` 提供配置读取、全量刷新和文件变更入口。准入状态负责将进行中任务的重复请求合并或拒绝。`BookRefreshRequestManager` 负责发起端任务状态，不能把本地 future 当作跨实例唯一状态。

### 启动校准

启动时使用同一刷新入口校准 `bookBaseLocate`。服务重启后 watcher、leader 和 RabbitMQ listener 都是新对象，必须重新注册；数据库已有记录不能因此被重建成重复书籍。

### 文件监听

`BookFolderWatcher` 监听书籍根目录，`BookLeaderCoordinator` 竞争 leader 锁。事件只触发局部刷新提示；批量复制、OVERFLOW 或网络盘断开后仍要执行全量扫描。非 leader 不应直接写库。

### 消息处理

`BookRefreshCommandListener` 执行命令，`BookRefreshStatusListener` 广播状态。消息重投时依赖 BookFile 路径唯一性和业务 upsert；封面、插图和 summary 的异步任务另有状态，不应阻塞基础文件入库。

## 扫描入库

### 文件类型

扫描根目录来自 `bookBaseLocate`，扩展名由 `bookFileType`/`BookFileType` 约束。扫描器应跳过临时下载文件、隐藏缓存和不支持格式，并把规范化路径、大小、mtime 保存为诊断信息。

```text
book root
  -> supported BookFileType
  -> canonical path
  -> format / size metadata
  -> BookFile
```

### 书籍身份

Book 是阅读对象，BookFile 是物理文件。扫描不能只按文件名创建 Book；同一本书的 PDF、EPUB、TXT 可以共享 Book，但每个物理文件需要独立 BookFile。路径、格式和文件 fingerprint 共同决定文件身份。

### 作者出版者

作者、出版者及关系表在主对象提交后同步。作者名称清洗必须保持可追溯，不能因为大小写或标点清洗把两个不同作者合并。关系删除要基于本轮可信解析结果，解析失败时保留上一版关系并记录异常。

### 派生任务

`BookIllustrationStatusListener`、summary 和封面任务在文件事务提交后触发。插图生成可以失败而不影响书籍文件可读；任务必须引用 bookId/bookFileId 的稳定身份，重复消息不能生成多份不可追踪资源。

## 删除恢复

### 缺失文件

全量扫描比较 BookFile 路径集合。确认缺失后删除或软删除 BookFile；只有在没有其他文件和业务引用时，才按保留策略处理 Book、Author 和 Publisher。用户阅读进度不能因为一个文件暂时不可读就立即清除。

### 文件移动

移动按旧路径删除、新路径创建处理。若要保留阅读进度，应通过 fingerprint 或明确迁移规则关联新 BookFile；不能仅凭标题把不同版本书籍视为同一文件。

### 派生文件

封面、插图、缩略图和 summary 是派生对象，失败可重试。源文件格式或 fingerprint 变化时，依赖文件解析的派生结果应标记过期；清理派生文件不能越过配置根目录。

### 异常记录

解析失败、权限不足、乱码和文件锁定必须记录路径及原因。刷新任务允许部分成功，但状态要能查询失败条目。下一轮文件恢复后，应重新进入扫描而不是依赖人工删除失败记录。

## 验证证据

### 运行检查

文件检查使用独立临时目录或明确的演练根目录，不绑定个人 NAS 映射盘。重点记录扫描根目录、文件类型、规范化路径和失败原因。

### 数据场景

覆盖同书多格式、同名不同书、重复事件、删除、移动、损坏文件和空目录。检查 BookFile 路径唯一性、格式、阅读进度关联、作者出版者关系和派生任务状态。

### 消息场景

重投相同 command、重启 listener、切换 leader 后再次刷新。期望书籍和文件不重复，状态最终明确，插图或 summary 任务按业务键幂等。

### 运行证据

记录根目录快照、数据库行数、失败路径和状态消息。若页面显示书籍但无法打开，继续核对 BookFile 的真实路径、格式和下载接口，不要把扫描成功等同于文件服务成功。
