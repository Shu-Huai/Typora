# Series 前端选集

Series 播放页复用 Movie 的媒体时间轴原则，但页面增加季选择、集列表、自动下一集和集级进度。`src/views/series-play/index.vue` 的关键不是复制播放器，而是保证“当前集上下文”贯穿所有请求。

## 选集状态

### 当前上下文

页面状态必须同时保存 seriesId、seasonNo、episodeId、seriesEpisodeFileId、sessionId、duration 和 resumePosition。标题、集号和 URL 参数只用于定位，prepare 返回的 fileId 才是媒体请求的最终身份。

### 集列表

集列表按数值 seasonNo/episodeNo 排序，过滤没有可播放 EpisodeFile 的条目。选择集时先更新 pending selection，旧集的异步请求不能覆盖新选择。

### 播放状态

playing、paused、seeking、changingEpisode、changingVariant 和 failed 的状态优先级要明确。切集时显示新集准备状态，不把旧集的 playing 状态留在页面上。

### 自动下一集

ended 事件触发前先保存当前集进度，再从排序后的可播放集列表寻找下一项。找不到下一集时显示完成，不循环回第一集。

## 切集流程

### 手动切集

```text
click episode
  -> remember current episode heartbeat
  -> invalidate old load token
  -> close or detach old media session
  -> prepare new episodeFileId
  -> load new HLS
  -> restore new episode progress
```

旧集 close 失败不能阻止新集创建独立 session，但旧 session 清理要交给后端 TTL。

### 返回上一集

返回上一集重新读取该集 progress。页面不能复用最近一次 `currentTime`，因为它属于另一集且 duration 可能不同。

### 画质切换

同一 episodeFileId 内切 variant 保留 absolute currentTime；切集则同时替换 variant 上下文、字幕 context 和 duration。切换失败保留旧集旧画质可继续播放。

### seek

seek 目标带当前 episodeFileId 和 load token。用户连续拖动时，只处理最后一次 change；早先 prepare 返回的 playlist 不得覆盖最终目标。

## 播放附属状态

### 字幕上下文

subtitle URL 必须随着 episodeFileId 更新。加载新集字幕前清空旧 overlay，旧集 VTT cue 或 ASS renderer 不能继续读取新 video currentTime。

### 进度保存

heartbeat 包含 seriesEpisodeFileId、currentTime、paused 状态和 variant。切集前强制保存，页面卸载时再补一次，但不因为旧集网络失败把新集位置写入旧 session。

### 恢复时机

等新集 video metadata 和 HLS buffer 就绪后设置 resumePosition。若在 metadata 前设置 currentTime 被浏览器忽略，页面应重新应用一次，而不是把恢复失败误判为后端进度丢失。

### 状态展示

“第 N 集准备中”和“第 N 集播放失败”必须使用当前集名称。旧请求的错误不能覆盖新集已成功的 UI。

## 组件边界

### Movie 复用

可以复用时间格式化、字幕解析、HLS 错误分类和控制器行为；Series 特有的选集、季列表和 next episode 不放进 Movie 组件。

### 路由

路由至少保留 seriesId 和 seriesEpisodeFileId。title query 只作为页面展示 fallback，页面加载时仍需向后端确认该文件属于当前 Series。

### 网络请求

`apis/series.ts` 统一 prepare、heartbeat、subtitle 和 source pretranscode API。组件不得在模板中直接拼接 `/file/hls` 或调用 axios，避免 Movie/Series 的 base URL 和认证行为漂移。

### 卸载

清理选集轮询、自动播放 timer、heartbeat、HLS、subtitle renderer 和键盘事件。返回 Series detail 后不能残留旧 session 的定时器。
