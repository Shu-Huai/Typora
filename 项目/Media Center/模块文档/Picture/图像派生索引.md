# 图片派生索引

![](http://public.file.lvshuhuai.cn/images\picture-derivation-pipeline-1786601764741-13.svg)

Picture 的主索引是“文件存在、路径正确、用户能打开”。尺寸、EXIF、缩略图、embedding、Qdrant point 和 AI 插图都属于派生能力，应该分别记录状态，不能用一列 `ready` 概括所有结果。

## 元数据

### 提取结果

`PictureMetadataService.extract` 从原图读取宽高、方向、拍摄时间和 EXIF。元数据提取失败时仍保留 PictureFile，并记录失败原因和 fingerprint，下一次刷新可以重试。

### 方向处理

EXIF orientation 会导致原图横向、缩略图纵向或前端旋转错误。缩略图生成和详情展示要明确是否已经应用 orientation，不能让两个入口各自旋转一次。

### 版本绑定

Metadata 行必须绑定 pictureFileId 和 fingerprint。图片被覆盖后旧的拍摄时间、尺寸和向量都不能继续标记为当前结果。

### 性能

读取 EXIF 不应阻塞全量索引的主事务。先写基础文件，再以有界任务执行派生；失败可重试，不能无限创建线程。

## 缩略图

### 尺寸策略

`ThumbnailServiceImpl` 根据请求 size 生成受控尺寸，禁止把用户传入的巨大 width/height 直接交给图像库。缓存键包含 fileId、fingerprint、size 和处理版本。

### 原子发布

先写临时文件，校验 MIME、尺寸和可读性，再移动到最终路径。H5 或图片列表不能读取正在写入的半成品。

### 缓存清理

清理器只删除派生根目录中超过 TTL 的缩略图。原图、数据库记录和仍有 active request 的 thumbnail 受保护。删除失败保留重试状态。

### 浏览器输出

Content-Type 根据真实图片格式返回，不能所有图片都标成 image/jpeg。浏览器成功显示缩略图不代表原图、EXIF 或语义搜索可用。

## 向量检索

### 写入流程

```text
PictureFile READY
  -> image embedding
  -> ensure Qdrant collection
  -> upsert point(fileId, fingerprint, model, vector)
  -> MySQL embedding index READY
```

Qdrant point 的 payload 保存 fileId、fingerprint 和模型版本，查询结果必须回查 MySQL 确认文件仍存在。

### 集合生命周期

当前实现全量刷新可能删除旧 collection，首次成功 embedding 时重新创建。因此 collection 不存在是可恢复中间状态，不应让管理页报告“图片索引完全成功”。

### 模型变化

模型、维度或归一化方式变化时，旧向量不能和新向量混查。embedding index 记录 model、dimension、status，升级时按版本重建或切换 collection。

### 查询降级

LLM embedding 或 Qdrant 不可用时，目录浏览、原图和缩略图继续工作；语义搜索返回依赖错误和可重试提示，不返回空结果冒充“没有匹配图片”。

## AI 插图

### 任务身份

生成任务至少包含 fileId、style、model、promptHash、requestId 和用户 ID。相同 requestId 重复提交应返回已有任务，不能重复调用模型并产生多次费用。

### 结果发布

模型返回临时 URL 不等于成功。结果下载、对象存储上传、数据库关联和可访问 URL 全部完成后才发布 SUCCESS；任一步失败都保留 FAILED 和原因。

### 用户隔离

插图结果属于发起用户或明确的公共资源。用户 A 的任务不能被用户 B 的列表读到，Redis lock 只解决并发，不能替代数据库权限条件。

### 清理策略

AI 插图不跟随原图缩略图 TTL 自动删除。清理必须依据产品保留策略、用户引用和对象存储状态，避免用户刷新图片库后生成内容消失。

**验收证据**

派生矩阵：

```text
主文件：可读、路径正确
Metadata：尺寸/EXIF 正确
Thumbnail：尺寸、MIME、原子发布
Embedding：模型、维度、point、状态
Illustration：任务、对象存储、权限、URL
```

运行检查：

使用临时目录和假的外部响应，记录 Metadata、Thumbnail、Embedding、Illustration 的状态变化，不能依赖个人 Qdrant 数据。

故障演练：

分别模拟 EXIF 损坏、缩略图写盘失败、Qdrant 不可用、collection 被删除、模型超时、对象存储失败和重复 requestId。检查主索引是否仍可用，以及每个派生状态是否可重试。
