# 页面与流程

本文说明每个页面的职责、数据来源和关键交互。

本文不讨论前端技术实现，见 [[前端/前端架构|前端架构]]。

源码范围：`src/app/` 各页面、`src/components/` 业务组件。

## 页面结构

底部 5 Tab：记录 / 计时 / 分析 / 目标 / 动力（积分+奖励）。

```
/records    记录时间轴（默认首页）
/timer      秒表计时
/analysis   统计分析
/goals      目标
/points     积分流水（动力 Tab）
/rewards    奖励商店（动力 Tab）
/dashboard  今日总览（顶部入口）
/activities 活动管理
```

## 记录页与计时页

### 记录页（/records）

- 时间轴：记录 + 空白 gap（记录之间的空档展示）
- 日期导航：records-date-navigator 前后切换日期
- 补录：浮动 + 按钮 → backfill-sheet-form（底部抽屉表单，datetime-wheel-picker 滚动选择时间）
- 删除记录：调用 DELETE /api/records/[id]，返回 {id, delta, balance} 用于提示"已删除，积分 -X，余额 Y"
- 进入页面时触发目标结算（settleOnRecordsVisit），结算结果通过 searchParams（delta、balance、success）在 URL 上回传展示

### 计时页（/timer）

- TimerPanel：开始 → 选活动 → 每秒刷新 elapsed → 停止（完成/取消）
- 完成：POST /api/timer/stop mode=FINISH → 生成记录+积分，提示结果
- 取消：mode=CANCEL → 会话置 CANCELED
- 切换活动：POST /api/timer/activity（运行中换活动）
- 刷新页面后通过 GET /api/timer/current 恢复运行中的秒表

## 分析、目标与动力

### 分析页（/analysis）

日/周/月切换（analysis-range-picker）：

- 时间占比环形图（conic-gradient）
- 活动时长排行（CSS 柱状条）
- 5 分钟热力块（一天 288 格）
- 周分布 SVG 折线

### 目标页（/goals）

- 列表：每个目标的周期类型、目标时长、奖惩分、进度
- 编辑：goal-editor-form + goal-activity-picker（选关联活动）
- 历史：/goals/[id]/history 展示最近 100 条结算（达标/未达标、时长、积分）

### 动力 Tab（/points + /rewards）

- /points：当前余额 + 最近 100 条流水（类型、金额、balanceAfter、时间）
- /rewards：商品卡片（价格、库存），兑换按钮 → redeem action；管理入口增删改
- 兑换成功后余额刷新，库存（限量商品）减少

## 活动管理、状态与边界

### 活动管理（/activities）

- 列表：名称、图标、回报率、性质（正/中/负）
- 创建表单：activity-create-form，回报率按性质校验（正值活动不能给负回报率，反之亦然）
- 编辑：/activities/[id]/edit
- 删除：软删除（列表里消失，历史记录保留）

### 状态展示约定

- 表单错误：字段级 + 页面 feedback-banner
- 操作成功：searchParams 回传（records 页）或 router.refresh 后 UI 自然更新
- 空态：无记录时时间轴空、无目标时列表空
- 加载：无全局 loading，Server Component 渲染天然等待；计时页 CSR 有本地状态

### 已知边界

- /activities/new 是占位页（提示跳转），不是真正的创建页
- 记录页的 gap 展示依赖连续记录计算，深夜无记录时段会显示超长空档
- 分析页没有"自定义时间范围"，只有日/周/月三档
- 积分流水页只展示 100 条，更早的流水无入口
