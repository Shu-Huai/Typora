# 前端架构

本文说明前端的技术栈、目录结构、渲染策略和设计系统。

本文不讨论页面交互细节，见 [[前端/页面与流程|页面与流程]]。路由清单见 [[接口/接口总览|接口总览]]。

源码范围：`src/app/`、`src/components/`、`src/actions/`。

## 技术栈

Next.js 16 App Router、React 19、TypeScript、Tailwind CSS 4、@iconify/react、date-fns、zod。

没有：UI 组件库、状态管理库（用 React 内置 hooks）、图表库（全部手写）、测试框架。

## 目录与渲染策略

| 目录 | 内容 | 渲染 |
|---|---|---|
| `app/` | 页面与 API 路由 | 页面默认 Server Component |
| `components/ui/` | 基础组件：app-shell、bottom-tab-nav、section-card、iconify-icon 等 | 混合 |
| `components/{activities,analysis,dashboard,goals,records,rewards,timer}/` | 业务组件 | 叶子交互组件 CSR |
| `actions/` | Server Actions | 服务端 |

渲染策略：页面主体 SSR（Server Component 直接查库渲染），交互叶子（计时器、表单、图标选择器、滚动选择器）标 "use client"。计时器 TimerPanel 是典型 CSR：SSR 传入活动列表和运行中会话，客户端每秒 setInterval 刷新本地显示。

## 设计系统与图表

### 设计系统

- globals.css 1059 行，定义 `up-*` 语义类：up-card、up-page-header、up-stat-grid、up-tabbar、up-field、up-segmented-btn、up-progress-track
- CSS 变量主色 #2f93e8（蓝）、成功 #44ab73（绿）、损失 #eb9a48（橙）
- 移动 App 风格：max-width 420px 圆角壳、底部 5 Tab（记录/计时/分析/目标/动力）、浮动 + 按钮、100dvh
- 仅浅色主题，字体 Segoe UI / PingFang SC / Microsoft YaHei

### 图表（无图表库）

分析页图表全部手写：

- 环形图：conic-gradient
- 活动排行：CSS 柱状条
- 5 分钟热力块：CSS grid 色块
- 周分布：SVG polyline 折线

### 图标

@iconify/react 的 Icon 组件按名称运行时从 Iconify CDN 拉 SVG；iconify-icon 封装对不含 `:` 的值直接当 emoji 渲染（活动图标支持 emoji）。iconify-picker 提供搜索选择器。

## 状态数据流与已知边界

### 状态与数据流

- 无全局状态库：页面数据来自 Server Component 查询；交互状态用 useState/useEffect/useTransition
- 变更后刷新：Server Action 里 revalidatePath；计时走 fetch + router.refresh()
- 错误反馈：Server Action 抛错 → 页面 feedback-banner 横幅；计时 fetch 失败 → 组件内提示

### 已知边界

- 无暗色主题
- 无懒加载控制（Next.js 默认按路由分块，无手动动态 import）
- Iconify 依赖外部 CDN，离线图标空白
- 无组件测试、无快照测试
- 移动壳宽度 420px，桌面端居中留白，无响应式大屏布局
