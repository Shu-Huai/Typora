# 数据模型

本文说明 11 个 Prisma 模型、7 个枚举、约束和删除策略。

本文不讨论业务语义，见 [[总体设计/积分模型|积分模型]]、[[总体设计/目标结算|目标结算]] 和各模块文档。

源码范围：`prisma/schema.prisma`、`prisma/migrations/`。

## 模型清单

![](Z:\Public\images\uptimer-er-diagram.svg)

| 模型 | 业务意义 |
|---|---|
| User | 账号，pointBalance 积分余额 |
| Activity | 活动（回报率），软删除 |
| Record | 时间记录（含活动快照 + pointDelta） |
| TimerSession | 计时会话（RUNNING/FINISHED/CANCELED） |
| Goal | 周期目标（DAILY/WEEKLY/MONTHLY） |
| GoalActivity | 目标-活动多对多联接 |
| GoalSettlement | 目标周期结算（含目标快照） |
| PointTransaction | 积分流水（含 balanceAfter） |
| RewardItem | 奖励商品（限量/不限量） |
| Redemption | 兑换记录（价格快照） |
| Tag | 遗留模型，零代码引用 |

所有主键都是 cuid() 字符串。

## 枚举与关键约束

### 枚举

| 枚举 | 值 |
|---|---|
| ActivityNature | POSITIVE / NEUTRAL / NEGATIVE |
| RecordSource | MANUAL / TIMER |
| TimerStatus | RUNNING / FINISHED / CANCELED |
| PointTransactionType | RECORD_EARN / GOAL_REWARD / GOAL_PENALTY / REWARD_REDEEM |
| PointRelatedType | RECORD / GOAL_SETTLEMENT / REDEMPTION |
| GoalPeriodType | DAILY / WEEKLY / MONTHLY |
| StockMode | LIMITED / UNLIMITED |

### 关键约束

| 约束 | 位置 | 用途 |
|---|---|---|
| @@unique([userId, name]) | Activity / Tag | 活动名同用户唯一 |
| @@unique([goalId, periodStart, periodEnd]) | GoalSettlement | 周期结算幂等（防重复） |
| @@unique(email) | User | 登录标识 |
| @@id([goalId, activityId]) | GoalActivity | 复合主键 |
| 外键 Restrict | Record→Activity、GoalActivity→Goal | 活动/目标只能软删 |
| 索引 [userId,startAt] [userId,endAt] [activityId,startAt] | Record | 时间轴与冲突检测查询 |
| 索引 [userId,status] | TimerSession | 查运行中会话 |
| 索引 [userId,happenedAt] [userId,type] | PointTransaction | 流水分页 |

## 快照设计与删除策略

### 快照设计

三个模型带业务快照，历史数据不随配置漂移：

| 模型 | 快照字段 |
|---|---|
| Record | activityNameSnapshot、activityNatureSnapshot、rewardRateSnapshot |
| GoalSettlement | targetMinutesSnapshot、rewardPointsSnapshot、penaltyPointsSnapshot |
| Redemption | priceSnapshot |

配套的 pointDelta（Record）和 pointDelta（GoalSettlement）记录结算时的实际积分变动。

### 删除策略

| 对象 | 策略 |
|---|---|
| Activity | 软删除：isEnabled=false + name 加 `__deleted__<id>` 后缀（外键 Restrict 强制） |
| Record | 硬删除 + 负向积分回滚流水 |
| TimerSession | 硬删除可用（取消的会话留着） |
| Goal | 停用（isEnabled=false），历史结算保留 |
| RewardItem | 硬删，有兑换记录时被外键 Restrict 拦住（ConflictError） |
| Redemption / PointTransaction / GoalSettlement | 只增不改不删 |
| Tag | 无入口（遗留） |

## 已知边界

- Tag 模型零引用：schema 里有但没有任何代码使用，删掉不影响功能
- 活动软删除改名字会污染历史搜索（名字变了但记录快照不变，展示上以快照为准）
- Goal 停用后其 GoalSettlement 不再修正：reconcile 只处理启用目标的结算？源码里修正逻辑按"受影响结算"查，停用目标的旧结算是否修正需要确认，见 [[模块/目标/目标与结算|目标模块]]
- 无 CHECK 约束：durationMinutes ≥1、pointDelta 精度等靠应用层保证
- 时间字段全部 timestamp，无时区处理约定（date-fns 默认本地时区），跨时区使用有隐患
