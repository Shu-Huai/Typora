# 接口总览

本文列出全部页面路由、Server Actions 和 API 端点。

本文不讨论业务逻辑，见各模块文档。

源码范围：`src/app/`（页面 + route.ts）、`src/actions/`。

## 页面路由

| 路径 | 说明 | 登录 |
|---|---|---|
| / | redirect /records | 是 |
| /auth/login、/auth/register | 登录注册 | 公开 |
| /auth/logout | GET 路由，删 Cookie 重定向登录页 | — |
| /dashboard | 今日总览：日总结、积分余额、实时计时卡、时间轴 | 是 |
| /records | 记录时间轴，searchParams：date/backfill/error/success/delta/balance | 是 |
| /records/new | redirect 到 /records?backfill=1 | 是 |
| /timer | 计时页（SSR 传活动列表，客户端秒表） | 是 |
| /analysis | 统计：日/周/月，环形图、排行、热力块、周分布 | 是 |
| /activities、/activities/[id]/edit | 活动管理 | 是 |
| /activities/new | 占位页，提示去 /activities 创建 | 是 |
| /goals、/goals/new、/goals/[id]/edit、/goals/[id]/history | 目标管理 + 结算历史 | 是 |
| /points | 积分余额 + 最近 100 条流水 | 是 |
| /rewards、/rewards/new、/rewards/[id]/edit | 奖励商店 | 是 |

## Server Actions 与 API 端点

### Server Actions（src/actions）

| 文件 | Actions |
|---|---|
| auth.actions.ts | loginAction、registerAction、logoutAction |
| activity.actions.ts | create、update、setEnabled、delete |
| record.actions.ts | createRecordAction、updateRecordAction |
| goal.actions.ts | create、update、toggleEnabled |
| reward.actions.ts | create、update、redeem、delete |
| timer.actions.ts | startTimerAction、stopTimerAction（死代码，无人引用） |

Server Action 的约定：表单提交后 revalidatePath 刷新页面，错误透传到页面 feedback-banner。计时不经过 Action，走 API。

### API 端点

| 端点 | 方法 | 请求体 | 返回 |
|---|---|---|---|
| /api/timer/start | POST | {activityId?, startedAt?} | {session} |
| /api/timer/stop | POST | {mode: FINISH/CANCEL, note?, endedAt?} | {result} |
| /api/timer/current | GET | — | {session} |
| /api/timer/activity | POST | {activityId?}（切换运行中计时的活动） | {session} |
| /api/records | GET | ?date=YYYY-MM-DD | {records, gaps, range} |
| /api/records/[id] | DELETE | — | {id, delta, balance} |
| /api/goals/settle | POST | {now?} | {settledCount, scannedCount, settlements} |
| /api/goals/[id]/history | GET | — | {history}（最近 100 条） |

## 错误约定

| 场景 | 返回 |
|---|---|
| 未登录访问 API | 401 JSON {message: "未登录"}（middleware 层） |
| 未登录访问页面 | redirect /auth/login |
| 参数校验失败 | 400 + 具体消息（zod） |
| 业务冲突（重复计时、时间重叠、库存不足） | 409 或 400 + 业务消息 |
| Server Action 异常 | 页面 feedback-banner 展示消息 |

## 已知边界

- /api/goals/settle 不校验调用者身份：任何登录用户都能触发全局结算
- /api/records GET 无分页：按天返回全天数据，个人量级无压力
- Server Action 与 API route 两套错误处理路径，前端展示逻辑不统一
- 没有 API 版本号、没有 OpenAPI 文档
