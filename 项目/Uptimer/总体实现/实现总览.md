# 实现总览

本文说明项目的实际结构、模块分层、配置来源和当前实现边界。

本文不讨论各模块业务细节，见模块文档。鉴权细节见 [[后端/后端分层|后端分层]]。

源码范围：`src/` 全部、`middleware.ts`、`prisma/`。

## 实际结构与调用链

```
src/
├── actions/     # 6 个 Server Actions（表单提交入口）
├── app/         # App Router：页面 + 8 个 API 路由
├── components/  # 按业务域分组的 React 组件 + ui/ 基础组件
├── lib/         # auth、db、errors、time、constants、utils
└── modules/     # 业务分层：service/repository/schemas/types
```

核心调用链三条：

```
表单流：Form → Server Action → service → repository → Prisma → revalidatePath
计时流：TimerPanel(fetch) → /api/timer/* → timerService → $transaction + advisory lock
结算流：/records 页面加载 → settleOnRecordsVisit → 结算 + 修正 → 流水
```

## 模块清单与配置

### 模块清单

| 模块 | service 核心职责 |
|---|---|
| auth | 注册、登录、登出、会话校验（lib/auth 里的 getSession/requireUserId） |
| activity | CRUD、软删除、正负性质与回报率校验 |
| timer | start/stop/switch/current，advisory lock 串行化 |
| record | 补录、修改、删除、冲突检测、积分结算与回滚、结算修正联动 |
| goal | CRUD、活动关联、周期计算、结算与修正 |
| points | 流水追加（appendTransaction）、余额 increment |
| reward | CRUD、库存、兑换（双 advisory lock） |

### 配置来源

环境变量只有三个：

| 变量 | 用途 |
|---|---|
| DATABASE_URL | PostgreSQL 连接串（prisma.config.ts 读取） |
| AUTH_SECRET | JWT HS256 密钥，缺省回退 "dev-auth-secret-change-me" |
| AUTH_COOKIE_SECURE | 强制 Cookie secure（本地 http 用 false） |

没有其他配置文件：无 vercel.json、无 Docker、无 CI、无功能开关。主题色和设计系统在 globals.css 里。

## 鉴权与数据访问

### 鉴权三层

| 层 | 位置 | 行为 |
|---|---|---|
| middleware | 根目录 middleware.ts | 只查 cookie 存在性，粗防护（不验签） |
| requireUserId | Server Components / Actions | 真正验签 JWT，失败 redirect 登录 |
| getCurrentUserId | API routes | 验签失败返回 401 JSON |

middleware 的粗查是性能考虑（验签在 Node runtime 边缘/服务端做），安全性由第二三层保证。JWT payload 只有 sub 和 email，7 天过期，改密不会作废已签发的 token（没有 token version 机制）。

### 数据库与 Prisma

- Prisma 7 新风格：datasource url 移出 schema（prisma.config.ts 注入），engineType binary，@prisma/adapter-pg 适配器
- `lib/prisma.ts` 或 `lib/db.ts` 维护单例，日志只开 warn/error
- 6 个已应用迁移（init 之后有过 6 次结构演进：加认证、删颜色、删分类、删标签关系、目标升级、删目标组）
- seed 提供 demo 账号和 7 活动、2 目标、3 奖励

## 实现边界

- 无测试：任何改动靠手工验证，积分/结算逻辑没有回归保障
- 无日志系统：无 pino/winston，靠 Next.js 默认 console
- 无监控：错误只在前端 feedback-banner 展示（Server Action 错误透传到页面横幅）
- 无定时任务：结算全部惰性
- 无缓存：页面全部实时查库
- 遗留：Tag 模型零引用、timer.actions.ts 死代码、三个 placeholder 组件、updateUserBalance 死方法，见 [[后端/后端分层|后端分层]]
