# 环境与启动

本文说明新开发者如何从零把项目跑起来：环境要求、启动步骤、seed 数据和常见错误。

本文不讨论部署，见 [[开发文档/数据库与部署|数据库与部署]]。

源码范围：`package.json`、`.env.example`、`prisma/seed.ts`、`prisma.config.ts`。

## 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| Node.js | 20+（@types/node ^20） | |
| PostgreSQL | 任意现代版本 | 本地或远程均可 |
| npm | 10+ | |

不需要 Redis、不需要消息队列、不需要其他中间件。

## 启动步骤

```bash
# 1. 安装依赖（postinstall 自动跑 prisma generate）
npm install

# 2. 准备环境变量
cp .env.example .env
# DATABASE_URL 改成你的 PostgreSQL 连接串
# AUTH_SECRET 改成随机长字符串

# 3. 建表 + seed
npm run db:migrate
npm run db:seed

# 4. 启动（端口 4399）
npm run dev
```

浏览器打开 http://localhost:4399，会重定向到登录页。demo 账号：`demo@uptimer.local` / `demo1234`。

## seed 数据与常见错误

### seed 数据

`prisma/seed.ts` 创建：

- demo 用户（id `demo-user`）
- 7 个活动：学习(+10/h)、阅读(+6)、运动(+8)、睡觉(0)、吃饭(+1)、刷短视频(-8)、打游戏(-6)
- 2 个目标：每日学习 60 分钟（奖 8 罚 4）、每周学习+阅读 600 分钟（奖 30 罚 12）
- 3 个奖励：看一集剧(15 分不限量)、买一杯奶茶(25 分限量 5)、玩 30 分钟游戏(10 分不限量)

seed 可以重复执行（幂等依赖固定 id 的 upsert 语义，实际是 create，重复跑会报主键冲突，需要先清库或删 demo 数据）。

### 常见启动错误

| 现象 | 原因 | 处理 |
|---|---|---|
| prisma generate 失败 | 网络问题拉引擎失败 | 用镜像或离线缓存，Prisma 7 binary 引擎 |
| 数据库连接失败 | DATABASE_URL 错或 PG 未启动 | 检查连接串格式 postgresql://user:pass@host:5432/uptimer |
| migrate 报 pending | 迁移没跑 | npm run db:migrate |
| 登录后立刻跳回登录页 | AUTH_SECRET 与签发时不一致（改过 .env） | 清浏览器 cookie 重新登录 |
| 本地 http 下 Cookie 丢失 | AUTH_COOKIE_SECURE 设成了 true | 本地用 false |
| dev 起在 3000 而不是 4399 | 手动 next dev 没带参数 | 用 npm run dev（脚本里固定 --port 4399） |
| 页面样式混乱 | Tailwind 4 需要 postcss 插件 | 确认 npm install 完整，postcss.config.mjs 存在 |
| 计时接口 401 | cookie 被 middleware 拦 | 确认请求带 credentials（同源 fetch 默认带） |
