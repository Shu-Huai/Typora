## 项目概况

UpTimer 是个人成长时间记录与积分激励系统。给每个日常活动设定回报率（学习 +10 分/小时、刷短视频 -8 分/小时），用秒表计时或手动补录时间块，系统按回报率自动结算积分；周期目标（每日/每周/每月）达标发奖励分、未达标扣惩罚分；积分可以在奖励商店兑换（看一集剧、买杯奶茶）。

这是一个 Next.js 16 全栈单体应用：

- 框架：Next.js 16.2.2（App Router）+ React 19 + TypeScript
- 数据：Prisma 7 + PostgreSQL（11 个模型、7 个枚举）
- 样式：Tailwind CSS 4 自研设计系统，移动端 App 风格（420px 壳 + 底部 5 Tab）
- 认证：邮箱密码 + bcrypt + JWT httpOnly Cookie（7 天）
- 源码：`Z:\JetBrains\WebStorm\Uptimer`，git 分支 `master`，开发端口 4399

项目名与 Uptime 监控服务无关。"Timer" 指秒表计时，项目里没有 target/check/探针/告警这类监控概念。

## 关键事实速查

- 开发/生产端口 4399；数据库 PostgreSQL（`uptimer` 库，默认 public schema）
- Cookie 名 `uptimer_session`，JWT HS256（jose），7 天过期；密钥 `AUTH_SECRET`，缺省回退 dev 弱密钥
- 积分精度 decimal(12,2)，余额变更全部原子 increment + 流水记录 balanceAfter
- 活动回报率 decimal(10,2) 元/小时，pointDelta = round(回报率 × 分钟 / 60, 2)
- 同一用户同一时间只允许一个 RUNNING 计时会话；时间块不允许重叠
- 目标结算唯一键 (goalId, periodStart, periodEnd)，每周从周一开始
- 活动删除是软删除：isEnabled=false + 名字加 `__deleted__<id>` 后缀
- demo 账号：demo@uptimer.local / demo1234（seed 数据含 7 活动、2 目标、3 奖励）
- 前端计时器每 1 秒 setInterval 刷新本地显示，实际落库只在停止时发生
