# 页面与流程

本文说明前端每个页面的职责、数据来源和关键交互。

本文不讨论前端技术实现，见 [[前端/前端架构|前端架构]]。

源码范围：`src/views/`、`src/components/`、`src/layouts/`。

## 页面结构

```
登录 → 选存档 → home（BasicLayout 布局）
├── home          主页仪表盘
├── club-player   球员
├── player-perform 数据总览
├── game-prepare  赛前准备
├── game-on       比赛进行中
├── game-result   比赛结果
├── player-page   球员详情
└── transfer-list 转会大名单
```

GlobalHeader 常驻：当前日期、下一天（空格快捷键）、度假、退出、转会通知。

## 主页（home）

四个面板：

- 下场比赛：倒计时（distance 天）+ 两队排名
- 积分榜：我的俱乐部行高亮
- 财政：结余、赛季利润、预计收支（门票/广告/转播/奖金/工资）
- 统计：最佳球员（射手/评分/助攻/传球/拦截/过人）、球员统计、进球失球、战术统计

数据来自 club/league 的一批统计接口。

## 比赛三页

### 赛前准备（game-prepare）

- 足球场阵型盘：HTML5 拖拽把球员放进 12 个位置槽（ST/LW/RW/CAM/LM/RM/CM/CDM/LB/CB/RB/GK）
- 5 条战术权重滑条：下底传中/边路内切/倒三角/中路渗透/防守反击
- 开始比赛 → POST /game-pve/start → 跳 game-on
- 跳过比赛 → POST /game-pve/skip → 直接跳 game-result

### 比赛进行中（game-on）

- 左右球场 Field + 双方球员数据表（TeamData）
- 比分与回合时间（GameStatus）
- 战术选择器（TacticalSelector）：手动选战术 → 推进一回合；自动模式每 1 秒轮询推进
- 解说列表：script 按 `内容@时间@等级` 解析滚动展示
- turns > 51 → 跳 game-result

### 比赛结果（game-result）

- 比分 + 进球时间线
- 双方战术柱状图 + 能力雷达图（ECharts）
- MVP 卡（各项成功率）
- 解说时间线 + 双方球员表格

注意：文件内有一段 620 行的硬编码样例比赛数据，是开发期假数据，正常流程用 /game/{id} 的真实数据。

## 转会、球员与边界

### 转会大名单（transfer-list）

- 搜索：姓名/国籍/俱乐部/位置
- 排序、分页懒加载
- 点行弹报价窗口 → make-offer → 三个分支提示（成交/重复报价/资金不足）
- 被报价的通知在 GlobalHeader：接受 → 薪资谈判聊天弹窗（输入薪资 → 同意/再考虑，2 次失败破裂）；拒绝 → 通知

### 球员页

- club-player：卡片墙（头像 + 9 项能力条），分页
- player-page：详情（赛季统计、能力条、近 N 场评分折线、位置出场饼图）
- player-perform：能力/表现两个 tab 的表格，数值红黄绿着色

### 状态展示约定

- 加载：n-spin + LoadingEmptyWrapper 三态（加载/空/网络异常+重试）
- 空：转会页"暂无挂牌球员 明天再来看看吧"
- 错误：大多 catch 静默；关键分支 window.$message（阵容不完整、战术无效、交易状态）
- 下一天：5 秒"请稍候"伪等待弹窗，返回 state=pve 时跳赛前准备

### 已知边界

- 大量 .catch 静默吞错误，接口失败无感知
- 硬编码：club_id=1、620 行样例数据、转播奖金表
- 下一天的"请稍候"是前端 setTimeout(5000) 假等待，不是真实进度
- 无比赛中断恢复：game-on 刷新后 PvE 状态靠 show-game-info 恢复，体验一般
