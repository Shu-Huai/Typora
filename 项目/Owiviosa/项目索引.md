## 项目概况

Owiviosa 是一款足球经理模拟游戏（后端 README 标题 "Tie-Breaker Backend"）。玩家选一家俱乐部 → 逐日推进赛程 → 排兵布阵 → 逐回合指挥比赛 → 转会市场买卖球员 → 冲联赛排名。产品代号 OwiviOsa（猫头鹰谐音），与植物无关。

- 后端：Python 3.10 + FastAPI + SQLAlchemy 2 + MySQL，端口 8080，源码在 `Z:\JetBrains\PyCharm\Owiviosa-Backend`
- 前端：Vue 3.2 + TypeScript + Vite 4 + Naive UI + ECharts，端口 19232，源码在 `Z:\JetBrains\WebStorm\Owiviosa-Frontend`
- 核心：自研比赛模拟引擎（逐回合事件模拟 + 文字解说脚本）、球员/联赛/赛程生成器、转会市场与薪资谈判
- 特色：两个本地机器学习子系统——位置能力线性回归、战术成功率随机森林（sklearn 训练，5 个 .pkl 模型打进项目）

没有 Redis、没有消息队列、没有定时任务（世界推进靠玩家手动"下一天"或度假接口触发）。队伍徽章图片来自独立的静态图床（端口 1451，按队名 .png 加载）。

## 关键事实速查

- 后端 8080、前端 19232；前端无 Vite 代理，直连 `VITE_APP_INTERFACE_URL`（默认样例 http://localhost:8080/api/v1）
- 登录 OAuth2 表单（username=邮箱），JWT Bearer（python-jose HS256）；密码 bcrypt
- 存档 save 是游戏核心容器：date（如 2020-08-01）、season、player_club_id、lineup（阵容 JSON 串）
- 一场 PvE 比赛最多 51 回合（turns ≤ 51），前端自动模式每秒推进一回合
- 球员能力 11 项：射门/传球/盘带/拦截/速度/力量/侵略/预判/任意球/体力/守门
- 5 种战术权重：下底传中/边路内切/倒三角/中路渗透/防守反击
- 12 个场上位置：ST/LW/RW/CAM/LM/RM/CM/CDM/LB/CB/RB/GK
- 转会谈判成功率公式：90 - (想要工资 - 报价)/想要工资 × 100
- 队徽图片服务器独立（默认 http://localhost:1451/，按队名 .png）
- ML：位置能力 LinearRegression（数据在 machine_learning/linear_weight/data/），战术成功率 RandomForest（model/ 下 5 个 .pkl）
