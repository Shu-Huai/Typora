# 环境与启动

本文说明新开发者如何从零把前后端跑起来：环境要求、启动步骤、联调。

本文不讨论生产部署，见 [[开发文档/配置与部署|配置与部署]]。

源码范围：后端 `pyproject.toml`、`main.py`、`env.json.example`；前端 `package.json`、`.env.development.sample`。

## 环境要求

| 组件 | 版本 |
|---|---|
| Python | 3.10（venv 实际 3.10.9） |
| uv（推荐）或 pip | 后端包管理（uv.lock 已提交） |
| MySQL | 任意现代版本（pymysql 连接） |
| Node.js | 16+（Vite 4 时代版本） |
| 可选：静态图床 | 队徽服务器（默认 http://localhost:1451/） |

## 后端启动与前端启动

### 后端启动

```bash
cd Owiviosa-Backend

# 用 uv 安装依赖
uv sync
# 或 pip install -r requirements.txt（旧清单，版本偏旧）

# 配置数据库
cp env.json.example env.json
# DB_URL 改成你的 MySQL 连接串（core/dburl.py 里选定 mysql_db_url = "MySQL"）

# 启动（uvicorn :::8080）
python main.py
```

启动时自动建库建表（create_all）+ 建 player_id_idx 索引 + 加载 5 个 ML 模型 .pkl。日志输出到 `./logs/log_YYYY_MM_DD.log`。

### 前端启动

```bash
cd Owiviosa-Frontend
pnpm i        # 或 npm i（有 patch-package postinstall）
# 准备环境变量
# 参考 .env.development.sample 创建 .env.development：
#   VITE_APP_INTERFACE_URL="http://localhost:8080/api/v1"
#   VITE_TEAM_IMAGE_BASE_URL="http://localhost:1451/"
pnpm dev      # 端口 19232
```

前端无代理，直连 VITE_APP_INTERFACE_URL。队徽图片按 `VITE_TEAM_IMAGE_BASE_URL + 队名.png` 加载，图床没起时首页队徽裂图。

## 本地联调与常见错误

### 本地联调

1. 注册 → 登录 → 选存档页选"五大联赛"剧本 + 一家俱乐部 → 进入 home
2. 点"下一天"（或按空格）推进世界，`state=pve` 时进入赛前准备
3. 布阵（拖 11 人上场）+ 调战术权重 → 开始比赛 → 手动选战术逐回合推进，或开自动模式
4. 转会页搜索球员 → 报价 → 对方接受后薪资谈判
5. 开发期可用 /api/v1/test/game-process-demo 直接看一场完整比赛的解说

### 常见启动错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 连不上 MySQL | env.json 或 dburl.py 配置 | 检查连接串和 MySQL 服务 |
| 模型加载失败 | machine_learning/model/ 下 .pkl 缺失或版本不符 | 确认 5 个 .pkl 存在；重新训练见 [[模块/机器学习/机器学习子系统|机器学习子系统]] |
| 前端所有请求失败 | VITE_APP_INTERFACE_URL 未配置 | 创建 .env.development |
| 登录 401 | token 密钥不一致（token_config.py 被改过） | 确认代码一致，重新登录 |
| 队徽裂图 | 图床没起 | 起静态服务（1451 端口），或忽略（不影响玩法） |
| 依赖冲突 | requirements.txt 与 pyproject.toml 版本不一致 | 以 uv sync（pyproject + uv.lock）为准 |
| 下一天后无反应 | BackgroundTasks 后台执行中 | 刷新首页看日期是否变化 |

## 开发约定

- 后端无测试、无 lint 配置，改动比赛引擎后手工用 game-process-demo 验证
- 随机数无种子：复现问题靠重复触发
- 不要在生产环境暴露 /api/v1/test 端点
