# 接口总览

本文列出全部 HTTP 端点、鉴权要求和危险端点。

本文不讨论业务逻辑，见各模块文档。

源码范围：`routers/api_v1/` 全部、`routers/api_test/test.py`。

## 通用约定

- 前缀 /api/v1（config 的 API_PREFIX 为 /api）
- 鉴权：`Authorization: Bearer <token>`（OAuth2 风格，login 用表单 username/password）
- game/player/club/league/game-pve/next-turn/transfer 路由在注册时统一挂 verify_token 依赖；user 路由部分端点自行校验
- 返回：FastAPI 原生 JSON（无统一 {code, data} 包装），错误是 FastAPI 的 {detail} 格式

## 错误约定

- 401：login 密码错 "Incorrect username or password"；token 无效 "Could not validate credentials"
- 400：重复邮箱 "Email already registered"；非法剧本/俱乐部 403
- 404：比赛/球员不存在
- 前端只细分 401/400(重复邮箱)/404/500/502，其余分支是注释占位

## 已知边界

- 转会端点大量用 GET + query 参数执行写操作（报价、谈判、标记），违反 HTTP 语义，且浏览器预取可能误触发
- /test 端点无鉴权
- 无接口文档（无 OpenAPI 导出配置确认，FastAPI 默认自带 /docs）
- 返回格式不统一：多数直出模型，统计接口出 pandas records，中文键 dict 混用
