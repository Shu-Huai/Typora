## 配置与网关

FastAPI 读取 `model_provider/application.yml`，再递归合并同目录且被 Git 忽略的 `application-local.yml`。不需要通过终端临时设置环境变量。

| 配置块 | 选择项 | 实际行为 |
| --- | --- | --- |
| `controller-llm` | `online` 或 `local` | `/v1/chat/completions` 将请求转发到选定的 OpenAI 兼容上游，并覆盖请求中的模型名 |
| `embedding` | `online` 或 `local` | 在线模式调用 OpenAI 兼容 Embedding；本地模式延迟加载 `sentence-transformers` |
| `slide` | `shared-path` | Python 读取 SVS 的唯一根目录，必须与 Java 一致 |
| `openslide` | `enabled`、属性上限 | 控制 OpenSlide 元数据端点 |

`/v1/chat/completions` 保持请求和流式响应的 OpenAI 兼容传输格式。上游 HTTP 错误会透传状态码和响应体；无效 JSON 返回 400；连接/转发问题返回 502。Java 端配置 HTTP/1.1，避免 Uvicorn 收到 h2c 升级请求导致空请求体。

## API 与数据边界

| 路径 | 用途 | 当前实现 |
| --- | --- | --- |
| `GET /health` | 健康检查 | 返回 `UP`、版本、`slideMetadata=REAL` |
| `POST /v1/chat/completions` | Controller LLM 网关 | 在线或本地上游转发，可流式 |
| `POST /v1/embeddings` | 文本向量 | 可配置在线或本地提供方 |
| `POST /api/model/text-diagnosis` | 文本诊断 | 随机返回演示性诊断结果 |
| `POST /api/model/multimodal-diagnosis` | 多模态诊断 | 随机返回演示性诊断，支持降级说明 |
| `POST /api/slide/metadata` | 读取 SVS 元数据 | 真实 OpenSlide 文件读取 |

[已知边界] `diagnosis_service.py` 的诊断集合为“无明显异常、冠状动脉粥样硬化、高血压性心脏病、心肌纤维化”，每次随机选择，置信度与耗时为固定演示值。它不加载 LoRA 或多模态真实模型，不得以其输出作医学判断。

多模态接口不会将 SVS 变成病理文字。它只接收 Java 已验证的切片逻辑引用，并在结果中说明这些引用作为视觉 softprompt 输入。没有器官检验完整描述时返回 `DEGRADED`、缺失字段与警告。

## OpenSlide 故障语义

| 情况 | HTTP 状态 | 返回含义 |
| --- | --- | --- |
| 功能关闭或未安装绑定 | 503 | OpenSlide 元数据不可用 |
| 共享目录未配置或不可用 | 503/404 | 运行环境或目录不满足要求 |
| 绝对路径、越界、非 SVS | 400 | 拒绝用户路径 |
| 文件不存在 | 404 | 相对路径在根目录下不存在 |
| 格式不支持 | 422 | OpenSlide 不支持该文件 |
| OpenSlide 读取错误 | 500 | 文件或库读取失败 |
