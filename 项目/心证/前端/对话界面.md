## 页面与权限

| 路由 | 页面 | 访问规则 | 主要行为 |
| --- | --- | --- | --- |
| `/login` | `LoginView` | 未登录可访问 | 登录后保存 JWT 与用户信息 |
| `/agent/:conversationId?` | `AgentWorkspaceView` | 已登录 | 新建、选择会话、发送消息、展示流式轨迹 |
| `/history` | `ConversationHistoryView` | 已登录 | 浏览可见会话历史 |
| `/profile` | `ProfileView` | 已登录 | 展示当前账号信息 |
| `/admin/users` | `UserManagementView` | `ADMIN` | 创建、启停用户 |
| `/admin/knowledge` | `KnowledgeBaseView` | `ADMIN` | 上传、启停、重建、删除 PDF |

路由守卫读取 `useAuthStore`。没有 Token 或用户信息时跳到登录页；普通用户进入管理员路由时跳回 Agent。Axios 收到 HTTP 401 时清除本地登录状态并跳转登录页。

## 一次发送与 SSE 消费

```text
MessageComposer
  → conversationStore.send
  → POST /conversations/{id}/messages
  → POST /event-ticket?runId=...
  → EventSource /events?ticket=...
  → mergeEvent 更新 Pinia
  → MessageThread 与 ToolActivityCard 渲染
```

`conversationStore` 保存以下与当前页面相关的状态：

| 状态 | 来源 | 前端行为 |
| --- | --- | --- |
| `messages` | 会话详情、`MESSAGE_COMPLETE` | 按 `sequenceNo` 排序展示 |
| `streamingContent` | `MESSAGE_START`、`MESSAGE_DELTA` | 显示正在生成的临时 Agent 消息 |
| `toolActivities` | `TOOL_START`、`TOOL_RESULT` | 以 `toolCallId` 合并为可折叠工具卡片 |
| `publicSummaries` | `MODEL_PUBLIC_SUMMARY` | 显示模型提供方可用的公开摘要 |
| `runStatus` | Run、消息完成、错误事件 | 影响顶部状态和输入禁用 |
| `error` | 请求失败或 SSE 断开 | 显示提示并从服务端刷新会话 |

`EventSource` 收到 `DONE` 后关闭连接并刷新会话；异常断开时也会刷新。事件序号去重，避免缓冲重放与实时事件重复显示。

## 界面边界

[已实现]

- 消息区是独立可滚动区域，输入框位于网格最后一行，长对话不应挤出输入区。
- 移动端隐藏桌面会话栏，使用 `NDrawer` 打开会话列表。
- 工具卡片默认折叠；展开后只显示工具名、公开结果摘要、耗时和错误码。
- 页面明确声明辅助结果不能替代专业病理诊断。

[已知边界]

- 前端不直接上传 SVS，也不展示服务器绝对路径。
- 运行轨迹来自当前或最近一次 Run；跨多个历史 Run 的完整比较需在会话详情数据基础上扩展界面。
- 浏览器刷新后临时的 SSE 增量文本消失，但最终消息、工具和证据会从后端详情恢复。
