## 角色、输入和权限

| 角色 | 可以做什么 | 不能做什么 |
| --- | --- | --- |
| 普通用户 | 登录、创建自己的会话、发送消息、查看自己的运行轨迹 | 管理账号、上传/管理知识 PDF、查看其他普通用户会话 |
| 管理员 | 具备普通用户能力；创建、启停账号；上传、启停、重建、删除 PDF | 通过公开注册创建账号 |
| Controller Agent | 读取当前会话状态并自主调用已注册工具 | 绕过 Java 权限、步数、路径和领域守卫；输出私有推理链 |

[已实现] 系统无公开注册接口。首次启动只在管理员不存在时按 `bootstrap.admin` 创建管理员；密码以 BCrypt 哈希保存。

用户可以直接输入以下任意组合，无需填写固定病例表单：

- 病例自然语言信息：年龄、性别、临床资料、器官检验完整描述、组织病理学检验文本；
- SVS 文件名或相对于共享目录的路径；
- 心脏病理相关问题、知识库检索诉求或公开互联网证据诉求；
- 明确声明“仅文本诊断”“没有切片”“直接继续”等会影响 Agent 后续选择的文字。

## 核心场景

### 对话式病例分析

```text
用户发送文本
  → 后端创建用户消息与 PENDING 运行
  → Controller 选择更新病例事实、核验切片、检索或诊断等工具
  → 工具记录审计与证据
  → Agent 输出辅助回答
  → 前端展示回答和本轮公开轨迹
```

同一会话在 `PENDING` 或 `RUNNING` 时拒绝第二条消息，避免同一事实状态被并发修改。用户刷新页面后可通过会话详情恢复历史消息、工具轨迹和证据。

### 知识库管理

管理员上传不超过 50MB 的 PDF。后端计算 SHA-256 去重、原子保存文件、PDFBox 按页切分文本、调用 Embedding、写入 Qdrant。管理员可停用、重建或删除文档。

### 切片资源核验

用户仅提供逻辑相对路径。Java 先验证目录边界、扩展名和文件存在性；Python 再次验证同一共享目录，并以 `openslide-python` 读取元数据。不会把 SVS 上传到浏览器或生成病理文字描述。

## 不做的内容

[已知边界]

- 不保存或导入数据集仓库；历史 CSV/XLSX 只用于开发时理解字段和命名边界。
- 不实现异步队列、GPU 调度、多实例协调或任务断点续跑。
- 不展示 Controller 私有思维链；仅展示工具活动、工具公开结果、模型提供方可用的公开摘要和回答增量。
- 不保证所有互联网搜索都有结果；上游搜索引擎限流、验证码或不可用时允许空结果或工具失败。
- 不把当前诊断结果用于临床决策；真实模型替换、标定、医学验证和合规流程不属于初版。
