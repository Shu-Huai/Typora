# 配置说明

本文汇总所有配置项：Spring 配置文件、Jasypt 加密、config 业务表、前端环境变量。

本文不讨论配置项的联动校验逻辑，见 [[模块/管理端/管理功能|管理功能]]。不讨论每个配置怎么改，见 [[开发文档/环境与启动|环境与启动]]。

源码范围：`src/main/resources/application.yml.example`、`application-dev.yml.example`；`config/` 与 `beans/` 包；`src/main/resources/schema.sql`、`data.sql`；前端 `.env.development.sample`。

## Spring 配置与 Jasypt 加密

### Spring 配置

真实文件 `application.yml`、`application-dev.yml` 被 .gitignore 排除，仓库只保留 `.example` 版本。开发者复制改名为真实文件后修改。

`application.yml` 关键项：

| 配置 | 默认/示例 | 说明 |
|---|---|---|
| `server.port` | 25001 | 后端端口 |
| `app.timezone` | Asia/Shanghai | 应用时区，调度器 zone 和 Jackson 都依赖它 |
| `token.privateKey` | 无 | JWT HS256 签名密钥，必须改 |
| `token.youngToken` | 1000000 ms | 新鲜 token 窗口，之后响应头回写新 token |
| `token.oldToken` | 3000000000 ms | token 总寿命 |
| `jasypt.encryptor.password` | 无 | 配置解密口令，必须与加密时一致 |
| `jasypt.encryptor.algorithm` | PBEWITHMD5ANDDES | 加密算法 |
| `wechat.pay.appId/mchId/...` | 占位 | 微信支付参数，当前 mock 模式下仅日志展示 |
| `wechat.pay.autoMockSuccess` | true | mock 支付是否 1.5 秒后自动成功 |
| `reserve.mode` | redis | 预约实现切换：redis / db |

`application-dev.yml` 关键项：

| 配置 | 说明 |
|---|---|
| `spring.datasource.url` | 带 `createDatabaseIfNotExist=true` 的 MySQL 连接串，库名 `badminton_flash` |
| `spring.data.redis.database` | 2，所有 bf: key 的归属库 |
| `spring.sql.init.mode` | always，每次启动执行 schema.sql + data.sql（都是幂等语句） |
| `spring.rabbitmq.publisher-confirm-type` | correlated，抢票依赖它拿确认 |
| `spring.rabbitmq.publisher-returns` / `template.mandatory` | true，消息不可路由时退回 |
| 日志级别 | ReserveController/ReserveServiceImpl/ReserveConsumer 设为 ERROR，压测时压日志量 |

### Jasypt 加密

敏感配置项（如数据源密码、token 密钥）可以写成 `ENC(密文)`，启动时用 `jasypt.encryptor.password` 解密。

生成密文的两种方式：

```bash
# 方式一：本地跑 JasyptComputer 的 main（项目内 tools 未提供，可用标准 jar）
java -cp jasypt-1.9.3.jar org.jasypt.intf.cli.JasyptPBEStringEncryptionCLI \
  input="明文" password="口令" algorithm=PBEWITHMD5ANDDES
```

解密器实现是项目内 `JasyptComputer`（iterations=1000、RandomSaltGenerator、base64），`@EnableEncryptableProperties` 全局开启。注意：algorithm 必须是 PBEWITHMD5ANDDES，用默认 PBEWithMD5AndTripleDES 生成的密文解不开。

## config 业务表

`data.sql` 幂等初始化 7 项（`INSERT ... SELECT ... WHERE NOT EXISTS`）：

| config_key | 默认值 | 含义 |
|---|---|---|
| WARMUP_MINUTE | 5 | 开抢前多少分钟开始预热 |
| GENERATE_TIME_SLOT_TIME | 00:35:00 | 每天几点生成当天时间槽 |
| PAY_TIMEOUT_MINUTE | 15 | 未支付多少分钟后自动取消（也是支付单有效期） |
| PAY_AMOUNT | 15.00 | 单次预约价格（元） |
| COURT_COUNT | 15 | 球场数量 |
| COURT_NAME_FORMAT | 球场 %d | 球场命名模板，必须含 %d |

管理员账号同文件初始化：`student_id=root`，`password=5A31893BE1B474502A046E74841E119B`（MD5 大写存储值，明文不在仓库里）。

这些值运行时可以在管理面板改，改动有校验和联动补偿，见 [[模块/管理端/管理功能|管理功能]]。

## 前端环境变量与生效范围

| 变量 | 默认 | 说明 |
|---|---|---|
| VITE_API_BASE_URL | 空 | 非空时前端直连该地址（生产），空则走相对路径+Vite 代理（开发） |
| VITE_DEV_PROXY_TARGET | http://localhost:25001 | Vite 代理目标 |

实际 `.env.development` 里代理目标是 `http://lvshuhuai.cn:25001`（远程服务器），本地联调记得改。

前端没有其他运行配置。主题（深/浅色）存 localStorage `bf_theme_mode`，token 存 `bf_token`，都不是配置文件。

配置修改后的生效方式：

| 改动 | 生效方式 |
|---|---|
| application*.yml | 重启后端 |
| 前端 .env | 重启 vite |
| config 表 | 立即生效，管理端保存时自动补偿（生成槽、预热等） |
| 数据库 schema | 重启后由 schema.sql 执行（只建不删） |
