# 接口总览

本文列出全部 HTTP 端点、鉴权要求、统一返回结构和错误码。

本文不讨论每个接口的业务逻辑细节，见对应模块文档。请求响应示例可打开后端 `/doc.html`（Knife4j）在线调试。

源码范围：`controller/` 包全部类、`response/` 包、`model/dto`、`model/vo`。

## 通用约定

- 基础路径无前缀，直接按控制器路径
- 除白名单外全部需要 `Authorization: Bearer <token>`
- 请求响应统一 `Response<T>`：

```json
{ "code": 200, "enumCode": "SUCCESS", "message": "...", "data": ... }
```

- 成功时 code=200；失败时 code 为错误码，enumCode 是错误枚举名
- token 续期时响应头 `Authorization: Bearer <新token>` 回写
- 时间字段序列化为 `HH:mm:ss` 和 `yyyy-MM-dd` 格式，时区 Asia/Shanghai

## 白名单

无 token 可访问：

- `POST /auth/register`、`POST /auth/login`
- `/doc.html`、`/v3/api-docs/**`、`/webjars/**`、`/swagger-resources/**`（接口文档）

## 端点清单

### 认证与用户

| 端点 | 鉴权 | 说明 |
|---|---|---|
| POST /auth/register | 白名单 | body UserDTO{studentId, password}，返回 token |
| POST /auth/login | 白名单 | 同上 |
| GET /user/me | USER | 当前用户信息 |
| PATCH /user/me | USER | 改学号/密码，body UserSelfUpdateDTO，改哪个填哪个 |
| DELETE /user/me | USER | 自助销户，ADMIN 禁止 |

### 浏览与预约

浏览全部 USER 起，条件都是可选查询参数，省略即不过滤：

| 端点 | 说明 |
|---|---|
| GET /browse/session | 场次列表。8 个边界参数：flashTime/beginTime/endTime/slotInterval 各自的 Lower/UpperBound |
| GET /browse/session/{id} | 场次详情 |
| GET /browse/open/{sessionId} | 是否已开闸（读 Redis gate） |
| GET /browse/court | 球场列表，可选 courtNameLike 模糊 |
| GET /browse/court/{id} | 球场详情 |
| GET /browse/slot | 时间槽列表，sessionId 必填，可选日期区间、courtIds（可重复）、起止时间区间 |
| GET /browse/slot/{id} | 时间槽详情 |
| GET /browse/reservation | 本人订单，可选 sessionId、slotId、statuses（可重复）、日期区间 |

预约：

| 端点 | 鉴权 | 说明 |
|---|---|---|
| POST /reserve/ | USER | body ReserveDTO{slotId, sessionId}，同步返回 traceId |

## 错误码

| 枚举 | code | 触发场景 |
|---|---|---|
| SUCCESS | 200 | 成功 |
| UNAUTHORIZED | 401 | 预留 |
| USERNAME_OR_PASSWORD_ERROR | 401 | 登录失败 |
| TOKEN_EXPIRED | 401 | token 超 oldToken |
| TOKEN_INVALID | 401 | 无 token / 格式错 / 验签失败 |
| FORBIDDEN | 403 | 角色不符（含 dbCheck 失败） |
| USERNAME_EXISTED | 2041 | 注册重名（遗留码） |
| USER_DUPLICATED | 2042 | 注册重复学号 |
| UNGATED | 4002 | 未开闸 |
| DUP_REQ | 4003 | 重复抢同一 slot |
| OUT_OF_STOCK | 4004 | 库存为 0 |
| TOO_MANY_REQUESTS | 4101 | 限流 |
| TIME_UNDEVIDED | 4444 | 时间槽间隔不能整除时间段 |
| DUP_GEN_SLOT | 4556 | 重复生成时间槽 |
| COURT_COUNT_UPDATE_WINDOW_CLOSED | 4557 | 球场数修改超出允许窗口 |
| PARAM_ERROR | 5010 | 参数错误（类型、缺失、非法值） |
| VALIDATE_FAILED | 1002 | 校验失败 |
| FAILED | 1001 | 业务失败 |
| DB_ERROR | 5002 | 数据库异常 |
| SQL_ERROR | 5001 | SQL 异常 |
| ERROR | 5000 | 未知异常 |
| VSPHERE_LINK_ERROR | 2001 | 遗留码，未使用 |

前端拦截器的行为：code 非 200 时弹 message.error 并抛 ApiError；TOKEN_EXPIRED / TOKEN_INVALID 额外清本地 token。响应头 token 回写自动替换本地 token。
