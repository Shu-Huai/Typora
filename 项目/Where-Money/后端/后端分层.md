# 后端分层

本文说明后端的分层约定、各层职责、公共组件。

本文不讨论业务逻辑，见各模块文档。包结构总览见 [[总体实现/实现总览|实现总览]]。

源码范围：`src/main/java/shuhuai/wheremoney` 全部包。

## 分层约定

Controller → Service（接口 + impl）→ Mapper（接口 + 手写 XML）。没有 Repository 层。

- Controller 全部 @RequestParam 接收表单参数，业务判断在 Service
- 异常统一抛 BaseException 子类，BaseController 是全部 Controller 的父类，用 @ExceptionHandler 集中转成 Response
- 实体直接出 Controller（getBill、getAsset 等），VO 只在列表聚合和统计场景用（GetAllBillResponse、StatisticResponse 等）
- 事务注解只在 BillServiceImpl 的 addBill/changeBill 和 BudgetServiceImpl 的 rebuildBudgetByBook 上，其他 Service 无显式事务

## 数据层与配置组件

### 数据层

MyBatis 手写 XML（10 个 mapper 文件），无 MyBatis-Plus、无 JPA。特点：

- resultMap 完整映射（驼峰转下划线由 mybatis 配置开启）
- selective insert/update：只更新非空字段
- 统计 SQL 直写聚合（分类统计、日统计、月度最大最小）
- 四类账单表各自独立 mapper，跨表合并排序在 Service 里做

枚举存储通过 TypeHandler：AssetTypeHandler、BillTypeHandler 按 name 读写。

### 配置与公共组件

| 类 | 作用 |
|---|---|
| AuthWebConfig | 注册 TokenValidator 拦截 /api/** |
| CorsConfig | 全开放 CORS + allowCredentials |
| RedisConfig | 序列化配置 + 5 个 ops Bean + @EnableCaching（无注解使用） |
| SpringDocConfig | Swagger 分组和 Bearer 安全方案 |

| 工具 | 说明 |
|---|---|
| TokenValidator | 拦截器：JWT 校验、双阈值续期、ThreadLocal 存 userId（不清理） |
| HashComputer | MD5 大写哈希（密码） |
| JasyptComputer | PBEWithMD5AndDES 加解密 |
| JsonOperator | 读 user.dir 下 json 文件（默认分类） |
| RedisConnector | 约 500 行通用封装，业务只用 string 相关方法 |
| RequestGetter | 请求/响应上下文（日志用） |
| TimeComputer | GMT+8 时间工具（取日界、日差、秒数） |
| BeanGetter | ApplicationContext 静态获取 Bean（绕过循环依赖） |
| Logger | ResponseBodyAdvice，按 code 记响应日志（含 URL） |

## 日志约定与已知边界

### 日志约定

- 无日志框架扩展，Spring Boot 默认 logback 输出控制台
- 响应日志由 Logger（ResponseBodyAdvice）统一写：成功 info、失败 error，含完整请求 URL
- AI 调用的业务日志落在数据库 ai_bill_parse_log，不是日志文件
- ManageController 提供日志文件下载（`${user.dir}/logs/log.log`），但默认日志不落文件，该接口实际拿不到东西

### 已知边界

- ThreadLocal 不清理：Tomcat 线程复用下 userId 残留，见 [[总体实现/异常与失败处理|异常与失败处理]]
- BeanGetter 静态拿 Bean 是循环依赖的补丁：BillServiceImpl 统计方法里用它拿 BillService，说明依赖结构有环
- 无分页组件：列表接口全量返回
- 事务粒度：只有账单和预算重建有 @Transactional，资产余额更新依赖账单事务
