# 接口总览

本文列出全部 HTTP 端点、鉴权要求、入参方式和错误码。

本文不讨论业务逻辑细节，见各模块文档。在线调试可用后端 SpringDoc 的 Swagger UI（访问 /swagger-ui.html，鉴权方案 Bearer JWT）。

源码范围：`controller/` 全部类、`response/`。

## 通用约定

- 全部接口使用 @RequestParam（表单参数）或 MultipartFile，没有 JSON 请求体
- 统一返回 `Response<T>`：`{code, message, data}`，code=200 为成功，HTTP 状态码恒为 200
- 除 user 的 login/register/protocol 外，全部需要 `Authorization: Bearer <token>`
- token 续期：响应头 `Authorization: Bearer <新token>` 回写，前端自动替换
- 图片接口返回 JSON 里的 base64 字节数组，不是二进制流

## 白名单

无需 token：`POST /api/user/register`、`POST /api/user/login`、`GET /api/user/protocol`。

配置里还排除了 `/api/test/generate-token`，但该端点不存在，是死配置。

## 端点清单

### 用户与资产

用户（/api/user）：

| 端点 | 说明 |
|---|---|
| POST /register | userName、password，注册即建默认账本和 43 个默认分类 |
| POST /login | 返回 LoginResponse（含 token） |
| PATCH /user-name | 改用户名，返回新 token |
| PATCH /password | 改密码 |
| GET /protocol | 使用协议 HTML 字符串 |

资产（/api/asset）：

| 端点 | 说明 |
|---|---|
| POST /asset | assetName、balance、type（资金/信用卡/充值/投资理财）、billDate/repayDate/quota（信用卡）、inTotal、svg |
| PATCH /asset | 按 assetId 只更新非空字段 |
| GET /all | 资产列表 + totalAsset/totalLiabilities/netAsset |
| GET /asset | 按 id 查单个 |
| GET /day-statistic | startTime/endTime，逐日资产快照（用于 30/365 天曲线） |

### 账单（/api/bill）

| 端点 | 说明 |
|---|---|
| POST /bill | type（收入/支出/转账/退款）+ 各类型专属字段 + file（可选图片） |
| PATCH /bill | 同上参数可部分更新，退款状态反转时递归处理 |
| DELETE /bill | id、type |
| GET /bill | id、type，单个账单 |
| GET /all | 按 bookId 全部账单（四表合并倒序） |
| GET /all/time | 加 startTime/endTime |
| GET /statistic/category | 分类统计（含占比，支出扣退款） |
| GET /statistic/day | 逐日聚合 |
| GET /statistic/pay | 支出最大最小单笔 |
| GET /statistic/income | 收入最大最小单笔 |
| GET /image | billId、type，返回 base64 图片 |
| DELETE /image | 置空图片 |
| POST /category | 账单侧建分类（bookId、billCategoryName、svg、type） |
| GET /category | 按 bookId 查分类 |
| POST /ai/parse | bookId、type、text，AI 解析返回账单草稿 |

### 账本与分类（/api/book）

| 端点 | 说明 |
|---|---|
| POST /book | title、beginDate（1-28） |
| GET /all | 用户全部账本 |
| GET /book | 按 id 查（内部触发预算重建） |
| GET /pay-month 等 | pay/income/balance/refund 四个月统计，参数 bookId、month |
| GET /bill-category | bookId、type |
| POST /bill-category | 建分类 |
| PUT /bill-category | 改分类（分类侧入口，与账单侧的 POST /category 并存） |
| DELETE /bill-category | 删分类，账单迁移到兜底分类 |
| DELETE /book | 删账本（至少保留一个），级联删账单预算分类 |

### 预算与其他（/api/budget、/api/manage）

| 端点 | 说明 |
|---|---|
| POST /budget | bookId、billCategoryId、limit |
| PATCH /budget | 只允许改 limit，amount/times 被拒绝 |
| GET /budget/all | 按 bookId 查全部分类预算 |
| PATCH /budget/total | 改账本总预算，usedBudget 被拒绝 |
| DELETE /budget | 按 id 删 |
| GET /manage/log | 下载 `${user.dir}/logs/log.log`（jar 部署时路径失效） |

## 错误码与前端约定

### 错误码

| code | 含义 | 触发场景 |
|---|---|---|
| 200 | 成功 | |
| 400 | 冲突 | 用户名/账本标题被占用 |
| 401 | 未授权 | 密码错误、token 无效/过期 |
| 403 | 无权限 | 数据归属校验失败 |
| 404 | 不存在 | 用户不存在等 |
| 422 | 参数/业务校验失败 | 参数错误、退款超额、AI 结果不完整/无关/歧义 |
| 429 | 限流 | AI 每分钟超 5 次 |
| 500 | 服务器错误 | 未知异常、AI 调用失败/超时/格式错、数据库错误 |

HTTP 状态码恒为 200，前端按响应体 code 判断。401 时前端清 token；token 无效和 token 过期跳登录页，密码错误留在登录页。

### 前端请求约定

- 除 /bill/bill 外，所有 post/patch 由 qs 转成 application/x-www-form-urlencoded
- /bill/bill 用 FormData（带图片）
- 超时 600 秒（代码里硬编码，config/common/service.ts 的 60 秒常量未被引用）
- AI 解析请求带 skipErrorMessage，失败不弹全局错误
