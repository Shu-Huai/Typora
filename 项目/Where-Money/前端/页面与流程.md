# 页面与流程

本文说明前端每个页面的职责、调用的接口、状态展示方式和关键交互。

本文不讨论技术实现细节，见 [[前端/前端架构|前端架构]]。接口参数见 [[接口/接口总览|接口总览]]。

源码范围：`views/`、`layouts/common/GlobalContent/`、`components/`。

## 页面结构

```
BasicLayout（侧栏 + 多页签 + 头部）
├── /home    首页统计
├── /bill    账单明细
├── /asset   资产
└── /budget  预算
全局悬浮 "+" 按钮 → AddModal（记一笔：支出/收入/转账三个 tab）
头部：账本切换/新增/删除、日期显示、暗色切换、退出
```

## 记一笔（全局入口）

AddModal 三个 tab 共用结构：金额、备注、账本、账户（底部抽屉选资产）、时间、图片上传、"AI"输入框。

- 支出（Pay）：分类必选 + 分类管理（增删改，IconifyPicker 选图标）
- 收入（Income）：同上
- 转账（Transfer）：转出账户、转入账户、手续费

提交走 `addBillApi`（FormData）。AI 解析成功后回填表单（金额、分类、资产、备注、时间），用户可改。

## 业务页面

### 首页（/home）

- 三张月统计卡片：月结余、月支出、月收入（getBalanceMonthApi/getPayMonthApi/getIncomeMonthApi）
- Naive UI 日历：每日收支 popover（getDayStatisticTimeApi）
- 分类占比环形图 + 收支分布柱状图（ECharts，月/年切换）
- 日均支出/收入、日统计表、分类统计表（getMaxMinPayTimeApi 等）

监听 main store 的 bookId 变化自动刷新。ECharts 手动管理 resize。

### 账单页（/bill）

- 顶部月统计卡片 + 可点击日历（选日过滤、选月刷新）
- 按日分组账单列表（DayBillList/BillItem），桌面右侧详情卡片、移动端底部弹窗
- 详情支持编辑（金额、类别、账户、时间、备注、图片）、退款（仅支出）、删除
- 图片：上传（FormData）、下载（getBillImageApi 拿 base64）、删除；Safari 下 HEIC/HEIF 预览兼容提示

编辑提交 `changeBillApi`（FormData），整页数据在提交成功后重查。

### 资产页（/asset）

- 汇总卡：净资产/总资产/总负债
- 折线图（G2Plot Line）：30 天/365 天净资产，主题色联动
- 分类折叠列表：信用卡显示进度条（已用/额度）、账单日、还款日；其他类型显示余额
- 新增/编辑资产弹窗

### 预算页（/budget）

- 每账本一张卡片（getAllBookApi 遍历）
- 总预算环形进度，可改总额（setBookBudget）
- 分类预算列表：额度、已用、笔数、环形进度；增删改弹窗
- 改预算时 used/times 字段前端不发（后端本来也拒绝）

## 登录注册、状态与边界

### 登录与注册

- 登录：用户名/密码、"记住我"（cookie 明文 7 天）、成功后存 token 跳首页
- 注册：表单 + 使用协议（getProtocolApi 拉 HTML v-html 展示）、成功跳登录
- 两页右上角有暗色切换

### 状态展示约定

- 加载：n-spin（图表、分类区、抽屉）、按钮 loading、路由 loadingBar
- 空态：n-empty（账单图片、预算）、文字"暂无分类"
- 错误：window.$message 统一弹（3 类：error/warning/success），大部分 catch 静默依赖拦截器
- 主题：暗色/浅色 + 6 色主题色，setting 抽屉可调布局模式、页签开关

### 已知边界

- 删账本、删账单没有二次确认弹窗，误点即删
- AI 解析失败不区分具体原因（429/422/500 都静默），用户只知道"解析失败"
- 预算超支只在进度条上体现，无任何提醒
- 图片 100MB 上限前端没有压缩，大图直接传
- 首页图表无导出功能
