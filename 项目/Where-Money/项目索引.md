# 项目索引

本文是 Where-Money（钱去哪儿了）文档体系的入口。说明项目是什么、文档怎么组织、源码在哪里、哪些能力已经落地、哪些还是设计目标。

## 项目概况

Where-Money 是个人财务管理系统。多账本记账：资产（资金、信用卡、充值、投资理财）、四类账单（收入、支出、转账、退款）、分类、月度预算、统计图表，外加一个 AI 自动记账入口——把一句自然语言（"今天食堂午饭 15 元"）解析成结构化的账单草稿。

当前实现是前后端分离的单体应用：

- 后端：Spring Boot 3.2.2，Java 21，端口 5050，源码在 `Z:\JetBrains\IDEA\Where-Money-Backend`
- 前端：Vue 3 + TypeScript + Vite 5 单页应用，开发端口 13140，源码在 `Z:\JetBrains\WebStorm\Where-Money-Frontend`
- 依赖：MySQL、Redis
- 外部服务：OpenAI 兼容大模型接口（当前走 opencode.ai 代理的 deepseek-v4-flash），用于 AI 记账
- 附带的发布形态：前端可构建为普通 Web 静态站，也有 Vercel 部署配置和一个 HarmonyOS 壳工程

技术选型细节见 [[总体设计/系统架构|系统架构]]。

## 关键事实速查

- 后端端口 5050，前端开发端口 13140，前端 dev 直连 `http://localhost:5050/api/`（无 Vite 代理）
- 数据库名 `where_money`（连接串 `createDatabaseIfNotExist=true` 自动建库，schema.sql 自动建表）
- token 存 localStorage key `__TOKEN__`，账本 id 存 `__BOOK_ID__`
- 请求头 `Authorization: Bearer <token>`；除 `/bill/bill` 外的 post/patch 都被前端 qs 转成 form-urlencoded
- 业务码 200 为成功，HTTP 状态码始终 200，code 在响应体里
- 账单图片存 MySQL mediumblob，Redis 缓存前会置空 image 字段
- AI 记账限流每用户每分钟 5 次，调用日志表 `ai_bill_parse_log`
- 账单表按类型拆了 4 张（income_bill / pay_bill / transfer_bill / refund_bill），查询时合并排序
