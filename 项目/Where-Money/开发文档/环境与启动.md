# 环境与启动

本文说明新开发者如何从零把前后端跑起来：环境要求、启动顺序、常见启动错误。

本文不讨论配置项含义，见 [[开发文档/配置与部署|配置与部署]]。

源码范围：后端 `pom.xml`、`src/main/resources/application.properties.example`；前端 `package.json`、`.env.development.example`。

## 环境要求

| 组件 | 版本要求 | 说明 |
|---|---|---|
| JDK | 21（pom 里 java.version=21；编译器插件配的 source/target 23，两者不一致） | 以 21 为准可运行 |
| Maven | 3.8+（仓库自带 mvnw wrapper 3.8.4） | |
| MySQL | 8+ | 连接串带 createDatabaseIfNotExist 自动建库 |
| Redis | 任意稳定版 | 默认 6379 |
| Node.js | ≥18 | 前端 |
| npm | ≥9 | 前端 |

## 启动顺序与后端启动

顺序：MySQL（3306）→ Redis（6379）→ 后端（5050）→ 前端（13140）。

后端：

```bash
# 仓库根目录
cp src/main/resources/application.properties.example src/main/resources/application.properties
# 修改数据源、Redis、token.privateKey、AI 配置
mvn spring-boot:run
```

启动时 `spring.sql.init.mode=always` 自动执行 schema.sql 建表（含动态建索引）。库名 `where_money` 自动创建。

前端：

```bash
npm run env:ensure   # 从 .example 复制生成 .env.development
npm run dev          # 端口 13140
```

前端没有 Vite 代理，`.env.development` 里 `VITE_APP_INTERFACE_URL` 直连后端（默认 http://localhost:5050/api/）。跨域靠后端 CorsConfig 全开放。

## 本地联调

1. `POST /api/user/register` 注册（会同时建默认账本和 43 个默认分类）
2. 登录拿 token，前端登录页走一遍即可
3. 建资产（资金类）后记一笔支出，看余额变化
4. AI 记账：在记一笔弹窗的 AI 输入框贴自然语言，需要本地配置里 AI base-url 和 key 可用

curl 示例见 [[接口/接口总览|接口总览]]。

## 常见启动错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 数据库连接失败 | 连接串/账号/密码错，或 MySQL 未启动 | 检查 application.properties 数据源 |
| Redis 连接失败 | host 错或 Redis 未启动 | 检查 redis 配置（默认 redis.lvshuhuai.cn，本地要改 localhost） |
| 默认分类加载失败 | JsonOperator 按 user.dir 相对路径读 json | 必须在项目根目录启动，打包成 jar 后该路径失效 |
| token 无效 | 请求头格式或密钥不匹配 | 严格 `Authorization: Bearer <token>`，token.privateKey 改了要重新登录 |
| AI 接口 500 | key 失效、base-url 不通、模型名错 | 看 ai_bill_parse_log 表的 error_code 和日志 |
| 前端接口 404 | VITE_APP_INTERFACE_URL 拼错 | 确认以 /api/ 结尾 |
| 端口占用 | 5050/13140 被占 | 改 server.port / vite 端口 |
| 编译报 source 23 | 本机 JDK 低于 23 | pom 编译器插件配了 23，用 JDK 21 时要改成 21 或换 JDK |
