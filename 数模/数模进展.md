**从表格看**

- 最佳组合的 AUC ≈ 0.79–0.80，说明 单靠两维时域统计特征，最多只能做到 80% 左右的判别力。
- 排行靠前的组合都带有 SHAPE, CREST, IMPULSE, KURT → 它们之间互补性比较强。
- RMS / STD 单独贡献不大，但和 CREST/IMPULSE 结合时也能到 0.77 左右。
- 换句话说：你的时域特征里，形状类（Shape factor, Crest, Impulse, Kurtosis） 是核心，均值/方差类（RMS, STD, MEAN）主要是“能量背景”，对分类帮助有限。

**从散点图看**

- KURT vs SHAPE：有一定分离，尤其某一类（Class 0）明显和其他类错开。
- IMPULSE vs SHAPE：Class 1/2/3 有部分聚集，但和 Class 0 还是有重叠。
- CREST vs SHAPE：和上面类似。
- STD vs CREST：Class 0 在右侧形成独立簇，但其他类别仍然重叠。

**直观上，说明**

- 某个类别（大概率是 N 或 OR） 很容易单独分出来。
- 其他几个故障类别在时域统计量空间里差异小 → 仅靠时域特征很难区分。

### PCA

![img](http://public.file.lvshuhuai.cn/images\1758719030543-4.png)

这三张 PCA 图在对比不同特征组合的判别力和可分性：

**左图**（time-only, 8 feats）

- 特征：只用了时域统计特征（RMS, STD, KURT, SKEW 等）。
- 结果：PC1 能解释 45.1% 方差，但各类（B, IR, OR, N）投影到二维后混杂较多，不同类之间分布重叠明显，聚类边界不清晰。
- 说明：单靠时域特征，区分类别能力不足。

**中图**（envelope-only, 6 feats）

- 特征：只用了包络谱谐波能量和峰值特征（BPFI_HER, BPFO_PEAK 等）。
- 结果：PC1/PC2 一共解释了 68.5% 方差（36.6%+31.9%），不同故障类型（尤其 IR, OR）形成了相对明显的簇；类别间的椭圆边界有一定分离。
- 说明：包络谱特征比时域统计特征更能区分不同故障类型。

**右图**（time+envelope, 14 feats）

- 特征：时域 + 包络谱特征联合。
- 结果：PC1/PC2 解释的方差下降到 44.3%（26.8%+17.5%），类别之间仍有分离，但没有中图那样清晰。
- 原因：混合特征后，时域部分的“噪声”掩盖了包络谱特征的优势，导致 PCA 的前两主成分没法集中突出诊断特征。
- 说明：简单拼接可能稀释了判别力，需要特征选择/加权。

**总结**

- 时域特征：可做辅助，但判别力有限。
- 包络谱特征：诊断信息更强，能有效区分类别。
- 两者合并：不一定提升效果，可能需要进一步做特征选择、正则化或监督降维（LDA、t-SNE、UMAP 等）。

**结论**：如果目标是区分故障类别，包络谱特征应作为核心特征；时域特征可以作为补充，但要谨慎融合。

## 第三问——域适应

### 整体结构

1. **读取与特征提取**
    1. 读入源域 `features.csv`（含标签 N/IR/OR/B）。
    2. 对目标域 `./data/target/*.mat` 自动找主通道、**重采样到 12 kHz**、带通 **50–4000 Hz**、按 **2 s 窗/1 s 步长**切片；计算**时域统计**（RMS/STD/MEAN/SKEW/KURT/CREST/…）、**包络谱近似 BPF 特征**（扫描轴频倍数取谐波能量前两名）与**阶次池化**（STFT 对 1×/2×/3×/5×阶能量），并写出 `target_features.csv`。
2. **域不变表征学习（特征解耦）**
    1. 用源/目标在“同一源域标准化器”下的特征训练一个**解耦网络**（两条 MLP：domain 分量 + invariant 分量），包含**对抗域判别（GRL）**、**任务分类头**、**HSIC 互信息最小化**与**正交约束**，得到把任意特征投到**域不变子空间**的映射 `phi_inv`。
3. **统计对齐 + 分类 + 自训练**
    1. 在域不变子空间上对**源域做 CORAL 协方差对齐**（目标域不变），先训一个分类器（默认 **HistGradientBoosting**；可切换 **LogReg**）。
    2. 依据目标域初次预测做**“类条件 CORAL”**：按类挑选高置信目标样本只对齐对应的源域类，再**重训分类器**。
    3. 可选一轮**自训练**：把 **p≥阈值** 的目标样本与伪标签拼回去再训，提升适配。
4. **文件级投票与可视化/产物**
    1. 将目标域切片级概率**按文件名聚合取均值**，得到每个 `A.mat ~ P.mat` 的**文件级标签与置信度**，写出 `./results/target_domain_out/target_predictions.csv`。
    2. 保存模型包（流水线、类别、共用特征列、CORAL 参数等）。
    3. 生成 **t-SNE**（可选 **UMAP**）的**域视角**和**类别视角**散点图 PNG 以检验对齐效果。

#### **左上：t-SNE with CORAL (class view)**

- 横纵坐标是 t-SNE 的低维嵌入（无实际物理意义，只是把高维特征压到二维）。
- 点的颜色表示类别（N=正常，IR=内圈故障，OR=外圈故障，B=滚动体故障）。
- 可以看到不同类别在经过 **CORAL 协方差对齐** 后，已经有比较好的类簇分布。

👉 说明：CORAL 对齐后，各类样本在源+目标混合的特征空间里，类别间仍然能较好区分。

#### **右上：t-SNE with CORAL (domain view)**

- 颜色表示域（蓝色=源域，橙色=目标域）。
- 可以看到，经过 CORAL 后，目标域的点（橙色）和源域点（蓝色）基本分布在相同簇里，而不是完全分开。

👉 说明：CORAL 在一定程度上减少了源/目标分布的差异，使得目标域数据更接近源域特征分布。

#### **左下：t-SNE with CORAL and MI (class view)**

- 在 CORAL 基础上，又加了 **互信息解耦（MI）模块**。
- 类别视角下，簇更细、更分散，说明特征被进一步“拉开”，类内更紧凑、类间更分离。

👉 说明：互信息约束帮助模型学到更加判别性的特征，不同类别之间区分更明显。

#### **右下：t-SNE with CORAL and MI (domain view)**

- 颜色仍然是域。
- 可以看到，目标域点（橙色）和源域点（蓝色）混合得比仅用 CORAL 时更紧密。
- 表示在 MI 约束下，源域和目标域的分布对齐效果更好。

👉 说明：互信息模块不仅增强了类间判别性，还促进了跨域对齐，使源域知识更容易迁移到目标域。

#### 微波辐射数据

- 表头含站点经纬度与海拔、地面要素（SurTem 气温、SurHum 相对湿度、SurPre 气压）、是否降水、云底高、可降水量 **Vint**、液水路径 **Lqint**。
- 后面每一列是高度层（0–10 km，步长 0.025 km）的廓线值。
- 第三列的编号表示变量类型：**11=温度(℃)**、**12=水汽密度(g/m³)**、**13=相对湿度(%)**、**14=液态水含量(g/m³)**。
- 每一行是一时刻的完整剖面，末列 **QCflag** 为质控标记。

#### 待验证方案——时空GCN（ST-GCN）

- **图构建**：将每个高度层作为节点；按垂直相邻（$$k \leftrightarrow k\pm1,\pm$$）连边，并加入物理边权（如按 $$\lvert Ri\rver$$、$$\lvert \partial\theta/\partial z\rver$$、谱宽相似度加权）。
- **节点特征**：$$[\,u,\ v,\ \lvert \vec U\rvert,\ \sigma_w,\ \theta,\ \partial\theta/\partial z,\ S=\sqrt{\left(\frac{\partial u}{\partial z}\right)^2+\left(\frac{\partial v}{\partial z}\right)^2},\ Ri,\ \text{QC}\,\ $$
- **时间维**：采用 TCN/GRU 或 Temporal Attention 处理时间序列，再叠加 GCN（或使用 ChebGCN/GAT）。
- **输出**：逐高度的 $$TI(z$$、$$k(z$$、$$\varepsilon(z$$。

"""
源域诊断（基于 features.csv）
改进点：
1) 文件级“分层+分组”划分，防止切片泄漏并保证各类在 test 出现
2) 两阶段判别（可开关）：One-Class SVM 先筛“正常域”，剩余交给多分类器
3) 文件级 N 阈值（可开关）：p(N) >= 阈值 才判 N
4) 训练时加大 N 权重（可开关）
5) 额外评估：Permutation Importance、GroupKFold、留一载荷/转速（LOLO）、小网格调参（tau & nu）
6) 批量推理：对任意 features.csv 输出文件级预测

def load_dataset(path: str) -> Tuple[pd.DataFrame, List[str]]:
    df = pd.read_csv(path)
    df = df[df[LABEL_COL].isin(["N", "IR", "OR", "B"])].copy()
    df = df.dropna(axis=1, how="all")

    feat_cols = [c for c in df.columns if c not in META_COLS and pd.api.types.is_numeric_dtype(df[c])]
    df[feat_cols] = df[feat_cols].fillna(0.0).astype(np.float32)
    return df, feat_cols


def group_stratified_split(df: pd.DataFrame, test_size=0.2, random_state=2025):
    """文件级分层划分：对 FILE 做多数票 -> stratify，再映射回行索引"""
    file2label = (
        df.groupby(GROUP_COL)[LABEL_COL]
        .agg(lambda s: s.value_counts().idxmax())
        .reset_index()
    )
    files = file2label[GROUP_COL].values
    labels = file2label[LABEL_COL].values

    f_train, f_test = train_test_split(
        files, test_size=test_size, random_state=random_state, stratify=labels
    )
    is_train = df[GROUP_COL].isin(f_train).values
    train_idx = np.where(is_train)[0]
    test_idx = np.where(~is_train)[0]
    return train_idx, test_idx


def build_model(random_state=2025):
    """构建分类器管道"""
    if USE_HGB:
        base_clf = HistGradientBoostingClassifier(
            learning_rate=0.1, max_iter=300, max_depth=None,
            class_weight="balanced", random_state=random_state
        )
        clf = CalibratedClassifierCV(base_clf, cv=3, method=CALIB_METHOD) if USE_CALIBRATION else base_clf
        pipe = Pipeline([
            ("scaler", StandardScaler(with_mean=True, with_std=True)),
            ("clf", clf)
        ])
    else:
        base_clf = LogisticRegression(
            multi_class="multinomial", class_weight="balanced",
            max_iter=2000, solver="lbfgs", random_state=random_state
        )
        clf = CalibratedClassifierCV(base_clf, cv=3, method=CALIB_METHOD) if USE_CALIBRATION else base_clf
        pipe = Pipeline([
            ("scaler", StandardScaler(with_mean=True, with_std=True)),
            ("clf", clf)
        ])
    return pipe


def train_oneclass_normal(X_train: np.ndarray, y_train: np.ndarray) -> Optional[Dict[str, Any]]:
    """训练一类机（正常域），N 太少则返回 None"""
    mask_n = (y_train == 'N')
    if (mask_n.sum() < 5) or (not USE_TWO_STAGE):
        return None
    scaler = StandardScaler()
    oc = OneClassSVM(kernel='rbf', nu=OC_NU, gamma=OC_GAMMA)
    Xn = scaler.fit_transform(X_train[mask_n])
    oc.fit(Xn)
    return {"scaler": scaler, "oc": oc}


def two_stage_predict_proba(pipe: Pipeline,
                            X: np.ndarray,
                            oc_pack: Optional[Dict[str, Any]],
                            classes: np.ndarray) -> Tuple[np.ndarray, np.ndarray]:
    """两阶段概率输出；若未启用或未训练成功则回退单阶段"""
    # 单阶段
    if oc_pack is None:
        prob = pipe.predict_proba(X)
        prob = np.nan_to_num(prob, nan=0.0, posinf=1.0, neginf=0.0)
        return prob, classes

    # 先用一类机筛“正常域”
    Xs = oc_pack["scaler"].transform(X)
    is_normal = (oc_pack["oc"].predict(Xs) == 1)  # 1=正常域，-1=异常域

    prob = pipe.predict_proba(X)
    prob = np.nan_to_num(prob, nan=0.0, posinf=1.0, neginf=0.0)

    # 若分类器不含'N'列，则补一列
    if 'N' not in classes:
        classes = np.array(list(classes) + ['N'])
        prob = np.hstack([prob, np.zeros((prob.shape[0], 1), dtype=prob.dtype)])

    # 提高正常域样本的 N 概率（简单有效）
    n_idx = np.where(classes == 'N')[0][0]
    prob[is_normal, :] *= 0.2
    prob[is_normal, n_idx] = 1.0
    prob = prob / (prob.sum(axis=1, keepdims=True) + 1e-12)
    return prob, classes


def probs_to_labels(probs: np.ndarray, classes: np.ndarray) -> np.ndarray:
    return classes[np.argmax(probs, axis=1)]


def file_level_aggregate(df_sub: pd.DataFrame,
                         probs: np.ndarray,
                         classes: np.ndarray,
                         use_threshold: bool = True,
                         n_threshold: float = 0.65) -> pd.DataFrame:
    """对 FILE 概率均值聚合；可选对 N 加阈值再决策"""
    prob_cols = [f"p_{c}" for c in classes]
    tmp = pd.DataFrame(probs, columns=prob_cols)
    tmp.insert(0, GROUP_COL, df_sub[GROUP_COL].to_numpy())
    tmp.insert(1, LABEL_COL, df_sub[LABEL_COL].to_numpy())

    agg_probs = tmp.groupby(GROUP_COL, as_index=False)[prob_cols].mean()
    y_true_file = (
        tmp.groupby(GROUP_COL)[LABEL_COL]
        .agg(lambda s: s.value_counts().idxmax())
        .reset_index()
        .rename(columns={LABEL_COL: "y_true_file"})
    )
    out = agg_probs.merge(y_true_file, on=GROUP_COL, how="left")

    if use_threshold and ('N' in classes):
        n_col = f"p_{'N'}"
        base_pred = out[prob_cols].idxmax(axis=1).str.replace("p_", "", regex=False)
        use_n = (out[n_col] >= n_threshold)
        base_pred[use_n] = 'N'
        out["y_pred_file"] = base_pred
    else:
        out["y_pred_file"] = out[prob_cols].idxmax(axis=1).str.replace("p_", "", regex=False)

    return out


def safe_auc_ovr(y_true: np.ndarray, y_prob: np.ndarray, classes: np.ndarray) -> float:
    """仅在测试集中实际出现的类上计算 OvR AUC"""
    classes_in_test = np.unique(y_true)
    keep_mask = np.isin(classes, classes_in_test)
    y_prob_keep = y_prob[:, keep_mask]
    cats = pd.Categorical(y_true, categories=classes[keep_mask])
    y_true_bin = pd.get_dummies(cats).values
    if y_true_bin.shape[1] <= 1:
        return float("nan")
    try:
        return float(roc_auc_score(y_true_bin, y_prob_keep, average="macro", multi_class="ovr"))
    except Exception:
        return float("nan")

def show_top_features(pipe: Pipeline, X_val: np.ndarray, y_val: np.ndarray, feat_cols: List[str], n_repeats=10, topk=20):
    r = permutation_importance(pipe, X_val, y_val, n_repeats=n_repeats, random_state=0)
    idx = np.argsort(-r.importances_mean)[:topk]
    pairs = [(feat_cols[i], float(r.importances_mean[i])) for i in idx]
    print(pairs)
    return pairs


def eval_group_kfold(df: pd.DataFrame, feat_cols: List[str],
                     label_col="LABEL", group_col="FILE", n_splits=5,
                     n_threshold=0.65):
    X = df[feat_cols].values
    y = df[label_col].values
    groups = df[group_col].values

    gkf = GroupKFold(n_splits=n_splits)
    seg_f1s, file_f1s = [], []

    for tr, te in gkf.split(X, y, groups):
        Xtr, Xte = X[tr], X[te]
        ytr, yte = y[tr], y[te]
        dfte = df.iloc[te]

        model = build_model(RANDOM_STATE)
        model.fit(Xtr, ytr)
        yprob = model.predict_proba(Xte)
        classes = model.named_steps["clf"].classes_

        ypred = classes[np.argmax(yprob, axis=1)]
        seg_f1s.append(f1_score(yte, ypred, average="macro"))

        fdf = file_level_aggregate(dfte, yprob, classes, use_threshold=True, n_threshold=n_threshold)
        file_f1s.append(f1_score(fdf["y_true_file"], fdf["y_pred_file"], average="macro"))

    print(f"[GroupKFold {n_splits}] seg Macro-F1: {np.mean(seg_f1s):.4f} ± {np.std(seg_f1s):.4f}")
    print(f"[GroupKFold {n_splits}] file Macro-F1: {np.mean(file_f1s):.4f} ± {np.std(file_f1s):.4f}")


def parse_load_from_filename(fn: str) -> int:
    # 例：B028_1.mat 或 N_2_(1750rpm).mat → 载荷 = 1 或 2
    m = re.search(r'_(\d)(?:\D|$)', os.path.basename(fn))
    return int(m.group(1)) if m else -1


def eval_leave_one_load(df: pd.DataFrame, feat_cols: List[str],
                        label_col="LABEL", group_col="FILE",
                        n_threshold=0.65):
    loads = df[group_col].apply(parse_load_from_filename)
    uniq = sorted([u for u in loads.unique() if u >= 0])
    res = []
    for lv in uniq:
        te_mask = (loads == lv)
        if te_mask.sum() < 10:
            continue
        tr = df.loc[~te_mask]
        te = df.loc[te_mask]
        model = build_model(RANDOM_STATE)
        model.fit(tr[feat_cols].values, tr[label_col].values)
        yprob = model.predict_proba(te[feat_cols].values)
        classes = model.named_steps["clf"].classes_

        ypred = classes[np.argmax(yprob, 1)]
        f1_seg = f1_score(te[label_col].values, ypred, average="macro")
        fdf = file_level_aggregate(te, yprob, classes, use_threshold=True, n_threshold=n_threshold)
        f1_file = f1_score(fdf["y_true_file"], fdf["y_pred_file"], average="macro")
        res.append((lv, f1_seg, f1_file))
    print("LOLO results (load, segF1, fileF1):", res)
    return res


def tune_hyperparams_small(df: pd.DataFrame, feat_cols: List[str],
                           tau_grid: List[float], nu_grid: List[float]):
    """简易小网格：文件级 Macro-F1 的均值（GroupKFold）"""
    X = df[feat_cols].values
    y = df["LABEL"].values
    files = df["FILE"].values
    gkf = GroupKFold(n_splits=5)

    best = (0.0, None)
    for tau in tau_grid:
        for nu in nu_grid:
            file_f1s = []
            for tr, te in gkf.split(X, y, files):
                model = build_model(RANDOM_STATE)
                model.fit(X[tr], y[tr])
                yprob = model.predict_proba(X[te])
                classes = model.named_steps["clf"].classes_
                fdf = file_level_aggregate(df.iloc[te], yprob, classes, use_threshold=True, n_threshold=tau)
                file_f1s.append(f1_score(fdf["y_true_file"], fdf["y_pred_file"], average="macro"))
            score = float(np.mean(file_f1s))
            if score > best[0]:
                best = (score, {"tau": tau, "nu": nu})
    print("Tuning best (file Macro-F1, params):", best)
    return best

def predict_files(features_csv, model_pkl="./src_domain_out/model.joblib",
                  out_csv="./src_domain_out/predict_files.csv",
                  n_threshold=0.65):
    """批量推理：读取 features.csv 输出文件级预测"""
    pack = joblib.load(model_pkl)
    pipe = pack["model"]
    classes = np.array(pack["classes"])
    feat_cols = pack["features"]

    df_new = pd.read_csv(features_csv)
    X = df_new[feat_cols].fillna(0.0).values
    yprob = pipe.predict_proba(X)
    fdf = file_level_aggregate(df_new, yprob, classes, use_threshold=True, n_threshold=n_threshold)
    fdf.to_csv(out_csv, index=False, encoding="utf-8")
    print(f"[predict] Saved: {out_csv}")


def main():
    os.makedirs(OUT_DIR, exist_ok=True)

    # 载入数据与划分
    df, feat_cols = load_dataset(FEATURES_CSV)
    X = df[feat_cols].values
    y = df[LABEL_COL].values
    train_idx, test_idx = group_stratified_split(df, TEST_SIZE, RANDOM_STATE)
    X_train, X_test = X[train_idx], X[test_idx]
    y_train, y_test = y[train_idx], y[test_idx]
    df_train, df_test = df.iloc[train_idx].copy(), df.iloc[test_idx].copy()

    # 构建模型
    pipe = build_model(RANDOM_STATE)

    # 训练（HGB 时可选对 N 提高 sample_weight）
    if USE_HGB and USE_SAMPLE_WEIGHT_FOR_N:
        sw = np.ones(len(y_train), dtype=np.float32)
        sw[y_train == 'N'] = N_SAMPLE_WEIGHT
        scaler = pipe.named_steps["scaler"]
        clf = pipe.named_steps["clf"]
        scaler.fit(X_train)
        Xtr_s = scaler.transform(X_train)
        clf.fit(Xtr_s, y_train, sample_weight=sw)
    else:
        pipe.fit(X_train, y_train)

    # 获取类别顺序
    clf = pipe.named_steps["clf"]
    if hasattr(clf, "classes_"):
        classes = clf.classes_
    else:
        est = getattr(clf, "estimator", clf)
        classes = getattr(est, "classes_", None)
        if classes is None:
            classes = np.unique(y_train)
    classes = np.array(classes)

    # 训练一类机（正常域）
    oc_pack = train_oneclass_normal(X_train, y_train) if USE_TWO_STAGE else None

    # ---------- 切片级评估 ----------
    if USE_TWO_STAGE:
        y_prob_test, classes = two_stage_predict_proba(pipe, X_test, oc_pack, classes)
    else:
        y_prob_test = pipe.predict_proba(X_test)
        y_prob_test = np.nan_to_num(y_prob_test, nan=0.0, posinf=1.0, neginf=0.0)

    y_pred_test = probs_to_labels(y_prob_test, classes)
    acc_seg = accuracy_score(y_test, y_pred_test)
    f1m_seg = f1_score(y_test, y_pred_test, average="macro")
    cm_seg = confusion_matrix(y_test, y_pred_test, labels=classes)
    rpt_seg = classification_report(y_test, y_pred_test, labels=classes, digits=4)
    auc_ovr = safe_auc_ovr(y_test, y_prob_test, classes)

    # ---------- 文件级评估 ----------
    file_pred_df = file_level_aggregate(
        df_test, y_prob_test, classes,
        use_threshold=USE_FILE_N_THRESHOLD, n_threshold=FILE_N_THRESHOLD
    )
    y_true_f = file_pred_df["y_true_file"].values
    y_pred_f = file_pred_df["y_pred_file"].values
    acc_file = accuracy_score(y_true_f, y_pred_f)
    f1m_file = f1_score(y_true_f, y_pred_f, average="macro")
    cm_file = confusion_matrix(y_true_f, y_pred_f, labels=classes)
    rpt_file = classification_report(y_true_f, y_pred_f, labels=classes, digits=4)

    # ---------- 保存 ----------
    np.savetxt(os.path.join(OUT_DIR, "confusion_matrix_segment.csv"), cm_seg, fmt="%d", delimiter=",")
    np.savetxt(os.path.join(OUT_DIR, "confusion_matrix_file.csv"), cm_file, fmt="%d", delimiter=",")
    file_pred_df.to_csv(os.path.join(OUT_DIR, "file_level_predictions.csv"), index=False, encoding="utf-8")

    joblib.dump({
        "model": pipe,
        "classes": classes.tolist(),
        "features": feat_cols,
        "config": {
            "USE_HGB": USE_HGB,
            "USE_CALIBRATION": USE_CALIBRATION,
            "CALIB_METHOD": CALIB_METHOD,
            "USE_TWO_STAGE": USE_TWO_STAGE,
            "USE_FILE_N_THRESHOLD": USE_FILE_N_THRESHOLD,
            "FILE_N_THRESHOLD": FILE_N_THRESHOLD,
            "USE_SAMPLE_WEIGHT_FOR_N": USE_SAMPLE_WEIGHT_FOR_N,
            "N_SAMPLE_WEIGHT": N_SAMPLE_WEIGHT,
            "TEST_SIZE": TEST_SIZE,
            "RANDOM_STATE": RANDOM_STATE
        },
        "one_class_pack": oc_pack  # 可为 None；里边是 scaler + oc 的 dict
    }, os.path.join(OUT_DIR, "model.joblib"))

    with open(os.path.join(OUT_DIR, "metrics.txt"), "w", encoding="utf-8") as f:
        f.write("== Segment-level ==\n")
