## HistoGPT

### 数据

#### 模型训练

HistoGPT 模型的训练数据来自德国慕尼黑工业大学皮肤科的临床数据，包括：

- **15,129 张全切片图像（Whole Slide Images, WSI）**
- 来自 **6705 位皮肤病患者**
- 病理报告

论文中给出了这个数据集的一部分：[marr-peng-lab/histogpt-dataset · Datasets at Hugging Face](https://huggingface.co/datasets/marr-peng-lab/histogpt-dataset)

在链接中有慕尼黑数据集的 100 例和明斯特数据集的 50 例，且不包含病理报告。论文中使用这两个数据集分别用来做盲法研究和临床评估。

慕尼黑数据集的格式是 `czi`，明斯特数据集的格式是 `ndpi`。

#### 预训练

论文中提到，HistoGPT 是一个模型系列，具有三种参数量的配置（小、中、大），对于每一种配置，有一个视觉模块和一个语言模块。

视觉模块对于中小型的模型，基于贴片编码器 CTransPath，对于大模型，使用 UNI。

- CTransPath 是一个轻量级（3000 万参数）的 Swin Transformer，训练于 TCGA 和 PAIP 的 32000 多张病理图像，分辨率为每像素 1 微米，采用语义引导的对比学习。
- UNI 是一个更大的 Vision Transformer（3 亿参数），在 22 种组织类型的 10 万多张图像上训练，分辨率为 0.5 微米，使用自蒸馏和遮挡重建方法训练。

论文中的语言模块使用 BioGPT，一个基于 Transformer 的自回归生成模型 GPT-3 的解码器架构，对来自 PubMed 的 1500 万篇生物医学文章进行了训练，词汇量为 42,384。

这些都是预训练好的。

```python
# get text prompt and image features
import h5py
from transformers import BioGptTokenizer

tokenizer = BioGptTokenizer.from_pretrained("microsoft/biogpt-large")

prompt = 'Final diagnosis:'
prompt = torch.tensor(tokenizer.encode(prompt)).unsqueeze(0).to(device)

with h5py.File('./content/save_folder/h5_files/256px_ctranspath_0.0mpp_4.0xdown_normal/2023-03-06 23.51.44.h5',
               'r') as f:
    features = f['feats'][:]
    features = torch.tensor(features).unsqueeze(0).to(device)
    
# generate text autoregressively
from histogpt.helpers.inference import generate

output = generate(
    model=histogpt,
    prompt=prompt,
    image=features,
    length=256,
    top_k=40,
    top_p=0.95,
    temp=0.7,
    device=device
)

decoded = tokenizer.decode(output[0, 1:])

print(decoded)
```

## HIPT

来自 Scaling Vision Transformers to Gigapixel Images via Hierarchical Self-Supervised Learning

通过分层自监督学习将视觉 Transformer 扩展到十亿像素图像

**作者**：Chen et al., 2022

**会议**：CVPR 2022
**论文链接**：[Paper](https://arxiv.org/abs/2206.02679)

**代码**：[GitHub](https://github.com/mahmoodlab/HIPT)

### 背景

- Whole Slide Images (WSIs) 在医学病理中广泛使用，分辨率极高（可达 150,000×150,000）。
- 当前主流方法如 ViT 仅使用 256×256 patch，缺乏对**宏观结构**的理解。
- 目标：让 Vision Transformer 能够处理 **gigapixel 图像**，捕捉**细胞到组织到整片的层次信息**。

### 主要贡献

#### 提出 HIPT 架构（Hierarchical Image Pyramid Transformer）

模仿 NLP 分层建模思想，构建 3 层 ViT：

- **ViT256-16**：处理 256×256 patch（cell-level）
- **ViT4096-256**：处理 4096×4096 区域（region-level）
- **ViTWSI-4096**：处理整个 slide（slide-level）

<img src="http://public.file.lvshuhuai.cn/images\image-20250611002641503.png" alt="image-20250611002641503" style="zoom:50%;" />

#### 逐级自监督预训练（Hierarchical Pretraining）

使用 DINO 框架逐层自监督：

- ViT256-16 用于 patch 表征；
- ViT4096-256 聚合 patch-level 特征；
- ViTWSI 聚合 region-level 表征进行下游任务（分类/生存预测）。

DINO 是一种自监督训练的方法：

- 用一对学生-教师模型（Student & Teacher ViTs）；
- 给同一张图像不同的增强版本（crop、颜色扰动等）；
- 要求学生的输出向量 **模仿教师的输出**；
- 教师模型是学生模型的 **EMA 滑动平均版本**（不反向传播）；
- 最终训练出一个能提取有语义表示的 ViT。

**给模型不同角度/增强版本的同一张图，要求它对两张图得出“相似的语义表示”。**

#### 训练流程

1. 预训练 ViT256-16（细胞级别），token 来自图像 patch（256×256）划分成的 16×16 token
2. 冻住 ViT256-16，预训练 ViT4096-256（区域级别），token 是 ViT256-16 提取的 patch 表征
3. 冻住 ViT256-16 和 ViT4096-256，训练 ViTWSI-4096（全图级别），token 是 ViT4096-256 的输出

#### 在多个任务上超越 SOTA

- TCGA 多个癌种上，HIPT 在：
    - **亚型分类准确率**
    - **生存期预测 c-index**
    - 均优于 CLAM、TransMIL 等方法。

### 数据集

模型使用的数据集是 TCGA，包含 28 种癌症类型的诊断全切片图像。

使用公开可用的 CLAM 库进行组织分割、组织切片和特征提取。
