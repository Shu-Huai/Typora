# Redis

## Redis 是什么？

Redis 是一个高性能的键值对存储数据库，广泛应用于缓存、消息队列等场景。

Redis（REmote DIctionary Server）是一个开源的键值对存储系统，使用 ANSI C 语言编写，遵守 BSD 协议。它支持多种数据结构，如字符串、哈希、列表、集合和有序集合等。Redis 通常被称为数据结构服务器，因为它不仅仅是一个简单的键值存储。
