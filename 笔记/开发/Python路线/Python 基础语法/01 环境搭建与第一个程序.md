# 01 环境搭建与第一个程序

这篇笔记解决三件事：把 Python 装好、跑出第一行代码、知道交互模式怎么用。之后所有笔记里的代码，都假设机器上已经有一个 3.10 以上版本的 Python，Windows 用户可以打开 PowerShell 跟着敲。

## 为什么学 Python

Python 由 Guido van Rossum 在 1989 年底开始设计，1991 年发布第一个版本。三十多年里它从一门教学语言长成了爬虫、数据分析、自动化运维和机器学习的主流工具，TIOBE 和 GitHub 年度统计里常年排在前几名。

![Python 官方标志](http://public.file.lvshuhuai.cn/images\python-logo.png)

![Python 之父 Guido van Rossum](http://public.file.lvshuhuai.cn/images\guido.jpg)

> Beautiful is better than ugly.
> Explicit is better than implicit.
> Simple is better than complex.
>
> 优雅胜于丑陋，明了胜于晦涩，简洁胜于复杂。
>
> —— The Zen of Python(PEP 20，交互模式里输入 `import this` 能看到全文）

选 Python 当第一门语言的理由，通常是这几点：

- 语法接近伪代码，不用先和分号、花括号、类型声明搏斗，注意力能放在“怎么解决问题”上
- 标准库和第三方生态大，爬虫有 requests，数据有 pandas，AI 有 PyTorch，多数需求都有现成轮子
- 社区资料多，报错信息搜一下基本都能找到答案

短板也要说清楚：

- 解释执行，运行速度比 C/Java 慢一到两个数量级，计算密集的任务要靠 C 扩展或者换语言
- GIL（全局解释器锁）让多线程在 CPU 密集任务上使不上劲，真正的并行要走多进程
- 动态类型让大型项目的维护比静态语言费力，靠类型注解和测试来补

## 安装与验证

Windows 上最稳的安装方式是去官网下载安装包：

1. 打开 https://www.python.org/downloads/，下载最新稳定版（写这篇笔记时是 3.12.x，选 3.10 以上都行）
2. 运行安装程序，勾选 **Add python.exe to PATH**，然后点 Install Now
3. 装完在 PowerShell 里验证：

```powershell
python --version
```

```text
Python 3.12.4
```

那个 PATH 勾选框是最常见的坑。不勾选的话，python 命令只存在于安装目录里，命令行找不到：

```text
'python' 不是内部或外部命令，也不是可运行的程序或批处理文件。
```

漏勾了也不用重装，两种补救办法：

- 重新运行安装程序，选 Modify，把 Add python.exe to PATH 勾上
- 手动把 `C:\Users\用户名\AppData\Local\Programs\Python\Python312\` 和它的 Scripts 子目录加进系统环境变量 PATH

嫌官网下载慢的，可以用 winget 一行装好：

```powershell
winget install Python.Python.3.12
```

机器上装了多个版本（比如 3.10 和 3.12 并存）时，用 py 启动器指定版本：

```powershell
py --list        # 列出已安装的版本
py -3.12         # 用 3.12 进入交互模式
py -3.12 demo.py # 用 3.12 运行脚本
```

macOS 用 Homebrew：

```bash
brew install python@3.12
python3 --version
```

Debian/Ubuntu：

```bash
sudo apt update
sudo apt install python3
python3 --version
```

装完之后，常用的验证命令：

| 命令 | 作用 |
| --- | --- |
| `python --version` | 查看默认版本的版本号 |
| `py --list` | 列出机器上装的所有 Python(Windows) |
| `where python` | 查看 python 命令指向哪个文件 |
| `python -c "print(1 + 1)"` | 不写脚本文件，直接执行一行代码 |

## 交互模式与第一个脚本

### 交互模式 REPL

在命令行里直接输入 `python`(Windows 也可以输入 `py`），会进入交互模式，提示符是三个大于号 `>>>`：

![在终端里运行 python](http://public.file.lvshuhuai.cn/images\hello-repl.png)

交互模式的特点是输一行执行一行，适合干这些事：

- 试一段没把握的代码
- 查函数用法：`help(str.split)` 直接看文档
- 当计算器用：`2 ** 100` 马上出结果

第一行代码惯例是 Hello, world：

```python
>>> print("Hello, world!")
Hello, world!
```

`print()` 把括号里的内容输出到屏幕，这是用得最频繁的内置函数，没有之一。

几个交互模式的小技巧：

- 下划线 `_` 保存上一次表达式的结果，接着算很方便
- 退出用 `exit()` 或者 `quit()`，也可以按 Ctrl+Z 加回车(Windows)或 Ctrl+D(macOS/Linux)
- 输错语法时会看到 `SyntaxError` 和一个指出位置的小箭头，这是练习读报错的开始

help() 是内置的文档入口：

```python
>>> help(print)
Help on built-in function print in module builtins:

print(*args, sep=' ', end='\n', file=None, flush=False)
...
```

### 第一个脚本

交互模式适合试代码，真正写程序还是把代码存进 .py 文件里。新建一个 `hello.py`：

```python
# 第一个 Python 脚本
name = input("输入名字：")
print("你好，", name)
```

在 PowerShell 里运行：

```powershell
python hello.py
```

```text
输入名字：Ada
你好， Ada
```

关于中文输出：Python 3 的源码文件默认按 UTF-8 解析，文件本身不会有编码问题；容易出问题的是 Windows 老控制台的代码页还停留在 cp936/GBK，打印中文偶尔乱码。遇到乱码时先试：

```powershell
chcp 65001
python hello.py
```

把控制台切成 UTF-8 代码页再跑，多数情况能解决。

脚本里的注释用 `#` 开头：

```python
# 计算 BMI：体重(kg) / 身高(m) 的平方
bmi = 70 / (1.75 ** 2)
```

需要写多行说明时，习惯上用三引号字符串放在文件或函数开头（本质是个字符串字面量，解释器求值后直接丢掉）：

```python
"""
这个脚本演示 BMI 计算。
身高单位是米，体重单位是千克。
"""
```

注释写“为什么”而不是“是什么”。`# 加 1` 没有信息量，`# 索引从 0 开始，所以减 1` 才有价值。

### 编辑器选择

| 编辑器 | 优点 | 缺点 | 适合人群 |
| --- | --- | --- | --- |
| IDLE | 随 Python 自带，零安装 | 功能少，没有自动补全 | 刚接触，跑跑例子 |
| VS Code | 免费，插件多，Python 扩展体验好 | 配置项多，第一次用要折腾一下 | 绝大多数人 |
| PyCharm | 开箱即用，重构、调试强 | 社区版功能受限，吃内存 | 正经做项目 |

新手推荐 VS Code 装 Python 扩展，或者 PyCharm Community 版，两者都免费。

## 练手题

1. 在交互模式里用 `help()` 查看 `str` 类型有哪些方法，找出两个名字里带 strip 的，猜猜作用，各试一个例子。
2. 写一个脚本 ask.py：问姓名和年龄，打印“xxx 明年 n 岁”，用 `python ask.py` 运行。
3. 用 `py --list` 看机器上装了哪些 Python 版本；如果没有 py 启动器，用 `python --version` 确认版本。
4. 用 `python -c "print(3 ** 10)"` 验证可以不写文件直接执行代码。
5. 故意写一行少半个括号的代码，观察 SyntaxError 长什么样，找到箭头指出的位置。
