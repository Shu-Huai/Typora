# 02 变量与数据类型

程序说到底是在处理数据。变量负责给数据起名字，数据类型决定数据能参与什么运算。这篇讲变量机制和四种基础类型：数字、布尔、None、字符串（字符串在 03 单独展开）。

## 变量是标签不是盒子

很多语言把变量解释成“装着值的盒子”，Python 不是。Python 的变量是一个名字，贴在对象身上：

```python
a = 10
b = a
print(id(a))  # 输出：2243710967312
print(id(b))  # 输出：2243710967312（和 a 完全相同）
```

`id()` 返回对象的内存地址，`a = b` 之后两个名字指向同一个对象，所以地址一样。真正的“盒子”模型里复制一份值应该有两个盒子，Python 里只有两个标签贴着同一个对象。

> Names refer to objects. Names are introduced by name binding operations.
>
> 名字引用对象，赋值就是一次名字绑定。
>
> —— Python 官方文档，《Naming and binding》一节

![变量是贴在对象上的标签](http://public.file.lvshuhuai.cn/images\variable-ref.png)

再看重新赋值：

```python
b = 20
print(a)  # 输出：10
print(b)  # 输出：20
```

`b = 20` 没有“修改”原来的 10，而是把标签 b 撕下来贴到了新对象 20 上。原来的 10 还在，a 仍然指着它。

判断两个名字是否指向同一个对象用 `is`，判断值是否相等用 `==`：

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # 输出：True（内容相同）
print(a is b)  # 输出：False（不是同一个对象）
```

这个标签模型引出一个重要概念：**可变性**。整数、浮点数、字符串、布尔、元组是不可变对象，操作它们只会得到新对象；列表、字典、集合是可变对象，可以原地修改。可变性带来的“共享改连坐”问题在第 6、7 篇再展开。

## 数字、布尔与 None

### 整数 int

Python 3 的整数没有大小上限，算多大的数都行：

```python
print(2 ** 100)  # 输出：1267650600228229401496703205376
```

整数支持其他进制的写法，也支持下划线分隔大数：

```python
print(0b1010)      # 输出：10（二进制）
print(0o17)        # 输出：15（八进制）
print(0x1F)        # 输出：31（十六进制）
print(1_000_000)   # 输出：1000000（下划线只为了好读）
```

### 浮点数 float

浮点数带小数点，科学计数法也能直接写：

```python
print(3.14)      # 输出：3.14
print(1.5e3)     # 输出：1500.0
print(-2.5E-2)   # 输出：-0.025
```

浮点数的精度是入门必踩的坑：

```python
print(0.1 + 0.2)  # 输出：0.30000000000000004
```

0.1 和 0.2 在二进制里是无限循环小数，存储时被截断，加起来就多出来一点尾巴。这不是 Python 的 bug，所有用 IEEE 754 标准的语言都这样。后果有两个：

- 浮点数不要直接用 == 比较，用差的绝对值小于一个很小的数来判断
- 需要精确十进制计算的场景（钱、账目）用 `decimal.Decimal`

`round()` 也有坑，它用的是银行家舍入（四舍六入五取偶）：

```python
print(round(2.5))  # 输出：2
print(round(3.5))  # 输出：4
```

2.5 舍到最近的偶数 2，3.5 舍到 4。和小学学的四舍五入不一样，处理报表数字时注意。

**类型转换**：

`int()` 和 `float()` 可以把字符串转成数字：

```python
print(int("42"))     # 输出：42
print(float("3.14")) # 输出：3.14
print(int(3.99))     # 输出：3（截断，不是四舍五入）
```

字符串长得不像数字时会报错：

```python
int("3.14")
```

```text
ValueError: invalid literal for int() with base 10: '3.14'
```

注意报错信息：整数解析不了带小数点的字符串，先 `float("3.14")` 再 `int()` 才是常见解法。

### 布尔 bool

布尔只有 True 和 False 两个值，判断条件的真假全靠它：

```python
print(10 > 3)   # 输出：True
print(10 < 3)   # 输出：False
```

冷知识：bool 是 int 的子类，True 就是 1，False 就是 0：

```python
print(True + 1)   # 输出：2
print(True == 1)  # 输出：True
```

`bool()` 可以把任何值转成布尔，判定规则见下表：

| 值 | bool() 结果 |
| --- | --- |
| 0、0.0 | False |
| 空字符串 "" | False |
| 空列表 []、空字典 {}、空元组 () | False |
| None | False |
| 其他（非零数字、非空容器） | True |

“空的就是假，非空就是真”这个规则在流程控制里极常用，第 4 篇会反复用到。

### None

None 表示“没有值”，函数没有写 return 时返回的就是它（第 8 篇展开）。None 在内存里只有一个实例，判断时用 `is` 而不是 `==`：

```python
result = None
if result is None:
    print("还没有结果")
```

用 `is None` 是约定俗成的写法，比 `== None` 更快也更明确（`==` 理论上可能被自定义类的 `__eq__` 改写，`is` 不会）。

## 字符串初探与类型转换

字符串用单引号、双引号、三引号都能定义：

```python
s1 = 'hello'
s2 = "world"
s3 = """第一行
第二行"""
print(s3)
```

```text
第一行
第二行
```

三引号的字符串可以跨行。字符串的索引、切片、方法、格式化都在 03 专门讲，这里只把转换关系理清楚。

`str()` 把任意对象转成字符串，`print()` 内部干的就是这件事：

```python
print(str(42))      # 输出：42
print(str(3.14))    # 输出：3.14
print(str([1, 2]))  # 输出：[1, 2]
print(str(True))    # 输出：True
```

常用转换汇总：

| 目标类型 | 函数 | 示例 | 结果 |
| --- | --- | --- | --- |
| 整数 | `int()` | `int("42")` | 42 |
| 浮点数 | `float()` | `float("3.14")` | 3.14 |
| 字符串 | `str()` | `str(42)` | "42" |
| 布尔 | `bool()` | `bool("")` | False |

转换失败时抛 ValueError：

```python
int("abc")
```

```text
ValueError: invalid literal for int() with base 10: 'abc'
```

查看对象的类型用 `type()`，判断类型用 `isinstance()`：

```python
print(type(42))        # 输出：<class 'int'>
print(type("42"))      # 输出：<class 'str'>
print(isinstance(42, int))                  # 输出：True
print(isinstance(42, (int, float)))         # 输出：True（第二个参数可以是元组）
```

`type()` 和 `isinstance()` 的区别在继承上：子类对象对 `isinstance` 来说是父类(True)，对 `type` 来说不是。写类型检查优先用 `isinstance`，这是官方文档的建议。

## 踩坑清单

1. 把变量当盒子：`a = b` 之后以为复制了一份，实际两个名字共享一个对象，配合可变对象（列表）就会出“改了 a 结果 b 也变了”的灵异现象。
2. 浮点数直接比大小：`0.1 + 0.2 == 0.3` 是 False，用 `abs(a - b) < 1e-9` 这类写法。
3. `round(2.5)` 结果是 2 不是 3，银行家舍入了解一下。
4. 用 `== None` 判断空值：应该用 `is None`，这是社区约定，`==` 的行为可以被自定义类改写。
5. 把 bool 当独立类型用：True 加 1 等于 2 的副作用在写 `if x is True:` 这类判断时要小心，多数场景直接 `if x:` 就够。
