# 06 列表与元组

列表和元组是 Python 里装数据的两个最基本容器。**列表**(list)可增可删可改，是最常用的数据结构；**元组**(tuple)创建后不能改，用来表达固定搭配的数据。列表用 `[]`，元组用 `()`，两边的细节在这篇一次讲透：创建、索引切片、增删改查、引用与拷贝，最后是元组的全部要点。循环篇里遍历的集合大多是列表，这篇正好接上。

## 列表基础

列表是一组有序元素，元素可以是任意类型，甚至混着放：

```python
nums = [1, 2, 3]
mixed = [1, "two", 3.0, True]
empty = []

print(nums)      # 输出： [1, 2, 3]
print(mixed)     # 输出： [1, 'two', 3.0, True]
print(empty)     # 输出： []
```

创建列表有三种常用姿势。字面量直接写 `[1, 2, 3]`；`list()` 把其他可迭代对象转成列表；`list(range(...))` 一次生成数字序列：

```python
a = [1, 2, 3]
b = list("abc")          # 输出： ['a', 'b', 'c']
c = list(range(4))       # 输出： [0, 1, 2, 3]
d = list()               # 输出： []
```

`list("abc")` 把字符串按字符拆成列表，`list(range(4))` 把 range 展开成列表。空列表用 `[]` 或 `list()` 都行，习惯上直接写 `[]`。元素个数用 `len()` 拿：

```python
print(len([1, 2, 3]))    # 输出： 3
```

还有一招叫**列表推导**(list comprehension)，在方括号里写 for 直接生成列表：

```python
squares = [x ** 2 for x in range(1, 6)]
print(squares)    # 输出： [1, 4, 9, 16, 25]
```

推导式是列表的高频用法，能省掉一大段循环代码，进阶篇单独细讲，这里先记住有这个语法。

### 索引与切片

列表的元素按位置存取，下标从 0 开始：

```python
colors = ["red", "green", "blue"]
print(colors[0])      # 输出： red
print(colors[1])      # 输出： green
print(colors[-1])     # 输出： blue
```

**负索引**从右边倒数，`-1` 是最后一个元素，`-2` 是倒数第二个。下标越界会抛 `IndexError: list index out of range`，这个报错后文还会遇到。

**切片**(slice)用 `start:stop` 一次切出一段，返回一个新列表，原来的列表不动：

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])      # 输出： [1, 2, 3]
print(nums[:3])       # 输出： [0, 1, 2]
print(nums[3:])       # 输出： [3, 4, 5]
print(nums[:])        # 输出： [0, 1, 2, 3, 4, 5]
```

切片和 range 一样是左闭右开，`nums[1:4]` 取下标 1、2、3。冒号左边省掉从 0 开始，右边省掉到末尾，两边都省就是整份拷贝。切片还支持第三个参数步长，`nums[::2]` 隔一个取一个，`nums[::-1]` 倒序，这两个以后用得上，先混个脸熟。

负数也能当下标做切片，`nums[-3:]` 取最后三个元素。切片的头尾超出边界不报错，`nums[2:100]` 切到哪算哪；单下标超出边界才报 IndexError，两者的容错行为不同，这点别记混。

### 乘法初始化的坑

列表乘整数可以快速造出重复元素：

```python
print([0] * 3)          # 输出： [0, 0, 0]
print(["a", "b"] * 2)   # 输出： ['a', 'b', 'a', 'b']
```

但乘法初始化二维列表时有个著名的坑。想造一个 3×3 的矩阵，新手常这么写：

```python
matrix = [[0] * 3] * 3
matrix[0][0] = 9
print(matrix)    # 输出： [[9, 0, 0], [9, 0, 0], [9, 0, 0]]
```

只改了 `matrix[0][0]` 一个位置，三行的第一个元素全变成了 9。原因：`[[0] * 3] * 3` 里的乘法只是把同一个子列表重复了三遍，三行其实是同一个对象。用 `id()` 验证：

```python
m1 = [[0] * 3] * 3
m2 = [[0] * 3 for _ in range(3)]

print(id(m1[0]) == id(m1[1]))    # 输出： True，三行是同一个对象
print(id(m2[0]) == id(m2[1]))    # 输出： False，三行各自独立
```

`id()` 返回对象在内存里的唯一编号，编号相同就是同一个对象。`m1` 的三行编号相同，改一行等于改所有行；`m2` 用推导式生成，每行都是新建的独立列表，各改各的。二维列表的正确姿势是列表推导：`[[0] * 3 for _ in range(3)]`。这个坑的根源在引用机制，第二大节会从根上解释。

### 常用增删改查方法

改单个元素直接按下标赋值：

```python
colors = ["red", "green", "blue"]
colors[1] = "yellow"
print(colors)      # 输出： ['red', 'yellow', 'blue']
```

加元素最常用 `append()`，往末尾追加一个：

```python
nums = [1, 2]
nums.append(3)
print(nums)      # 输出： [1, 2, 3]
```

`extend()` 把另一个列表的元素逐个加进来，append 则是把参数整个当一个元素塞进去：

```python
a = [1, 2]
b = [1, 2]
a.append([3, 4])
b.extend([3, 4])
print(a)      # 输出： [1, 2, [3, 4]]
print(b)      # 输出： [1, 2, 3, 4]
```

append 和 extend 的区别是新人高频面试题。`a.append([3, 4])` 加进去的是列表本身，a 变成三层嵌套；`b.extend([3, 4])` 才把 3 和 4 两个元素逐个并入。`insert()` 在指定位置插入：

```python
nums = [1, 3]
nums.insert(1, 2)
print(nums)      # 输出： [1, 2, 3]
```

`insert(1, 2)` 在下标 1 的位置塞进 2，原下标 1 及之后的元素整体后移。删除有四种写法：

- `remove()` 按值删第一个匹配，找不到抛 ValueError
- `pop()` 按下标删并返回元素，空列表抛 IndexError
- `del` 是语句，按下标删，也能删切片
- `clear()` 清空整个列表

逐个看。`remove()` 删第一个匹配的值，找不到就抛 `ValueError: list.remove(x): x not in list`：

```python
nums = [1, 2, 3, 2]
nums.remove(2)
print(nums)      # 输出： [1, 3, 2],只删了第一个 2
```

`pop()` 按下标删并返回被删元素，不给下标默认删最后一个：

```python
nums = [1, 2, 3]
last = nums.pop()
print(last, nums)      # 输出： 3 [1, 2]

first = nums.pop(0)
print(first, nums)     # 输出： 1 [2]
```

pop 的特点是“删了还拿得到”，适合取出并处理的场景。空列表上 pop 会抛 `IndexError: pop from empty list`。`del` 是语句不是方法，按名字删下标：

```python
nums = [1, 2, 3]
del nums[1]
print(nums)      # 输出： [1, 3]
```

`clear()` 清空整个列表：

```python
nums = [1, 2, 3]
nums.clear()
print(nums)      # 输出： []
```

查有三种：`in` 判断元素在不在，`index()` 返回第一个匹配的下标，`count()` 数出现次数：

```python
nums = [1, 2, 3, 2]
print(2 in nums)       # 输出： True
print(5 in nums)       # 输出： False
print(nums.index(2))   # 输出： 1
print(nums.count(2))   # 输出： 2
```

`index()` 找不到也会抛 ValueError，和 remove 一样，用之前要么先 in 判断，要么套 try。改顺序的方法有 `sort()` 和 `reverse()`。sort 原地排序，列表本身被改变，返回值是 None：

```python
nums = [3, 1, 2]
nums.sort()
print(nums)      # 输出： [1, 2, 3]

words = ["apple", "pear", "kiwi", "banana"]
words.sort(key=len)
print(words)     # 输出： ['pear', 'kiwi', 'apple', 'banana']
```

`key=len` 按字符串长度排序，key 参数接一个函数，元素先经函数加工再比较。`reverse=True` 倒序。sort 原地改、返回 None 这个组合容易踩坑：`sorted_nums = nums.sort()` 拿到的是 None，不是排好的新列表。想要新列表，用内置函数 `sorted()`：

```python
nums = [3, 1, 2]
new = sorted(nums)
print(new)      # 输出： [1, 2, 3]
print(nums)     # 输出： [3, 1, 2],原列表没动
```

sort 和 sorted 的分工记一条：要改原列表用 sort，要保留原列表用 sorted。`reverse()` 把列表原地倒过来：

```python
nums = [1, 2, 3]
nums.reverse()
print(nums)      # 输出： [3, 2, 1]
```

内置函数还有 `min()`、`max()`、`sum()`，对数字列表直接取最小、最大、求和：

```python
nums = [3, 1, 2]
print(min(nums))     # 输出： 1
print(max(nums))     # 输出： 3
print(sum(nums))     # 输出： 6
```

## 引用与拷贝

这节讲列表最容易翻车的机制：**引用**。列表的内存布局如下：

![](http://public.file.lvshuhuai.cn/images\list-layout.png)

列表本身是一个“地址簿”，每个槽位存的是元素对象的地址，元素实际住在内存别处。这张布局图能解释后面所有诡异现象。

赋值语句 `a = b` 不复制数据，只是让两个名字指向同一个列表对象：

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)     # 输出： [1, 2, 3, 4]
```

只对 b 做了 append，a 也跟着变了。`a = b` 之后 a 和 b 是同一个地址簿的两张名片，改谁都是在改同一个列表。用 id 验证：

```python
a = [1, 2, 3]
b = a
print(id(a) == id(b))    # 输出： True
```

两个 id 相同，同一个对象无疑。这套机制和数字、字符串不一样：数字字符串的“赋值后再改”实际是重新绑定新对象，列表是原地改，所以才有这个现象。

想要真正的独立副本，用**浅拷贝**。两种写法等价：`copy()` 方法或切片 `[:]`：

```python
a = [1, 2, 3]
b = a.copy()
c = a[:]
b.append(4)
print(a)     # 输出： [1, 2, 3]
print(b)     # 输出： [1, 2, 3, 4]
print(c)     # 输出： [1, 2, 3]
```

浅拷贝复制了地址簿本身，槽位里的地址没动。这带来一个后果：嵌套列表的内层还是共享的：

```python
a = [[1, 2], [3, 4]]
b = a.copy()
b[0].append(99)
print(a)     # 输出： [[1, 2, 99], [3, 4]]
```

只对 b 动手，a 的内层列表照样变了。浅拷贝只复制外层，内层子列表还是同一个对象，地址簿里第二层槽位存的地址没换。要把嵌套结构整个复制，用 copy 模块的 `deepcopy()`：

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
b[0].append(99)
print(a)     # 输出： [[1, 2], [3, 4]]
print(b)     # 输出： [[1, 2, 99], [3, 4]]
```

**深拷贝**(deep copy)递归复制所有层，内层子列表也各自新建，改 b 完全不影响 a。

> 官方文档的解释：浅拷贝构造一个新的复合对象，并尽量把原对象中各个元素的引用插进去；深拷贝则递归复制内部所有对象。浅拷贝复制一层，深拷贝复制全部。

浅拷贝和深拷贝的取舍：

- 列表只装数字、字符串这类不可变元素，浅拷贝就够
- 列表里套列表，需要完全隔离时用 deepcopy
- deepcopy 有开销，大结构递归复制耗时，别不分场合地滥用

函数参数传列表，同样按引用传递。函数里对参数做原地修改，外面的列表会跟着变：

```python
def add_item(lst, x):
    lst.append(x)

nums = [1, 2]
add_item(nums, 3)
print(nums)     # 输出： [1, 2, 3]
```

函数收到的是列表对象的引用，append 改的是同一个列表。想让函数不污染原列表，要么传副本 `add_item(nums[:], 3)`，要么函数内部先拷贝再改。这个主题函数篇会再展开。

最后一个坑：`+=` 对列表是原地修改，`+` 则生成新列表：

```python
a = [1, 2]
b = a
a = a + [3]
print(a, b)     # 输出： [1, 2, 3] [1, 2]
```

`a = a + [3]` 里 `+` 生成新列表再绑定给 a，b 还指着旧列表，所以 b 没变：

```python
a = [1, 2]
b = a
a += [3]
print(a, b)     # 输出： [1, 2, 3] [1, 2, 3]
```

`a += [3]` 等价于 `a.extend([3])`，原地追加，a 和 b 指的是同一个列表，所以两个都变成 `[1, 2, 3]`。同一行代码，`+` 和 `+=` 对引用的影响完全相反，这是列表引用相关的头号陷阱。对元组则相反，元组不可变，`+=` 是重建新对象，下一节会讲。

## 元组

元组和列表长得像，用圆括号，元素也用逗号分隔：

```python
t = (1, 2, 3)
print(t)          # 输出： (1, 2, 3)
print(t[0])       # 输出： 1
print(len(t))     # 输出： 3
```

元组和列表最核心的区别是**不可变**：元组创建后不能增删改元素：

```python
t = (1, 2, 3)
t[0] = 9    # TypeError: 'tuple' object does not support item assignment
```

赋值、append、remove 这类修改操作对元组统统无效，运行时抛 TypeError。这份报错原文值得记住，看到它就知道在对元组做修改。

单元素元组有个著名语法点：逗号才是元组的标志，括号只是分组：

```python
a = (1)
b = (1,)
print(type(a))     # 输出： <class 'int'>
print(type(b))     # 输出： <class 'tuple'>
```

`(1)` 是带括号的整数 1，type 是 int；`(1,)` 多了个逗号，才是真正的单元素元组。空元组 `()` 是特例，没有歧义。写单元素元组永远加逗号，这个坑坑过无数人。

“不可变”要精确理解：不可变的是元组里的引用关系，不是引用指向的对象。元组里放一个列表，列表本身照样能改：

```python
t = (1, [2, 3])
t[1].append(4)
print(t)     # 输出： (1, [2, 3, 4]）
```

对 `t[1]` 这个列表 append 成功了。元组不允许换槽位里存的东西，`t[1] = [9]` 会抛 TypeError，但槽位里那个列表对象自身的方法不受限制。所以“元组不可变”翻译准确一点：元组的槽位不能重新绑定，槽位里的对象归对象自己管。

### namedtuple

普通元组按下标取值，代码里到处是 `p[0]`、`p[1]`，时间一长就忘了 0 和 1 各代表什么。**namedtuple** 给元组每个字段起名字，按下标和按名字都能取：

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
print(p.x, p.y)         # 输出： 3 4
print(p[0], p[1])       # 输出： 3 4
print(type(p))          # 输出： <class '__main__.Point'>
```

`namedtuple("Point", ["x", "y"])` 创建一个叫 Point 的元组子类，字段是 x 和 y。造出来的 p 不可变，但比裸元组可读性强得多。坐标、日期这类固定字段的数据，namedtuple 是轻量选择。

元组最重要的日常用法是**解包**。交换两个变量的经典写法背后就是元组：

```python
a, b = 10, 20
a, b = b, a
print(a, b)     # 输出： 20 10
```

`a, b = b, a` 的真相：右边 `b, a` 先打包成一个元组 `(20, 10)`，再解包赋值给左边的 a、b。没有临时变量也完成交换，靠的就是元组打包和解包两个动作。解包时用 `*` 收集剩余元素：

```python
first, *rest = [1, 2, 3, 4]
print(first)     # 输出： 1
print(rest)      # 输出： [2, 3, 4]

first, *mid, last = [1, 2, 3, 4]
print(mid)       # 输出： [2, 3]
```

`*rest` 收集头一个以外的所有元素，`*mid` 收集中间段。星号变量拿到的是列表，哪怕剩一个元素也是列表。函数返回多个值，实际返回的就是一个元组：

```python
def get_info():
    return "张三", 18

name, age = get_info()
print(name, age)     # 输出： 张三 18
```

`return "张三", 18` 返回的是元组 `("张三", 18)`，调用处直接解包。函数篇(08)会详细讲参数和返回值，这里先记住多返回值就是元组。元组和列表怎么选，看下面这张表：

| 维度 | 元组 | 列表 |
|---|---|---|
| 可变性 | 不可变，创建后不能增删改 | 可变，随时增删改 |
| 元素类型 | 常用作异构数据，如（“张三”，18) | 常用作同构数据，如成绩列表 |
| 性能 | 略高，结构固定有优化 | 略低，动态扩容 |
| 语义 | 表达固定搭配、多返回值、字典键 | 表达会变化的集合 |
| 常用场景 | 坐标、日期、函数多返回值 | 待办事项、批量数据 |

一句话：数据集合以后还要动，用列表；一组固定搭配的数据，用元组。元组还能当字典的键，列表不能，因为键要求不可变。

## 踩坑清单

1. `[[0] * 3] * 3` 造出来的三行是同一个子列表，改一行全变。正确写法是 `[[0] * 3 for _ in range(3)]`，跑一遍并打印 id 验证。
2. `a.append([3, 4])` 和 `a.extend([3, 4])` 结果完全不同，前者加进去的是列表本身。分别执行看输出。
3. `nums.sort()` 返回 None，`sorted_nums = nums.sort()` 拿不到新列表。要用 `sorted(nums)` 才对，或 sort 后再直接用 nums。
4. 浅拷贝 `a.copy()` 对嵌套列表只复制外层，改内层会连累原列表。用 `[[1, 2], [3, 4]]` 做实验，再用 `copy.deepcopy` 对比。
5. `a = a + [3]` 生成新列表，`a += [3]` 原地修改。先 `b = a` 再分别执行这两种写法，观察 b 有没有变。
