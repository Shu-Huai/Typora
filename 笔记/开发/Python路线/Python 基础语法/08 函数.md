# 08 函数

函数把一段代码打包成有名字的块，用到时按名字调用。上一篇的字典按值排序已经用过 lambda，这一篇把函数的定义、参数、作用域、闭包、装饰器一次讲全。所有例子可以直接跑，Windows 的 PowerShell 里敲 `py` 进交互模式，macOS/Linux 敲 `python3`。

## 定义与调用

`def` 关键字定义函数，函数体缩进四个空格：

```python
def greet(name):
    """打印一句问候语。"""
    print("欢迎，" + name)

greet("张三")     # 输出：欢迎，张三
```

结构是三件套：def 加函数名和参数表，冒号结尾；函数体整体缩进；函数名习惯用小写字母加下划线。Python 从上往下执行，调用必须写在定义之后，反过来会报 `NameError: name 'greet' is not defined`。

函数体第一行的字符串叫**文档字符串**(docstring)，用三重引号书写，`help()` 会把它展示出来：

```python
def add(a, b):
    """返回两个数的和。"""
    return a + b

help(add)
```

`help(add)` 在交互模式里打印出函数名、参数表和 docstring。写 docstring 的习惯值得养成，讲清楚函数做什么、参数是什么、返回什么，几个月后回来看代码也不会抓瞎。

**return** 把结果交还给调用处，函数在 return 处结束。return 不接值、或者整个不写，函数照样返回，值是 None：

```python
def no_return():
    print("这里执行了")

result = no_return()
print(result)    # 输出：None
```

变量篇讲过 None 表示“没有值”。print 和 return 是两回事：print 把内容输出到屏幕给人看，return 把值交给调用者接着用。

return 多个值，实际返回的是一个元组：

```python
def get_info():
    return "张三", 18

info = get_info()
print(info)           # 输出：('张三', 18)
print(type(info))     # 输出：<class 'tuple'>

name, age = get_info()
print(name, age)      # 输出：张三 18
```

`return "张三", 18` 先打包成元组再返回，调用处可以直接解包成两个变量，元组篇讲过这个机制。

### 调用栈与局部变量隔离

函数调用时，Python 在内部维护一个**调用栈**(call stack)。每次调用在栈顶压入一块**栈帧**(stack frame)，放这次调用自己的参数和变量，函数返回时弹出销毁：

![](http://public.file.lvshuhuai.cn/images\call-stack.png)

图里 main 调用 add，add 调用 multiply，后调用的压在栈顶，先返回。每个栈帧里的变量互不干扰，函数里改参数，不影响外面的变量：

```python
def change(x):
    x = x + 1
    print("函数内部：", x)

num = 10
change(num)
print("函数外部：", num)
# 输出：
# 函数内部： 11
# 函数外部： 10
```

change 里 x 变成 11，外面的 num 还是 10。函数内赋值的名字都是**局部变量**，属于自己那层栈帧，函数结束栈帧销毁，变量跟着消失：

```python
def make():
    temp = 99
    return temp

print(make())    # 输出：99
print(temp)      # NameError: name 'temp' is not defined
```

`temp` 只在 make 的栈帧里存在，函数返回后外面拿不到，报错原文是 `NameError: name 'temp' is not defined`。

### 递归

函数自己调用自己叫**递归**(recursion)。阶乘是标准例子：

```python
def factorial(n):
    """返回 n 的阶乘。"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))    # 输出：120
```

factorial(5) 调 factorial(4)，一路调到 factorial(1) 返回 1，再一层层乘回来。递归必须有**基准情形**(base case)负责终止，上面的 `n <= 1` 就是，少写它就无限调下去。

递归深度有上限，默认 1000 层：

```python
def endless(n):
    print(n)
    endless(n - 1)

endless(2000)
# 打印出一长串数字，最后抛：
# RecursionError: maximum recursion depth exceeded while calling a Python object
```

报错原文是 `RecursionError: maximum recursion depth exceeded while calling a Python object`。调用链超过 1000 层就触发。层数不够用可以调 `sys.setrecursionlimit`，但调太大可能耗尽内存。递归适合树、目录遍历这类天然嵌套的结构；普通循环能解决的问题，**能用迭代就别用递归**，迭代省内存，也不碰深度上限。

> 官方文档的态度：递归适合处理树形结构这类天然递归的数据；平铺直叙的重复任务用 for 或 while 更直接，还能避开递归深度限制。

## 参数全解

按顺序传的叫**位置参数**，数量必须对上：

```python
def sub(a, b):
    return a - b

print(sub(5, 3))     # 输出：2
```

少了参数会报 `TypeError: sub() missing 1 required positional argument: 'b'`，多了报 `takes 2 positional arguments but 3 were given`。

按名字传的叫**关键字参数**，顺序随便，可读性更好：

```python
print(sub(b=3, a=5))    # 输出：2
```

位置和关键字可以混用，位置在前、关键字在后：`sub(5, b=3)` 合法，`sub(a=5, 3)` 报语法错误。

**默认参数**给参数设缺省值，调用时省略就用默认：

```python
def greet(name, greeting="欢迎"):
    print(f"{greeting}，{name}")

greet("张三")                       # 输出：欢迎，张三
greet("张三", greeting="早上好")      # 输出：早上好，张三
```

默认参数让调用更省心，库函数大量使用这一招。函数参数形式汇总：

| 形式 | 写法 | 说明 |
|---|---|---|
| 位置参数 | `def f(a, b)` | 按顺序传 |
| 默认参数 | `def f(a, b=2)` | 省略时用默认值 |
| 可变位置 | `def f(*args)` | 收集多余参数成元组 |
| 可变关键字 | `def f(**kwargs)` | 收集关键字参数成字典 |
| 强制关键字 | `def f(*, key)` | `*` 之后必须按名传 |

### 默认参数的坑

默认值只在函数定义时求值一次。写 `def f(lst=[])`，两次调用共用同一个列表，是著名的坑：

```python
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))    # 输出：[1]
print(add_item(2))    # 输出：[1, 2]
print(add_item(3))    # 输出：[1, 2, 3]
```

每次都以为拿到空列表，实际拿到的是同一个列表，越攒越长。原因：`[]` 在函数定义时创建一次，之后每次调用复用的都是这个对象。

惯用解法是默认值用 None，函数体内再新建：

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(add_item(1))    # 输出：[1]
print(add_item(2))    # 输出：[2]
```

每次调用都新建列表，互不干扰。可变类型（列表、字典、集合）都不建议当默认值。

`*args` 收集多余的位置参数成一个元组，`**kwargs` 收集关键字参数成一个字典：

```python
def show(*args, **kwargs):
    print("位置参数：", args)
    print("关键字参数：", kwargs)

show(1, 2, 3, name="张三", age=18)
# 输出：
# 位置参数： (1, 2, 3)
# 关键字参数： {'name': '张三', 'age': 18}
```

args 和 kwargs 只是约定俗成的名字，作用在星号上。星号还能反向用，叫**解包传参**，列表前加一个星号按位置展开，字典前加两个星号按关键字展开：

```python
print(sub(*[5, 3]))            # 输出：2，等价于 sub(5, 3)

params = {"a": 5, "b": 3}
print(sub(**params))           # 输出：2，等价于 sub(a=5, b=3)
```

参数表里放一个单独的 `*`，后面的参数就变成**强制关键字参数**：

```python
def config(host, *, port=80, timeout=5):
    print(host, port, timeout)

config("example.com", port=8080)    # 输出：example.com 8080 5
config("example.com", 8080)
# TypeError: config() takes 1 positional argument but 2 were given
```

强制关键字参数防止调用者把 `8080` 和 `timeout` 的位置搞混。参数表顺序约定：位置参数、默认参数、`*args`、强制关键字参数、`**kwargs`，按这个顺序写，调用规则最不容易出错。

- 默认值避免用可变对象，用 None 兜底。
- 关键字参数让调用意图一目了然，公共 API 多用。
- `*args`、`**kwargs` 用于参数透传，装饰器里最常见。

## 作用域与高阶工具

### LEGB 与 global、nonlocal

名字查找按 LEGB 四层顺序：局部(Local)、闭包(Enclosing)、全局(Global)、内置(Built-in)：

| 层级 | 英文 | 例子 |
|---|---|---|
| 局部 | Local | 当前函数体内的变量 |
| 闭包 | Enclosing | 外层函数的变量 |
| 全局 | Global | 模块顶层的变量 |
| 内置 | Built-in | len、print、range |

```python
x = "global"          # 全局作用域

def outer():
    x = "enclosing"   # 闭包作用域
    def inner():
        x = "local"   # 局部作用域
        print(x)
    inner()

outer()               # 输出：local
```

每层都有 x，就近原则，先命中 local。找不到就一层层往外找，全找不到报 NameError。

函数里读全局变量没问题，赋值就出问题：

```python
count = 0

def add_one():
    count = count + 1

add_one()
# UnboundLocalError: cannot access local variable 'count' where it is not associated with a value
```

报错原文在 Python 3.11 及以后是 `UnboundLocalError: cannot access local variable 'count' where it is not associated with a value`，更早的版本是 `local variable 'count' referenced before assignment`。原因：函数体内一旦出现对 count 的赋值，Python 就把 count 当作局部变量，而局部变量在赋值完成前还没有值。改全局变量必须用 global 声明：

```python
count = 0

def add_one():
    global count
    count = count + 1

add_one()
add_one()
print(count)    # 输出：2
```

global 声明的变量属于全局作用域，函数内外操作同一个。能用参数和返回值解决的，尽量不用 global，全局状态一多，代码就难排查。

**闭包**(closure)是内层函数记住外层函数的变量。计数器是经典例子：

```python
def make_counter():
    count = 0
    def counter():
        nonlocal count
        count += 1
        return count
    return counter

c = make_counter()
print(c())    # 输出：1
print(c())    # 输出：2
print(c())    # 输出：3
```

make_counter 已经返回，count 还活着，因为 counter 记住了它。`nonlocal` 声明“count 是外层函数的变量”，没有这行，`count += 1` 同样报 UnboundLocalError。闭包让函数自带状态，也是装饰器的基础。

**lambda** 是匿名函数，语法 `lambda 参数: 表达式`，只能写一个表达式，不用写 return：

```python
double = lambda x: x * 2
print(double(5))    # 输出：10
```

等价于 `def double(x): return x * 2`。lambda 塞不下多行逻辑，复杂逻辑直接写 def。lambda 最常见的用武之地是给 sorted 当 key：

```python
students = [("张三", 92), ("李四", 85), ("王五", 78)]
students.sort(key=lambda s: s[1], reverse=True)
print(students)
# 输出：[('张三', 92), ('李四', 85), ('王五', 78)]
```

`key=lambda s: s[1]` 按元组第二个元素（成绩）排序，reverse=True 从高到低。

map 和 filter 是函数式风格的批量处理工具：

```python
nums = [1, 2, 3, 4]
print(list(map(lambda x: x * 2, nums)))      # 输出：[2, 4, 6, 8]
print(list(filter(lambda x: x > 2, nums)))   # 输出：[3, 4]
```

同样的效果，列表推导不需要 lambda，多数人觉得更好读：

```python
print([x * 2 for x in nums])           # 输出：[2, 4, 6, 8]
print([x for x in nums if x > 2])      # 输出：[3, 4]
```

推导式读起来像自然语言，风格上更推荐。map 和 filter 搭配已存在的命名函数时仍有位置，比如 `map(str, nums)`。

**装饰器**(decorator)在不改原函数代码的前提下给函数加能力，原理是“函数也是对象，可以接收函数、返回函数”。计时器装饰器：

```python
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        cost = time.perf_counter() - start
        print(f"{func.__name__} 耗时 {cost:.6f} 秒")
        return result
    return wrapper

@timer
def slow_sum(n):
    total = 0
    for i in range(n):
        total += i
    return total

print(slow_sum(1000000))
# 输出类似（耗时因机器而异）：
# slow_sum 耗时 0.041271 秒
# 499999500000
```

`@timer` 等价于 `slow_sum = timer(slow_sum)`，把原函数交给 timer，换回一个包装过的新函数。wrapper 用 `*args, **kwargs` 透传参数，测完时间原样返回结果。装饰器叠加了闭包、函数对象、解包传参三个知识点，能看懂这段，函数篇就过关了。

**类型注解**(type hints)在参数和返回值上标注类型：

```python
def add(a: int, b: int) -> int:
    return a + b

print(add(3, 5))    # 输出：8
```

注解只是给人和工具看的提示，运行时完全不校验，传错类型照样执行，会不会出错取决于代码本身的行为。Python 3.9 起内建容器可以直接写 `list[int]`、`dict[str, int]`，旧版本需要 `from typing import List` 再写 `List[int]`。编辑器靠注解做补全和静态检查，团队项目里能拦住不少低级错误。

> 经验法则：一个函数只做一件事，函数名用动词开头。函数超过二十行就该考虑拆成两个。
