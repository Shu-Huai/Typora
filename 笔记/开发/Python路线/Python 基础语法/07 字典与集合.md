# 07 字典与集合

字典(dict)和集合(set)是 Python 内置的两个哈希容器。列表按下标找元素，字典按键找值，集合保证元素不重复。日常写码里“查名字、记次数、去重复”这三件事，最终大多落到字典和集合上。这篇先讲字典的键值对模型和哈希定位，再讲增删改查与遍历，最后是集合的运算和典型用法。所有例子可以直接跑，Windows 的 PowerShell 里敲 `py` 进交互模式，macOS/Linux 敲 `python3`。

## 字典是什么

字典存的是**键值对**(key-value pair)，一个键对应一个值。键和值之间用冒号连接，键值对之间用逗号分隔，整体包在花括号里：

```python
student = {"name": "张三", "age": 18, "score": 92}
print(student["name"])    # 输出：张三
print(student["age"])     # 输出：18
print(len(student))       # 输出：3
```

`student["name"]` 的意思就是“拿 name 这个键，查它对应的值”。键通常用字符串，值可以是任意类型，数字、列表、另一个字典都行。字典最擅长描述“名字到事物”的对应关系：姓名到成绩、单词到词频、配置项到配置值。

除字面量外，`dict()` 构造函数也能造字典：

```python
a = dict(name="李四", age=20)
b = dict([("x", 1), ("y", 2)])
print(a)    # 输出：{'name': '李四', 'age': 20}
print(b)    # 输出：{'x': 1, 'y': 2}
```

`dict(name="李四", age=20)` 是关键字写法，键不用加引号；`dict([("x", 1), ("y", 2)])` 接收一个键值对列表。两种写法等价，字面量最常见。

### 哈希定位与 O(1) 查找

列表按位置存元素，找一个值要把元素从头比到尾，最坏情况比 N 次，时间复杂度 O(n)。字典不同，内部靠**哈希表**(hash table)实现：键先经过**哈希函数**算出一个整数，由这个整数直接定位存储槽位：

![](http://public.file.lvshuhuai.cn/images\dict-hash.png)

图里 `hash("name")` 算出一个槽位编号，取值时用同一个函数再算一遍，一步直达。所以字典查找跟字典大小无关，时间复杂度 O(1)，一百万条数据查一个键的速度，和只有十条时几乎一样。哈希函数只负责把对象映射成整数，冲突处理等细节由字典内部完成，初学阶段知道“哈希定位置、查找 O(1)”就够用。

> 哈希(hash)把任意长度的数据压缩成固定长度的整数，这个整数叫哈希值。相同对象的哈希值一定相同，字典因此能保证同一个键永远定位到同一个槽位。Python 内置 `hash()` 可以查看哈希值，`hash("name")` 会返回一个整数。

键必须**可哈希**(hashable)，也就是哈希值要稳定。字符串、整数、元组可以当键；列表、字典、集合不行：

```python
d = {}
d["abc"] = "字符串可以当键"
d[100] = "整数也可以"
d[(1, 2)] = "元组也可以"
print(d)
# 输出：{'abc': '字符串可以当键', 100: '整数也可以', (1, 2): '元组也可以'}

d[[1, 2]] = "列表不行"
# TypeError: unhashable type: 'list'
```

报错原文是 `TypeError: unhashable type: 'list'`。原因在可变性：列表内容一变，哈希值就跟着变，字典按旧哈希值找不到原来的条目。元组不可变，哈希值稳定，所以能当键。规则一句话：**可变类型不能当键**，列表、字典、集合都不行。

### 键的规则与插入顺序

键必须唯一，同一个键重复赋值是覆盖，不是并存：

```python
d = {"a": 1, "b": 2, "a": 100}
print(d)         # 输出：{'a': 100, 'b': 2}
print(len(d))    # 输出：2
```

`"a"` 出现两次，最终只保留最后一次赋的值 100，字典长度是 2 而不是 3。值可以随便重复，键不行。

Python 3.7 起字典保证按**插入顺序**存储，先插入的键排在前面，遍历顺序就是插入顺序。3.6 时这只是 CPython 的实现细节，3.7 起写进了语言规范。当前从 python.org 安装的版本都满足这条，旧环境里不要依赖顺序。

字典和列表怎么选，看这张表：

| 维度 | 列表 | 字典 |
|---|---|---|
| 存取方式 | 按下标 | 按键 |
| 查找复杂度 | O(n)，从头比到尾 | O(1)，哈希直接定位 |
| 顺序 | 有固定顺序 | 3.7 起保持插入顺序 |
| 重复元素 | 允许 | 键不允许，值允许 |
| 典型场景 | 排队的数据、批量数据 | 名字到事物的映射 |

一句话：数据排成一行、按下标取，用列表；数据有名字、按名字查，用字典。

## 增删改查与遍历

### 增删改查

按键取值直接写 `d[key]`，键不存在会抛 KeyError：

```python
d = {"name": "张三", "age": 18}
print(d["name"])     # 输出：张三
print(d["city"])     # KeyError: 'city'
```

报错原文是 `KeyError: 'city'`。键在不在，先用 `in` 问一句；或者直接用 `get`，键不存在时返回默认值而不是报错：

```python
d = {"name": "张三", "age": 18}
print("city" in d)            # 输出：False
print(d.get("city"))          # 输出：None
print(d.get("city", "未知"))   # 输出：未知
```

`get(key, 默认值)` 是访问“可能存在也可能不存在”的键的惯用写法。默认值参数省略时返回 None。`setdefault` 比 get 更进一步，键不存在就先写入默认值再返回：

```python
counts = {}
words = ["apple", "banana", "apple"]
for w in words:
    counts.setdefault(w, 0)
    counts[w] += 1
print(counts)    # 输出：{'apple': 2, 'banana': 1}
```

第一次遇到 apple，`setdefault` 写入 0 并返回，接着 `counts["apple"] += 1` 变成 1；第二次遇到 apple 直接加一。词频统计用这一招最省事。

改值直接赋值，加新键也直接赋值。删除用 `del` 或 `pop`：

```python
d = {"a": 1, "b": 2, "c": 3}
d["a"] = 10          # 改值
d["d"] = 4           # 加新键
print(d)             # 输出：{'a': 10, 'b': 2, 'c': 3, 'd': 4}

del d["b"]
print(d)             # 输出：{'a': 10, 'c': 3, 'd': 4}

val = d.pop("c")     # 弹出键 c，返回它的值
print(val)           # 输出：3
print(d)             # 输出：{'a': 10, 'd': 4}
```

`pop` 的返回值就是被删的那个值，删的同时拿回来用。键不存在时 `pop` 同样抛 KeyError，给第二个参数可以兜底，`d.pop("x", 0)` 在键不存在时返回 0。

`popitem` 从 3.7 起弹出**最后插入**的那个键值对，返回一个元组：

```python
d = {"a": 1, "b": 2}
item = d.popitem()
print(item)     # 输出：('b', 2)
print(d)        # 输出：{'a': 1}
```

`update` 批量更新，参数是另一个字典：

```python
d = {"a": 1, "b": 2}
d.update({"b": 20, "c": 3})
print(d)    # 输出：{'a': 1, 'b': 20, 'c': 3}
```

两个字典合并，Python 3.9 起用 `|` 运算符，生成新字典，原字典不动：

```python
d1 = {"a": 1, "b": 2}
d2 = {"b": 20, "c": 3}
merged = d1 | d2
print(merged)    # 输出：{'a': 1, 'b': 20, 'c': 3}
print(d1)        # 输出：{'a': 1, 'b': 2}
```

两边有相同键时右边的值获胜。旧版本写法 `{**d1, **d2}` 效果一样，两个星号把字典拆开再拼进新字典。

`dict.fromkeys` 批量造键，所有键共用同一个默认值对象。默认值是数字、字符串没问题，是可变对象就是坑：

```python
d = dict.fromkeys(["a", "b"], [])
d["a"].append(1)
print(d)    # 输出：{'a': [1], 'b': [1]}
```

键 a 和键 b 的“空列表”是同一个对象，往 a 里塞一个元素，b 也跟着变。需要各自独立的默认值，改用字典推导 `{k: [] for k in ["a", "b"]}`。

> 记忆口诀：取可能没有的键用 `get`，判断键在不在用 `in`，删了还要值用 `pop`，批量合并用 `update` 或 `|`。

### 遍历与字典推导

`for k in d` 默认遍历的是**键**，不是值：

```python
d = {"a": 1, "b": 2, "c": 3}
for k in d:
    print(k, end=" ")    # 输出：a b c
```

遍历值用 `values()`，键值一起遍历用 `items()`：

```python
d = {"a": 1, "b": 2}
for v in d.values():
    print(v, end=" ")    # 输出：1 2

for k, v in d.items():
    print(f"{k} -> {v}")
# 输出：
# a -> 1
# b -> 2
```

`items()` 每次给出一个 `(键, 值)` 元组，`for k, v in d.items()` 直接解包成两个变量，是最常用的遍历姿势。`keys()`、`values()`、`items()` 返回的是**视图对象**，字典一变视图跟着变，内存里不会复制一份数据。

遍历过程中改字典的大小会直接报错：

```python
d = {"a": 1, "b": 2, "c": 3}
for k in d:
    del d[k]
# RuntimeError: dictionary changed size during iteration
```

报错原文是 `RuntimeError: dictionary changed size during iteration`。解法是先把键复制成列表，遍历副本：

```python
d = {"a": 1, "b": 2, "c": 3}
for k in list(d.keys()):
    if d[k] < 3:
        del d[k]
print(d)    # 输出：{'c': 3}
```

`list(d.keys())` 把键复制进一个新列表，遍历副本、删原字典，两不耽误。`list(d)` 也能拿到键的列表，效果一样。改值不报错，只有增删键（改变大小）才报错。

**字典推导**(dict comprehension)和列表推导同款语法，换成花括号加冒号：

```python
squares = {x: x ** 2 for x in range(1, 6)}
print(squares)    # 输出：{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

带条件的推导也常见，比如只保留偶数：

```python
even = {x: x ** 2 for x in range(1, 6) if x % 2 == 0}
print(even)    # 输出：{2: 4, 4: 16}
```

字典本身不能直接排序，按值排序要借 `sorted` 和 lambda：

```python
d = {"apple": 5, "banana": 2, "cherry": 8}
print(sorted(d.items(), key=lambda item: item[1]))
# 输出：[('banana', 2), ('apple', 5), ('cherry', 8)]
```

`d.items()` 是键值对序列，`key=lambda item: item[1]` 表示按每个元组的第二个元素（值）排序，结果是排序好的键值对列表。lambda 的完整用法在函数篇(08)细讲。

## 集合

**集合**(set)是存放不重复元素的无序容器，创建用 `set()` 或花括号字面量。空集合必须写 `set()`，`{}` 是空字典，这是新人的第一坑：

```python
s = {1, 2, 3}
print(s)                 # 输出：{1, 2, 3}

empty_set = set()
empty_dict = {}
print(type(empty_set))   # 输出：<class 'set'>
print(type(empty_dict))  # 输出：<class 'dict'>
```

集合会自动去重，重复元素只留一个：

```python
s = set([1, 2, 2, 3, 3, 3])
print(s)    # 输出：{1, 2, 3}

print(sorted(set("hello")))
# 输出：['e', 'h', 'l', 'o'],两个 l 只剩一个
```

字符串也能直接转集合，按字符拆分并去重。集合内部无序，输出顺序和插入顺序没有关系，需要顺序时用 `sorted()` 排过再输出。

加元素用 `add`，删元素用 `discard` 或 `remove`，区别在元素不存在时的行为：

```python
s = {1, 2}
s.add(3)
print(s)          # 输出：{1, 2, 3}

s.discard(9)      # 不存在也不报错
s.remove(2)       # 存在，正常删除
print(s)          # 输出：{1, 3}

s.remove(9)       # KeyError: 9
```

`remove` 对不存在的元素抛 KeyError，`discard` 静默忽略。集合的元素也必须可哈希，列表不能放进集合。

集合的招牌是数学风格的集合运算，一张表看全：

| 运算符 | 名称 | 含义 | 示例 |
|---|---|---|---|
| `&` | 交集 | 两集合共有的元素 | `{1, 2, 3} & {2, 3, 4}` 得到 `{2, 3}` |
| `\|` | 并集 | 两集合的全部元素 | `{1, 2} \| {3, 4}` 得到 `{1, 2, 3, 4}` |
| `-` | 差集 | 左边有而右边没有 | `{1, 2, 3} - {2}` 得到 `{1, 3}` |
| `^` | 对称差 | 只出现在一边的元素 | `{1, 2} ^ {2, 3}` 得到 `{1, 3}` |
| `<=` | 子集 | 左边是否全部在右边 | `{1} <= {1, 2}` 得到 `True` |

代码验证一遍：

```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)     # 输出：{2, 3}
print(a | b)     # 输出：{1, 2, 3, 4}
print(a - b)     # 输出：{1}
print(a ^ b)     # 输出：{1, 4}
print(a <= b)    # 输出：False
```

集合相等只认元素，不认顺序，`{1, 2, 3} == {3, 2, 1}` 是 True。

`frozenset` 是集合的不可变版本，创建后不能增删元素，可以当字典的键：

```python
fs = frozenset([1, 2, 3])
d = {fs: "冻结集合可以当键"}
print(d)    # 输出：{frozenset({1, 2, 3}): '冻结集合可以当键'}
```

普通集合可变，哈希值不稳定，不能当键；frozenset 不可变，正好补上这个缺口。日常代码里 frozenset 出场不多，知道有这个类型，需要不可变集合时回来查就行。

集合的三个典型用途：

- **去重**：`list(set(data))` 一行去重，代价是顺序会乱。
- **成员判断**：`x in set_obj` 基于哈希，元素多的时候比在列表里找快得多。
- **集合关系**：两个列表的交集、差集、并集，转成集合做运算，再转回列表。

```python
names1 = ["张三", "李四", "王五"]
names2 = ["李四", "王五", "赵六"]

s1, s2 = set(names1), set(names2)
print(sorted(s1 & s2))    # 输出：['李四', '王五'],两班都有的学生
print(sorted(s1 - s2))    # 输出：['张三'],只有一班有
print(sorted(s1 | s2))    # 输出：['张三', '李四', '王五', '赵六'],全体学生
```
