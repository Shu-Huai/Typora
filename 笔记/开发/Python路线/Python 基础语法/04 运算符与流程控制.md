# 04 运算符与流程控制

变量负责存数据，运算符负责处理数据，流程控制决定代码走哪条路。这三样凑齐，就能写出真正干活的程序。这篇的运算符部分有几个反直觉的坑：负数的整除、逻辑运算的返回值、`-2 ** 2` 的结果，都是面试和实际写码的高频雷区，下面一个个拆开讲。例子同样可以直接在交互模式里跑，Windows 用 `py` 进 REPL,macOS/Linux 用 `python3`。

## 运算符

### 算术运算的几个坑

加减乘除之外，Python 还有整除、取余、幂三个运算符，这是最容易出错的组合：

```python
print(7 / 2)        # 输出： 3.5   普通除法，Python 3 里永远是浮点
print(7 // 2)       # 输出： 3     整除
print(7 % 2)        # 输出： 1     取余
print(2 ** 10)      # 输出： 1024  幂运算
```

两个地方要强调。第一，幂运算写 `**`，不是 `^`,`^` 是位运算里的异或，这是从 C 转过来的人最爱犯的错。第二，`/` 在 Python 2 里是整数除法，3 改成了真除法，7/2 从 3 变成 3.5，这是 2 升 3 最著名的行为变化之一，维护老代码时留意。

负数参与整除和取余时，结果经常超出直觉：

```python
print(-7 // 2)      # 输出： -4
print(7 // -2)      # 输出： -4
print(-7 % 2)       # 输出： 1
print(7 % -2)       # 输出： -1
```

`//` 是**向下取整**(floor)，不是向零取整。数学商是 -3.5，向下取整得到 -4，而不是 C/Java 那种 -3。乍看 -7 // 2 等于 -4 像是个 bug，其实是刻意设计，为的是保证 商*除数+余数 恒等于被除数：（-4)*2+1 正好等于 -7。取余结果跟着除数走符号，除数正余数正，除数负余数负。

> 官方文档原文：The / (division) and // (floor division) operators yield the quotient of their arguments. `/` 是普通除法，`//` 是向下取整除法，结果类型跟着操作数走：7 // 2 得 int 的 3,7.0 // 2 得 float 的 3.0。

`**` 有个函数版 `pow`，顺手还有绝对值 `abs`:

```python
print(pow(2, 10))       # 输出： 1024
print(abs(-3.5))        # 输出： 3.5
```

整除和取余有个配套函数 `divmod`，一次拿两个结果：

```python
q, r = divmod(7, 2)
print(q, r)     # 输出： 3 1
```

少见，但碰到需要同时要商和余数的场景，比算两遍快。取余最日常的用法是判断奇偶，`n % 2 == 0` 就是偶数，翻来覆去用。

优先级的大坑在幂运算和负号：

```python
print(-2 ** 2)      # 输出： -4
print((-2) ** 2)    # 输出： 4
```

`**` 的优先级高于一元负号，`-2 ** 2` 被解析成 `-(2 ** 2)`。数学课本上 -2² 就等于 -4,Python 反而和数学一致，和 C 相反。但这种微妙的地方别赌自己记得住，想表达什么就加括号，`(-2) ** 2` 和 `-(2 ** 2)` 一眼分得清。

### 逻辑短路与位运算

比较运算符支持链式写法：

```python
x = 5
print(1 < x < 10)           # 输出： True
print(1 < x and x < 10)     # 输出： True，上面那行的等价写法
```

`1 < x < 10` 是 Python 的语法糖，等价于 `1 < x and x < 10`，中间的 `x` 只求值一次。C 语言里这写法会先算出 `1 < x` 的结果再拿它和 10 比，含义完全不同。Python 专门处理了这种链，不用自己翻译成两个比较。

`and` 和 `or` 有两个特性，一个比一个反直觉。第一，它们返回的不是 True/False，是最后参与判断的**操作数本身**：

```python
print(0 or "默认值")      # 输出： 默认值
print("有值" or "默认值")  # 输出： 有值
print(1 and "yes")       # 输出： yes
print(0 and "no")        # 输出： 0
```

`print(0 or "默认值")` 打印出“默认值”而不是 True，这是新人面试的高频题。利用这个特性给变量设默认值非常顺手：

```python
config_path = user_input or "config.json"
```

但有个坑：0、空串、空列表都是假值，如果 0 是合法输入，这写法就把 0 丢掉了。真需要区分“没传”和“传了 0”，老老实实写 `if x is None:`。

第二，短路求值。左边已经能决定结果，右边根本不执行：

```python
def check():
    print("执行了")
    return True

False and check()       # 什么也不打印，check 没被调用
True or check()         # 什么也不打印
```

依赖短路能写出安全的判断，比如 `if x and x.name == "a"`,x 是空时后面的属性访问不会执行，不会炸。这是 Python 代码里极常见的惯用法，别把它当 bug。

`not` 的优先级低于比较运算符，`not x == y` 实际是 `not (x == y)`:

```python
x = 1
print(not x == 1)       # 输出： False，实际判断的是 not (x == 1)
print(not (x == 1))     # 输出： False
print((not x) == 1)     # 输出： False，(not 1) 是 False,False == 1 是 False
```

想表达“非 x 等于 y”必须写 `(not x) == y`。所有拿不准的表达式，加括号永远是对的。

位运算处理的是二进制位，和逻辑运算是两套东西：

```python
a = 0b1100      # 12
b = 0b1010      # 10
print(bin(a & b))       # 输出： 0b1000    按位与
print(bin(a | b))       # 输出： 0b1110    按位或
print(bin(a ^ b))       # 输出： 0b0110    按位异或
print(bin(~a))          # 输出： -0b1101   按位取反
print(bin(a << 2))      # 输出： 0b110000  左移 2 位
print(bin(a >> 2))      # 输出： 0b11      右移 2 位
```

`&` 两个都是 1 才得 1,`|` 有一个是 1 就得 1,`^` 不同得 1,`~` 全反过来。写网络掩码、权限标志、图像像素时常用。要命的是 `& |` 和 `and or` 长得像但行为完全不同：前者逐位计算返回整数且**不短路**，后者返回操作数且短路。条件判断里误写成 `if a & b:` 不报错，逻辑完全错，这种 bug 查起来非常痛苦。判断句里永远用 `and or`。

### 海象运算符与优先级表

**海象运算符** `:=` 是 Python 3.8 加入的，在表达式里顺便赋值。最合适的场景是 while 循环“先读再判”：

```python
while (line := input("输入(q 退出): ")) != "q":
    print(f"输入内容：{line}")
```

传统写法输入代码要写两遍：

```python
line = input("输入(q 退出): ")
while line != "q":
    print(f"输入内容：{line}")
    line = input("输入(q 退出): ")    # 重复的一行
```

`:=` 因为长得像海象得名。3.8 之前的环境用不了。它好用但有边界，`if (n := len(x)) > 3:` 这种写法事后看不如分两行清楚。海象只建议用在 while 这种确实省事的场景，别当炫技工具。

运算符优先级从高到低，完整表：

| 优先级 | 运算符 | 说明 |
|：---：|------|------|
| 最高 | `**` | 幂 |
| | `-x` `+x` `~x` | 一元负号、正号、按位取反 |
| | `*` `/` `//` `%` | 乘、除、整除、取余 |
| | `+` `-` | 加、减 |
| | `<<` `>>` | 移位 |
| | `&` | 按位与 |
| | `^` | 按位异或 |
| | `\|` | 按位或 |
| | `==` `!=` `<` `<=` `>` `>=` `is` `in` | 比较与成员 |
| | `not x` | 逻辑非 |
| | `and` | 逻辑与 |
| 最低 | `or` | 逻辑或 |

这表不用背，写代码时心里没底就加括号。加括号不花钱，排查优先级 bug 的时间很贵。另外 `=` 不是运算符，是赋值语句，它的优先级比表中所有运算符都低，并且不能出现在表达式里。`a = b = 1` 这种链式赋值是特例，`print(a = 1)` 会报语法错，别和 C 混了。

## if / elif / else

if 是分支结构的入口。Python 靠**缩进**划分代码块，这是语法，不是风格：

```python
score = 85
if score >= 60:
print("及格")
```

```text
  File "<stdin>", line 2
    print("及格")
        ^
IndentationError: expected an indented block
```

`IndentationError: expected an indented block` 的意思：这里应该有一个代码块，但解释器没看到缩进。规范做法是 4 个空格，别用 Tab，更别混用。编辑器里把 Tab 设置成自动展开为空格，能少踩很多坑。

完整的 if-elif-else 结构：

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

要点：`elif` 是 else if 的缩写，想写几个写几个；`else` 可有可无；每个分支后面都必须有冒号，漏了是 `SyntaxError`。条件从上往下依次判断，命中一个分支执行完就跳出整个结构，后面的分支不再看。所以分支顺序要按大小排好，乱序会进错分支，测试还常常测不出来。

分支里暂时不写逻辑，用 `pass` 占位：

```python
if score >= 60:
    pass        # 以后补，现在先空着
else:
    print("不及格")
```

空代码块是语法错误，`pass` 就是合法的“什么都不做”，占位用。

条件判断里常直接用列表、字符串当条件，这是**真值判断**(truthiness)的习惯：

```python
items = []
if items:
    print("有数据")
else:
    print("列表是空的")
```

`if items:` 和 `if len(items) > 0:` 等价，前者是地道写法。Python 里这些值在条件判断时是**假**：

- `None`
- `False`
- `0`、`0.0`
- 空字符串 `""`
- 空列表 `[]`、空元组 `()`、空字典 `{}`、空集合 `set()`

其余都是真，包括负数和非空容器。注意 `if not x:` 会把 0 误判成“没传”，判断参数是否缺省应该用 `if x is None:`，这是新人常踩的坑，0 作为合法值被吞掉，排查起来很耗时。

条件表达式可以一行搞定二选一：

```python
x = 10
label = "大" if x > 5 else "小"
print(label)     # 输出： 大
```

适合给变量赋二选一的值。嵌套两层以上立刻失去可读性，那种情况老实写 if-elif。官方文档里它叫**条件表达式**(conditional expression)，“三元运算符”是习惯叫法。

分支里面可以再套分支，缩进逐层加 4 格：

```python
age = 20
if age >= 18:
    if age >= 60:
        print("老年")
    else:
        print("成年")
else:
    print("未成年")
```

嵌套个两三层还看得过去，再深就抽成函数，不然读代码的人要拿尺子量缩进了。函数那篇会讲怎么抽。

成绩分级是个完整例子，流程图如下：

![](http://public.file.lvshuhuai.cn/images\if-flow.png)

```python
score = float(input("输入成绩: "))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"等级: {grade}")
```

图上 `score >= 60` 是判断菱形，是走左分支，否走右分支，层层嵌套就是整个 elif 链。输入 85 会输出 `等级: B`。`input()` 拿到的是字符串，要先 `float()` 转数字才能比较，忘了转会报 `TypeError: '>=' not supported between instances of 'str' and 'int'`，这个报错后面处理用户输入时经常见，先混个脸熟。

## match 语句(3.10+）

**match** 是 Python 3.10 加入的，类似 C 的 switch 但强得多，官方叫结构模式匹配(structural pattern matching)。3.9 及以下直接 `SyntaxError`，用不了。最基本的多分支常量判断：

```python
command = "start"

match command:
    case "start":
        print("开始")
    case "stop":
        print("停止")
    case _:
        print("未知命令")
```

`case` 后面跟的是**模式**，`_` 是通配符，相当于 if-elif 里的 else，习惯上放最后。放前面会怎样？不报错，但后面的 case 永远匹配不到，变成死代码。

一个分支匹配多个值用 `|`:

```python
match command:
    case "start" | "begin":
        print("开始")
    case "stop" | "end" | "quit":
        print("停止")
    case _:
        print("其他")
```

match 真正强的地方是匹配结构，顺便把变量绑了：

```python
point = (0, 5)

match point:
    case (0, 0):
        print("原点")
    case (0, y):
        print(f"y 轴上的点,y={y}")
    case (x, 0):
        print(f"x 轴上的点,x={x}")
    case (x, y):
        print(f"普通点 ({x}, {y})")
```

`case (0, y)` 里的 `y` 是**绑定变量**，匹配成功自动取值，不用再手动解包。注意顺序：`(0, 0)` 要放最前面，因为它也符合 `(0, y)` 的形状，放后面就永远轮不到。

这里藏着一个大坑：模式里的**裸名字一律是绑定变量**，不是常量引用，变量名全大写也没用：

```python
WIDTH = 100

match 200:
    case WIDTH:
        print(f"WIDTH 匹配,值是 {WIDTH}")   # 输出： WIDTH 匹配，值是 200
```

表面看是在拿 200 和 WIDTH 比较，实际是匹配成功然后把 200 绑给了 WIDTH，原值 100 被盖掉。想匹配常量，要么写字面量，要么用带点号的名字（比如枚举的 `Color.RED`），带点号的才会被当作值来比较。这是 match 最容易翻车的点。

和 C 的 switch 最大的区别：没有穿透。C 里不写 break 会一路往下执行，Python 的 match 命中一个 case 执行完就结束，break 这个概念根本不存在。少一类 bug，从 C 转过来的人可以放心。

什么时候用 match，判断标准如下：

- 分支五六个以上，全是常量比较，比一长串 elif 干净
- 匹配结构化数据，元组、列表、字典的拆解，elif 写起来很费劲
- 就两三个简单分支，老实写 if,match 是杀鸡用牛刀

最后提醒一句，match 匹配的是值的结构，不是类型判断，别指望它替代 `isinstance`，两者的用途不重叠。

## 练手题

1. 输入一个年份，判断是不是闰年。规则：能被 4 整除但不能被 100 整除，或者能被 400 整除。注意判断条件里的优先级，拿不准就加括号。
2. 写一个简单计算器：输入两个数字和一个运算符（+、-、*、/），输出结果。除数为 0 时打印错误提示，程序不能崩。
3. 石头剪刀布：玩家输入 s（剪刀）、j（石头）、b（布），电脑随机出一个，比胜负。Python 3.10+ 用 match 写，旧版本用 if-elif。
4. 输入一个正整数 n，用链式比较判断它是否“除以 2 余 1，且大于 10 且小于 100”。
5. 在交互模式里输入 `-2 ** 2` 看结果，再用括号试 `(-2) ** 2`，解释两者为什么不同。再试试 `not x == 1`,x 取 1 和 0 时结果分别是什么。
