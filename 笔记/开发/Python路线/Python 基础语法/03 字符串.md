# 03 字符串

字符串是 Python 里用得最多的类型，没有之一。读文件、抓网页、拼 SQL、打印日志，最终都落到字符串上。这篇笔记不打算把几十个字符串方法全列出来，只讲实际写代码时反复用的那些，外加几个新人几乎必踩的坑。所有例子都能直接贴进交互模式跑。Windows 上装好官方 Python，在 PowerShell 或 cmd 里敲 `py` 就能进 REPL，看到 `>>>` 提示符；macOS/Linux 上一般是敲 `python3`。

## 定义与转义

单引号和双引号在 Python 里完全等价，选哪个是风格问题。常见习惯是普通文本用单引号，文本里含单引号时换双引号，两种都含就转义。

```python
s1 = 'hello'
s2 = "hello"                      # 和 s1 一模一样
s3 = "It's fine"                  # 双引号包住，里面的单引号不用转义
s4 = 'He said "hi"'               # 反过来也行
s5 = 'It\'s fine, he said "hi"'   # 两种都有，只能转义
```

选引号的规则说白了就一条：

- 文本里只有单引号，外层用双引号
- 文本里只有双引号，外层用单引号
- 两种都有，转义，或者干脆用三引号

三引号写多行文本，三个单引号或三个双引号都行：

```python
msg = """第一行
第二行
第三行"""
print(repr(msg))    # 输出： '第一行\n第二行\n第三行'
```

`repr()` 会把换行显示成 `\n`，不然肉眼分不清字符串里到底有没有换行。三引号在函数体里还兼任**文档字符串**(docstring)，这个等讲函数时再说，现在只需要知道多行文本用它。

反斜杠是**转义符**，后面跟不同字母代表不同含义：

```python
print("a\nb")               # \n 换行
print("a\tb")               # \t 制表符
print("C:\\Users\\admin")   # \\ 代表一个真正的反斜杠
```

输出：

```text
a
b
a	b
C:\Users\admin
```

Windows 路径是重灾区。反斜杠在 Python 字符串里是转义符，写出来的路径很可能不是预期中的样子：

```python
path = "C:\Users\admin"
```

```text
  File "<stdin>", line 1
    path = "C:\Users\admin"
              ^
SyntaxError: (unicode error) 'unicodeescape' codec can't decode bytes in position 2-3: truncated \UXXXXXXXX escape
```

报错原因：`\U` 被当成 Unicode 转义的开头，后面没跟满 8 位十六进制，解析器直接炸了。这种属于运气好，报错摆在明面上。更阴的是 `"C:\new"` 这种，`\n` 悄悄变成换行，不报错，路径错了，查半天。

解法是**原始字符串**(raw string)，前面加个 `r`:

```python
path = r"C:\Users\admin"
print(path)     # 输出： C:\Users\admin
```

`r` 前缀让反斜杠失去转义功能，原样保留。写正则表达式时反斜杠满天飞，几乎必用 raw string。一个小限制：原始字符串末尾不能是单个反斜杠，`r"C:\"` 会语法错误，好在路径末尾一般不带这个。

拼接有两种姿势。加号是最直观的：

```python
name = "Ada"
age = 36
print(name + " 今年 " + str(age) + " 岁")   # 输出： Ada 今年 36 岁
```

注意 `age` 要包一层 `str()`，数字和字符串不能直接相加：

```python
print(name + age)
```

```text
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: can only concatenate str (not "int") to str
```

报错原文说得挺清楚：只能拼 str，这里给了 int。看到这个报错，找找哪一边忘了转字符串。

另一种是相邻字面量自动合并，只在写代码时对字面量生效：

```python
s = "hello" " " "world"
print(s)    # 输出： hello world
```

写长字符串时换行拆开，比用 `+` 或反斜杠续行干净：

```python
sql = ("SELECT id, name "
       "FROM users "
       "WHERE age > 18")
print(sql)  # 输出： SELECT id, name FROM users WHERE age > 18
```

注意这只对字面量有效，变量之间不会自动合并，`a b` 这样写是语法错误。再提醒一句，循环里反复用 `+` 拼长串效率很差，每拼一次都建一个新字符串，大批量拼接用 `join`，常用方法那节会讲。

## 索引与切片

字符串是**序列**。序列这个词在 Python 里指一串有先后顺序的东西，每个位置有编号，从 0 开始，负索引从 -1 开始从右往左数。下面这张图是 "Python" 六个字符的完整编号：

![](http://public.file.lvshuhuai.cn/images\string-index.png)

```python
s = "Python"
print(s[0])     # 输出： P
print(s[5])     # 输出： n
print(s[-1])    # 输出： n
print(s[-6])    # 输出： P
```

`len()` 拿长度，注意中文一个字算一个字符：

```python
print(len("Python"))    # 输出： 6
print(len("你好"))       # 输出： 2
```

切片用 `s[起点:终点]`，规则是**左闭右开**：起点算进去，终点不算。上图里 `[0:3]` 高亮的就是 P、y、t 三个字符，下标 3 的那个 h 被挡在外面。

```python
s = "Python"
print(s[0:3])   # 输出： Pyt
print(s[:3])    # 输出： Pyt      省略起点，默认 0
print(s[3:])    # 输出： hon      省略终点，默认到末尾
print(s[:])     # 输出： Python   两头都省，整个复制一份
```

左闭右开的好处就一个：终点减起点正好是切出来的长度，`s[0:3]` 是 3 个字符，`s[2:5]` 也是 3 个。做长度计算时不容易犯迷糊。

单索引越界会直接抛错：

```python
s = "Python"
print(s[6])
```

```text
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: string index out of range
```

**IndexError** 是写索引时最常见的报错，看到 "string index out of range" 就是下标超了，长度 6 的串最大合法下标是 5。切片越界则完全没事：

```python
print(s[2:100])     # 输出： thon   终点超了，自动截到末尾
print(s[10:20])     # 输出： 空串   起点就超了，给个空串
```

这个不对称是故意的：单索引取一个值，取不到就该报错；切片本来就要容忍边界，自动截断比报错省心。写代码时可以反过来利用这点，`s[:50]` 不管原串多短都安全。

第三个参数是步长：

```python
s = "Python"
print(s[::2])       # 输出： Pto     隔一个取一个
print(s[1::2])      # 输出： yhn
print(s[4:1:-1])    # 输出： oht     负步长，从右往左取
print(s[::-1])      # 输出： nohtyP  反转
```

`s[::-1]` 反转字符串是出场率最高的切片写法，一行搞定，面试也爱问。步长为负就是倒着走，所以 `[::-1]` 能把整个串翻过来。

切片返回的是**新对象**，不是原串的引用：

```python
s = "Python"
t = s[:]
print(t == s)   # 输出： True   内容相同
print(t is s)   # 输出： False  但不是同一个对象
```

想改字符串？没法原地改，这是下节要讲的**不可变性**。顺带说一句，比较字符串内容用 `==`，别用 `is`,`is` 比的是对象身份，短字符串的缓存机制会让结果看起来像抽风，这个坑等讲对象时展开。

## 常用方法与格式化

先说最重要的概念：**字符串不可变**(immutable)。所有字符串方法都不会修改原字符串，而是返回一个新串，返回值必须接住：

```python
s = "hello"
s.upper()
print(s)            # 输出： hello，原串纹丝不动
s2 = s.upper()
print(s2)           # 输出： HELLO
```

新人最常见的困惑就是这个：方法明明调了，打印出来没变化，以为方法没生效。不是没生效，是返回值被扔掉了。Python 官方文档的说法贴在这里：

> 官方文档原文：Strings are immutable sequences of Unicode code points.（字符串是由 Unicode 码位构成的不可变序列。）这句话里“不可变”和“序列”两个词，正是这一整篇笔记的两条主线。

常用的字符串方法整理成一张表，覆盖日常 90% 的场景：

| 方法 | 作用 | 示例与结果 |
|------|------|------------|
| `s.split(sep)` | 按分隔符拆成列表 | `"a,b,c".split(",")` → `['a', 'b', 'c']` |
| `sep.join(seq)` | 用分隔符把序列拼成串 | `",".join(['a','b'])` → `'a,b'` |
| `s.strip()` | 去掉两端空白或指定字符 | `" hi ".strip()` → `'hi'` |
| `s.replace(a, b)` | 把 a 替换成 b，可限定次数 | `"aaa".replace("a", "b", 1)` → `'baa'` |
| `s.find(sub)` | 找子串首次出现的位置，找不到返回 -1 | `"abc".find("b")` → `1` |
| `s.startswith(p)` | 是否以 p 开头 | `"abc".startswith("ab")` → `True` |
| `s.endswith(p)` | 是否以 p 结尾 | `"abc".endswith("bc")` → `True` |
| `s.upper()` / `s.lower()` | 转大写 / 转小写 | `"aB".upper()` → `'AB'` |
| `s.count(sub)` | 统计子串出现次数 | `"aaa".count("aa")` → `1` |
| `s.isdigit()` | 是否全是数字字符 | `"123".isdigit()` → `True` |
| `s.isalpha()` | 是否全是字母 | `"abc".isalpha()` → `True` |

方法可以链式调用，前一个的返回值接着调下一个：

```python
print("  Hello World  ".strip().upper())    # 输出： HELLO WORLD
```

下面挑几个最容易出错的细讲。

### 拆分与拼接

`split` 和 `join` 是一对逆操作，一个拆一个拼：

```python
line = "apple,banana,cherry"
parts = line.split(",")
print(parts)                # 输出： ['apple', 'banana', 'cherry']

words = ["I", "love", "Python"]
print(" ".join(words))      # 输出： I love Python
```

注意两个方法的姿势不一样：`split` 是字符串的方法，分隔符传进去；`join` 是分隔符的方法，序列传进去。方向记反是常事。`",".join("abc")` 这种写法其实合法，但结果会出乎意料：把每个字符当元素拼，得到 `'a,b,c'`。

`split` 可以限制切几次，靠第二个参数 `maxsplit`:

```python
line = "apple,banana,cherry"
print(line.split(",", 1))   # 输出： ['apple', 'banana,cherry'] 只切第一刀
```

`split` 不带参数时按任意连续空白切，这是处理“用户输入了一行字”最省事的用法：

```python
text = "hello   world\tpython"
print(text.split())     # 输出： ['hello', 'world', 'python']
```

`join` 要求序列里全是字符串，混进数字会报错：

```python
",".join([1, 2, 3])
```

```text
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: sequence item 0: expected str instance, int found
```

解法是先把每个元素转成字符串，推导式或 `map` 都行：

```python
nums = [1, 2, 3]
print(",".join(str(n) for n in nums))   # 输出： 1,2,3
```

### 查找、判断与清理

`find` 找不到子串不报错，返回 **-1**：

```python
text = "hello world"
print(text.find("world"))   # 输出： 6
print(text.find("xyz"))     # 输出： -1
```

-1 这个返回值是个坑。它和“下标 0 是第一位”混在一起，`if text.find("x")` 判断的是“位置不等于 0”，而找不到时的 -1 是真值，判断结果完全反了。想判断包含关系，用 `in` 直接得多：

```python
if "world" in text:
    print("有这个词")
```

非要位置时再调 `find`。还有个 `index` 方法和 `find` 功能一样，但找不到会抛 `ValueError`，需要异常处理，新手用 `find` 就好。

`strip` 只清两端，中间不动：

```python
s = "  hello world  "
print(s.strip())        # 输出： hello world，中间的空格原样保留
```

想把中间空白也收拾干净，常见做法是 `split()` 配 `join()`:

```python
s = "  hello   world  "
print(" ".join(s.split()))  # 输出： hello world
```

`strip` 还能传参，但传参语义容易误解。`"hello world".strip("held")` 不是去掉子串 "held"，而是把两端所有属于 h、e、l、d 的字符逐个剥掉：

```python
print("hello world".strip("held"))    # 输出： o wor
```

这个传参叫**字符集合**语义，和 `replace` 的子串语义不一样，用之前想清楚。

判断类方法也埋着雷。`isdigit` 判断的是“字符是否都是数字”，小数点、负号都不算：

```python
print("123".isdigit())      # 输出： True
print("3.14".isdigit())     # 输出： False
print("-5".isdigit())       # 输出： False
```

所以别用 `isdigit` 验证用户输入的浮点数，验不过。想严谨地判断“字符串能不能转成数字”，常见做法是直接 `float(s)` 再捕获 `ValueError`，这个等异常处理那篇再写。`count` 也有细节：不数重叠部分，`"aaa".count("aa")` 是 1 不是 2，表里已经标了。

### 旧两派：百分号与 format

把变量塞进字符串，Python 前后有三代写法，按出现顺序捋一遍，老代码里都能遇到。

最老的 `%` 写法脱胎于 C 的 printf:

```python
name = "Ada"
age = 36
print("%s 今年 %d 岁" % (name, age))    # 输出： Ada 今年 36 岁
print("%.2f" % 3.14159)                # 输出： 3.14
```

`%s` 表示字符串，`%d` 整数，`%f` 浮点。这写法在 Python 2 时代是唯一选择，老代码、老库的日志里到处都是，能看懂就行，新代码别写：参数一多，占位符和值对不上号，可读性直线下降。

第二代是 `str.format`,Python 2.6 引入：

```python
print("{} 今年 {} 岁".format(name, age))        # 输出： Ada 今年 36 岁
print("{0} 和 {0} 相同".format("x"))             # 下标可以重复用
print("{n} 今年 {a} 岁".format(n="Ada", a=36))   # 也支持命名参数
print("{:>10}".format("hi"))                    # 右对齐占 10 格
```

花括号里可以写下标、名字、格式说明，比 `%` 灵活不少。现在很多教材还在教它，但 2017 年前后 f-string 普及之后，新代码里它的出现频率逐年下降。

### f-string 实用清单

**f-string**（官方叫 formatted string literal)是 Python 3.6 加入的，字符串前面加个 `f`，花括号里直接写表达式：

```python
name = "Ada"
age = 36
print(f"{name} 今年 {age} 岁")      # 输出： Ada 今年 36 岁
```

写起来最短，读起来最顺，性能也是三种里最好的。Python 3.6 以下会直接 `SyntaxError`，维护老环境（比如 CentOS 7 自带的 2.7、某些老板子上的 3.5)时用不了，但新项目完全可以放心用。

花括号里是完整的表达式，不是只能放变量名：

```python
print(f"明年 {age + 1} 岁")            # 输出： 明年 37 岁
print(f"名字大写: {name.upper()}")      # 输出： 名字大写： ADA
print(f"长度: {len(name)}")            # 输出： 长度： 3
```

调试利器 `f"{x=}"`,Python 3.8 加入，把变量名和值一起打出来：

```python
x = 42
print(f"{x = }")        # 输出： x = 42
```

写调试日志的时候省掉手动拼 "x =“，这个语法在日常调试里用得极多。注意它比 f-string 本体晚两年，3.6、3.7 上会报错，别把版本要求弄混。

格式控制跟在冒号后面，常用的有对齐、宽度、小数位、千分位：

```python
name = "Ada"
print(f"{name:>10}|")       # 右对齐，占 10 格
print(f"{name:<10}|")       # 左对齐
print(f"{name:^10}|")       # 居中
pi = 3.1415926
print(f"{pi:.2f}")          # 输出： 3.14
n = 1234567890
print(f"{n:,}")             # 输出： 1,234,567,890
```

`>` `<` `^` 控制对齐方向，数字是总宽度，`.2f` 是保留两位小数，`,` 是千分位。打印对齐的报告和表格时这几招天天用，练手题里会用到。

最后一个坑，引号冲突。f-string 里面写表达式，表达式里又有字符串，引号很容易打架：

```python
print(f"He said "hi"")
```

```text
  File "<stdin>", line 1
    print(f"He said "hi"")
                      ^
SyntaxError: invalid syntax
```

外层用了双引号，表达式里的双引号把字符串提前截断了。解法很简单，错开引号：

```python
print(f'He said "hi"')      # 输出： He said "hi"
```

外层单引号里面双引号，或者反过来。3.12 起这类报错的信息变得更友好，会明确指向 f-string 的问题位置，但错开引号的习惯什么时候都管用。

## 练手题

1. 用一行代码把 "hello world" 反转成 "dlrow olleh"，不许用循环。
2. 有字符串 "2024-08-13"，用 split 拆开再重组，输出 "13/08/2024"。
3. 统计 "abracadabra" 里字母 a 出现的次数，再用 replace 把 a 全部替换成 o，打印结果。
4. 变量 name = "Bob"、score = 87.5，用 f-string 输出一行 "Bob 的成绩是 87.50"，分数保留两位小数，名字右对齐占 8 格。
5. 在交互模式里执行 s = "hello"、s.upper()、print(s)，解释为什么打印的还是小写。
