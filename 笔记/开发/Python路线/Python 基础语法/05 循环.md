# 05 循环

循环解决的是“同一件事做很多遍”。分支让程序会挑路走，循环让程序能反复执行同一段代码。Python 里只有两种循环：**for 循环**和 **while 循环**，比 C/Java 少了 do-while，语言本身刻意保持精简。

两种循环的分工不同：for 按“集合里还剩几个元素”推进，适合遍历已知范围；while 按“条件还成不成立”推进，适合事先不知道要跑多少轮的场景。大部分循环用 for，while 留给交互输入、等外部事件这类“什么时候结束看情况”的地方。

- for 按元素推进，适合遍历已知范围
- while 按条件推进，适合结束时机不确定的场景

全篇例子可以直接跑。Windows 打开 PowerShell 输入 `py`，macOS/Linux 输入 `python3`，进入交互模式逐行敲，或者存成 `.py` 文件再执行，两种方式结果一样。

## for 循环

for 循环的骨架是 `for 变量 in 可迭代对象`，冒号后面缩进的代码块就是循环体。**可迭代对象**(iterable)是能一个接一个往外吐元素的东西，字符串、列表、元组、range 对象、字典、文件对象都属于这一类。for 每轮从对象里取一个元素绑到循环变量上，元素取完循环结束：

```python
for ch in "abc":
    print(ch)    # 每轮输出一个字符，依次为 a、b、c
```

字符串按字符逐个吐，列表按元素逐个吐：

```python
scores = [88, 95, 72]
for s in scores:
    print(s)    # 每轮输出一个成绩，依次为 88、95、72
```

循环体每执行一遍叫一次迭代。for 的执行流程是：取元素，有就执行循环体，回去再取，取不到就退出：

![](http://public.file.lvshuhuai.cn/images\for-loop.png)

图中箭头形成一个环，取元素、执行循环体、再回去取下一个。对象里的元素耗尽时环断开，程序继续往下走。所以只要可迭代对象是有限的，for 循环天然不会死循环，这和 while 不一样。

### range 的三个参数

for 配合最多的可迭代对象是 **range**。`range(stop)` 从 0 数到 stop 的前一个数。range 支持三种形式，对应一个、两个、三个参数：

```python
for i in range(5):
    print(i, end=" ")    # 输出： 0 1 2 3 4

for i in range(2, 5):
    print(i, end=" ")    # 输出： 2 3 4

for i in range(1, 10, 2):
    print(i, end=" ")    # 输出： 1 3 5 7 9
```

`range(5)` 等价于 `range(0, 5)`，只给一个参数时它当 stop，起点默认 0。step 默认 1，给 2 就是隔一个取一个。range 和切片一样是**左闭右开**：起点包含，终点不包含，`range(2, 5)` 取 2、3、4，5 属于开区间那头，永远轮不到。

step 可以是负数，用来倒着数。前提是 start 大于 stop，否则一个元素都拿不到：

```python
for i in range(5, 0, -1):
    print(i, end=" ")    # 输出： 5 4 3 2 1

print(list(range(5, 0, 1)))    # 输出： []
```

`range(5, 0, 1)` 起点比终点大，step 却正着走，方向对不上，直接是空范围。这是 range 最常见的坑：step 的方向必须和 start、stop 的先后一致。三个参数汇总如下：

| 写法 | 含义 | 举例 | 结果 |
|---|---|---|---|
| `range(stop)` | 从 0 到 stop-1 | `range(3)` | 0、1、2 |
| `range(start, stop)` | 从 start 到 stop-1 | `range(2, 5)` | 2、3、4 |
| `range(start, stop, step)` | 步长 step | `range(5, 0, -1)` | 5、4、3、2、1 |

range 对象很省内存，`range(10 ** 12)` 也不会真的分配一万亿个数字，只是记住 start、stop、step 三个值，迭代时现算。要拿到真正的列表得套 `list()`，下一篇列表会细讲。习惯上 range 的循环变量叫 `i`，嵌套时内层用 `j`、`k`。

### enumerate 与 zip

遍历的同时想要下标，老派写法是 `range(len(...))` 拿下标再反查元素：

```python
colors = ["red", "green", "blue"]
for i in range(len(colors)):
    print(i, colors[i])    # 输出依次为：0 red、1 green、2 blue
```

能跑，但先拿 `i` 再反查 `colors[i]` 多绕一道，而且要求对象支持按下标取值，文件对象这种只能顺序读的就用不了。官方推荐的写法是 **enumerate**，一轮同时给出下标和元素：

```python
for i, color in enumerate(colors):
    print(i, color)    # 输出依次为：0 red、1 green、2 blue
```

`enumerate(colors)` 每轮吐出一个下标和一个元素组成的二元组，循环头部的 `i, color` 把它拆成两个变量，这就是**循环变量解包**，下一小节展开。enumerate 还有 start 参数，下标不从 0 开始：

```python
for i, color in enumerate(colors, start=1):
    print(i, color)    # 输出依次为：1 red、2 green、3 blue
```

**zip** 把多个可迭代对象拉上拉链，同一轮取各自当前位置的元素拼成元组。两个列表按位置配对遍历：

```python
names = ["张三", "李四", "王五"]
scores = [88, 95, 72]

for name, score in zip(names, scores):
    print(name, score)    # 输出依次为：张三 88、李四 95、王五 72
```

两边长度不一样时，zip 按最短的那个截断，多余元素直接忽略，不报错：

```python
for a, b in zip("ab", [1, 2, 3]):
    print(a, b)    # 输出依次为：a 1、b 2
```

字符串 `"ab"` 只有两个元素，第三轮凑不齐就停了。反过来需要按最长序列走，用 `itertools` 模块里的 `zip_longest`，标准库篇再展开。三种遍历需求对应三个工具：

- 只要元素本身，直接 `for` 遍历
- 还要下标，用 `enumerate`
- 要配对多个序列，用 `zip`

### 遍历字典与循环变量解包

字典直接 `for` 遍历，拿到的是键：

```python
info = {"name": "张三", "age": 18}
for k in info:
    print(k)    # 输出依次为：name、age
```

键和值一起拿，用 **items()**：

```python
for k, v in info.items():
    print(k, v)    # 输出依次为：name 张三、age 18
```

`info.items()` 每轮吐一个由键和值组成的二元组，循环头部的 `k, v` 顺势拆开。这个拆解动作就是循环变量解包，只要每轮吐出来的是定长序列，几元都能拆：

```python
pairs = [(1, "a"), (2, "b"), (3, "c")]
for num, letter in pairs:
    print(num, letter)    # 输出依次为：1 a、2 b、3 c
```

只要键或只要值，`keys()` 和 `values()` 也能用，不过直接遍历字典默认就是键。解包的两头数量要严格对齐：每轮吐二元组，头部只写一个变量，抛 `ValueError: too many values to unpack`；变量写多了，抛 `ValueError: not enough values to unpack`。这个报错改头部变量个数就能解决。

## while 与循环控制

for 按元素推进，**while 循环**按条件推进：条件为真就一直转，条件变假才停。骨架是 `while 条件`，冒号后面是循环体，循环体里一般要有更新条件的语句：

```python
n = 0
while n < 3:
    print(n)    # 每轮输出当前 n，依次为 0、1、2
    n += 1
```

`n` 从 0 开始，每轮加 1，到 3 时 `n < 3` 不成立，循环退出。这种用计数器驱动的循环叫计数型循环，三件事缺一不可：计数器初始化、循环体里更新、条件里判断。

忘了更新计数器，条件永远成立，就掉进**死循环**：

```python
n = 0
while n < 3:
    print(n)
    # 循环体里没有 n += 1，条件永远成立，程序卡死在这里
```

这段代码会无限打印 0。打断死循环按 Ctrl+C，解释器抛出键盘中断异常：

```
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
KeyboardInterrupt
```

**KeyboardInterrupt** 是解释器收到 Ctrl+C 后发出的信号，程序随即停止。这不是程序报错，是主动打断的通道，macOS/Linux 同样是 Ctrl+C。写 while 之前先想好三件事齐不齐，尤其是更新语句。

while 的一个惯用法是 `while True` 加 `break` 自己控制出口：

```python
while True:
    cmd = input("> ")
    if cmd == "quit":
        break
    print(f"收到命令：{cmd}")
```

条件写死 True，循环本来会永远转下去，靠循环体里的 break 主动跳出。这种“无限循环加出口”的写法在处理交互输入、等待事件时很常见，比先设置一个退出标志再反复更新它要直白。

> `while True` 加 `break` 是官方文档和各大项目都认可的惯用法。真值判断恒成立，循环什么时候结束完全由循环体内的 break 决定，出口位置一目了然。

while 的完整交互例子是猜数字游戏。`input()` 拿输入，`int()` 转整数，比较大小直到猜中：

```python
import random

target = random.randint(1, 10)
while True:
    guess = int(input("猜一个 1 到 10 的整数："))
    if guess == target:
        print("猜对了！")
        break
    elif guess < target:
        print("小了")
    else:
        print("大了")
```

`input()` 返回的是字符串，必须 `int()` 转成整数才能和数字比较，忘了转会抛 `TypeError: '<' not supported between instances of 'str' and 'int'`，这个报错处理输入时经常见。`random.randint(1, 10)` 随机生成 1 到 10 的目标数，每轮判断大小给提示，猜中 break 结束。

### break、continue 与 else

**break** 立即终止整个循环，跳到循环后面的语句。break 之后的代码本轮不执行，后面的轮次也不会再执行：

```python
for i in range(10):
    if i == 3:
        break
    print(i, end=" ")
print("循环结束")    # 输出： 0 1 2 循环结束
```

**continue** 只跳过本轮剩下的代码，直接进入下一轮，循环本身继续：

```python
for i in range(5):
    if i % 2 == 0:
        continue
    print(i, end=" ")    # 输出： 1 3
```

偶数轮直接 continue，print 没执行；奇数正常打印。两者区别一句话：continue 跳下一轮，break 跳整个循环。

for 和 while 还能带 **else** 子句，语义和 if 的 else 完全不同。循环的 else 只在循环没被 break 打断、自然跑完时才执行：

```python
for i in range(3):
    print(i)
else:
    print("自然跑完")    # 整体输出依次为：0、1、2、自然跑完
```

一旦循环中途 break，else 就被跳过：

```python
for i in range(3):
    if i == 1:
        break
    print(i)    # 输出： 0
else:
    print("自然跑完")
```

这个 else 的名字起得不好，官方文档自己都提醒它和 if 的 else 没关系。当成“没被打断才执行”读就顺了。while-else 同理：

```python
n = 0
while n < 3:
    print(n)
    n += 1
else:
    print("条件不成立，自然退出")    # 整体输出依次为：0、1、2、条件不成立，自然退出
```

> 官方文档的解释是：else 子句在循环没有被 break 提前终止时执行。文档还专门说明，循环的 else 与 if 的 else 无关，与 try 的 else 更接近。

for-else 的经典用途是“找没找到”类问题，典型如判断质数：

```python
n = 29
for i in range(2, n):
    if n % i == 0:
        print(f"{n} 不是质数，能被 {i} 整除")
        break
else:
    print(f"{n} 是质数")    # 输出： 29 是质数
```

从 2 试除到 n-1，找到因子就 break 并下结论，一路没找到说明是质数，走 else。break 和 else 配合得天衣无缝：break 一旦发生，else 必然不执行，两条路各归各。用标志变量也能写，但标志要在循环外声明、循环里更新、循环后判断，三处散开；for-else 把三处压成一处，这是官方推荐的写法。

## 嵌套循环与遍历技巧

循环体里可以再写循环，构成**嵌套循环**。最经典的例子是九九乘法表，外层管行，内层管列：

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i * j}", end="  ")
    print()    # 行末换行；第一行输出 1×1=1，最后一行输出 1×9=9 到 9×9=81 共 9 个式子
```

两个 print 有分工：内层的 print 带 `end="  "`，打印完不换行，改成两个空格；外层每行末尾那个空 print 负责换行。`print()` 的 end 参数默认是换行符 `\n`，改成空格就实现一行内连续输出。嵌套循环的总轮数是内外层相乘，这里 45 轮。层数超过三层就该考虑抽成函数，最内层代码的可读性会乘着下降。

遍历列表的同时修改列表是经典大坑。先看一个看似正常的删除：

```python
nums = [1, 2, 3, 4, 5]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)
print(nums)    # 输出： [1, 3, 5]
```

这个例子凑巧删干净了。换一个列表，bug 立刻露头：

```python
nums = [1, 2, 4, 3, 5]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)
print(nums)    # 输出： [1, 4, 3, 5]
```

4 被漏掉了。原因：for 靠内部下标推进，删掉 2 之后列表收缩，4 挪到 2 原来的位置，但 for 的下标已经往前走，下一轮直接从 3 看起，4 逃过检查。遍历中增删元素，for 的下标和列表的实际位置发生错位，删除、插入都可能跳元素。

两种解法。第一种**倒序遍历**，从后往前删，删除只影响已经检查过的尾部：

```python
nums = [1, 2, 4, 3, 5]
for i in range(len(nums) - 1, -1, -1):
    if nums[i] % 2 == 0:
        del nums[i]
print(nums)    # 输出： [1, 3, 5]
```

第二种遍历副本，for 走的是拷贝，改的是原列表，互不干扰：

```python
nums = [1, 2, 4, 3, 5]
for n in nums[:]:
    if n % 2 == 0:
        nums.remove(n)
print(nums)    # 输出： [1, 3, 5]
```

`nums[:]` 是切片拷贝，下一篇列表展开。筛选类需求最省事的写法是**列表推导**：`[n for n in nums if n % 2 != 0]` 一行完事，同样留到下一篇。

循环里拼字符串，`+=` 累加写法直观，但每次 `+` 都生成新字符串，旧串等着回收，数据量大时明显变慢：

```python
result = ""
for word in ["hello", "world", "python"]:
    result += word + " "
print(result)    # 输出： hello world python
```

更好的做法是往列表里塞，最后用 **join** 一次拼起来：

```python
parts = []
for word in ["hello", "world", "python"]:
    parts.append(word)
print(" ".join(parts))    # 输出： hello world python
```

两段结果相同，数据量大时第二段快得多。记一条结论就够：循环里拼字符串用列表加 join，别用 `+=` 累加。join 是字符串方法，用调用它的分隔符把列表串起来，字符串篇提过。

1. 用双层 for 打印九九乘法表，行末换行、行内不换行，输出和上面的例子一致。再把内层 `range(1, i + 1)` 改成 `range(1, 10)` 跑一遍，观察区别并解释原因。
2. 输出斐波那契数列前 20 项：第 1、2 项都是 1，从第 3 项起每项等于前两项之和。提示：两个变量存前两项，循环里交替更新。
3. 找出 100 到 999 之间的所有水仙花数：各位数字的立方和等于该数本身，例如 153 = 1³ + 5³ + 3³。提示：`for` 加 `range`，循环体内用整除和取余拆出每一位。
4. 写词频统计雏形：给定一句英文，用 `split()` 拆成单词列表，遍历统计每个单词出现次数，最后用 `items()` 打印结果。字典篇会给出更省的写法。
5. 用 for-else 判断输入的正整数是不是质数，再改成 while-else 版本，对比两种循环的写法差异。
