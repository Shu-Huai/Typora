# 11 文件与异常处理

程序运行结束，内存里的数据就没了。想留结果，就要写文件；想处理数据，就要读文件。文件操作会碰到编码、路径、权限各种问题，出错时需要异常处理兜底。这一篇把这两件事放在一起讲。

## 文件的读与写

### 读文件

打开文件用内置函数 open，最基本的用法：

```python
f = open("data.txt", "r", encoding="utf-8")
content = f.read()
f.close()
print(content)
```

`"r"` 是读取模式，encoding 指定编码。读完后调用 close() 关闭文件。不关的话文件句柄一直占着，长时运行的进程会积累一堆句柄，轻则打不开新文件，重则文件删不掉、改不了，直到进程退出才被系统回收。

open 的路径分相对和绝对。相对路径以当前工作目录为基准：

```python
f = open("data.txt")                     # 当前目录下的文件
f = open("data/sub.txt")                 # 当前目录下 data 子目录里的文件
f = open(r"C:\Users\xxx\data.txt")       # 绝对路径，r 前缀防止反斜杠转义
f = open("C:/Users/xxx/data.txt")        # 绝对路径也可以用正斜杠
```

工作目录不等于脚本所在目录。在 PowerShell 里执行 `python C:\proj\main.py` 时，工作目录是当前所在目录，`open("data.txt")` 找的就不是 C:\proj 下的文件。稳妥做法：先用 `print(Path(".").resolve())` 确认工作目录，或者用 `Path(__file__).parent` 拼出脚本所在目录再找文件。

Windows 的编码坑是最常见的报错来源。Windows 上 open 默认按 cp936(GBK)解码，文件是 UTF-8 编码时就乱码或报错：

```python
f = open("data.txt", "r")
print(f.read())
f.close()
```

```text
UnicodeDecodeError: 'gbk' codec can't decode byte 0xad in position 2: illegal multibyte sequence
```

报错意思是「用 GBK 解不出这个字节」。加上 `encoding="utf-8"` 解决：

```python
f = open("data.txt", "r", encoding="utf-8")
```

macOS/Linux 默认编码是 UTF-8，这个问题不常见；Windows 上读写文本文件时 encoding="utf-8" 一律显式写上。

打开模式一览：

| 模式 | 含义 | 文件不存在时 | 文件已存在时 |
| --- | --- | --- | --- |
| r | 只读 | 报 FileNotFoundError | 从头读 |
| w | 写入 | 新建 | 清空重写 |
| a | 追加 | 新建 | 在末尾续写 |
| x | 独占新建 | 新建 | 报 FileExistsError |
| r+ | 读写 | 报 FileNotFoundError | 从头读，可写 |

`b` 可以和上面组合，如 `rb`、`wb`，表示二进制模式，图片、音频、视频都用二进制读。二进制模式不做换行转换，也不做编码解码。

with 语句自动关闭文件，是推荐写法：

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)
```

with 块结束自动调用 close()，块里报错也会关。文件操作一律用 with，close() 可以忘掉。

读文件的方式有四种，各有用途：

- read()：整个文件读成一个大字符串，小文件用
- readline()：读一行，含末尾换行符，只取首行的场景用
- readlines()：读成列表，每个元素是一行，需要随机访问某行时用
- for line in f：逐行迭代，一行只占一行内存，大文件唯一推荐

逐个演示。假设 data.txt 内容两行：「第一行」「第二行」：

```python
with open("data.txt", "r", encoding="utf-8") as f:
    text = f.read()
    print(repr(text))
```

```text
'第一行\n第二行'
```

```python
with open("data.txt", "r", encoding="utf-8") as f:
    line = f.readline()
    print(repr(line))
```

```text
'第一行\n'
```

```python
with open("data.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
    print(lines)
```

```text
['第一行\n', '第二行']
```

```python
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line, end="")
```

```text
第一行
第二行
```

几百 MB 的日志文件用 read() 会占满内存，for line in f 一行行处理，内存占用恒定。

pathlib 提供更现代的写法，Path 对象的 read_text 一行完成读：

```python
from pathlib import Path

text = Path("data.txt").read_text(encoding="utf-8")
print(text)
```

### 写文件

写文件用 `w`、`a`、`x` 三种模式：

```python
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("第一行")
    f.write("第二行")
```

写完打开 out.txt，内容是：

```text
第一行第二行
```

write() 不会自动加换行，两次写入粘在一起。换行要自己写 `\n`：

```python
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")
```

w 是覆盖写：文件已存在时内容清空重写，不想丢数据就检查模式。a 是追加：在末尾接着写，日志场景常用。x 是独占创建：文件已存在直接报错，适合「只生成一次」的场景：

```text
FileExistsError: [Errno 17] File exists: 'out.txt'
```

print 也能写文件，file 参数指定目标：

```python
with open("out.txt", "w", encoding="utf-8") as f:
    print("第一行", file=f)
    print("第二行", file=f)
```

print 默认自带换行，比 write 方便。

换行符有平台差异：Windows 文本文件的行尾是 `\r\n`，Linux/macOS 是 `\n`。Python 写文件时默认做转换：写入 `\n` 在 Windows 上落盘成 `\r\n`，读取时又还原成 `\n`，正常读写不用管。需要原样读写时用 newline 参数：

```python
with open("out.txt", "w", encoding="utf-8", newline="") as f:
    f.write("a\nb\n")
```

`newline=""` 关闭换行转换，`\n` 落盘就是 `\n`。二进制模式(rb/wb)不做任何转换。

写文件有缓冲。write() 之后内容先待在内存缓冲区，文件关闭或缓冲区满时才真正落盘：

```python
f = open("out.txt", "w", encoding="utf-8")
f.write("hello")
# 此刻用记事本打开 out.txt 可能什么都看不到
f.close()      # 关闭时才写入磁盘
```

程序跑着、文件却看不到内容，多半是缓冲没刷。想立即落盘，调用 flush()：

```python
f = open("out.txt", "w", encoding="utf-8")
f.write("hello")
f.flush()      # 强制把缓冲区内容写入磁盘
```

长时运行的日志进程依赖 flush()，否则程序跑着，日志文件一直是空的。数据安全敏感的写入（比如进度记录），用 flush() 加 os.fsync() 保证落盘。

## JSON

JSON 是通用的数据交换格式，跨语言、可读、简洁。Python 的 json 模块提供 dumps/dump/loads/load 两对函数：带 s 的处理字符串，不带 s 的处理文件。

Python 对象转 JSON 字符串用 dumps：

```python
import json

data = {"name": "小明", "score": 85, "tags": ["python", "基础"]}
text = json.dumps(data)
print(text)
print(type(text))
```

```text
{"name": "\u5c0f\u660e", "score": 85, "tags": ["python", "\u57fa\u7840"]}
<class 'str'>
```

中文被转成了 `\u` 转义序列，这是默认行为，为了兼容性。加 ensure_ascii=False 保留中文：

```python
text = json.dumps(data, ensure_ascii=False)
print(text)  # 输出： {"name": "小明", "score": 85, "tags": ["python", "基础"]}
```

indent 参数美化输出：

```python
text = json.dumps(data, ensure_ascii=False, indent=2)
print(text)
```

```text
{
  "name": "小明",
  "score": 85,
  "tags": [
    "python",
    "基础"
  ]
}
```

JSON 字符串转回 Python 对象用 loads：

```python
s = '{"name": "小明", "score": 85}'
data = json.loads(s)
print(data["name"])  # 输出： 小明
print(type(data))    # 输出： <class 'dict'>
```

dump 和 load 直接处理文件，完整往返：

```python
import json

info = {"name": "小明", "score": 85}
with open("info.json", "w", encoding="utf-8") as f:
    json.dump(info, f, ensure_ascii=False, indent=2)

with open("info.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)

print(loaded)  # 输出： {'name': '小明', 'score': 85}
```

JSON 类型和 Python 类型基本一一对应：JSON 对象对应 dict，数组对应 list，字符串对应 str，数字对应 int/float，true/false 对应 True/False，null 对应 None。日期时间没有对应类型，需要手动转成字符串再存。

## 异常处理

程序出错时抛出的对象叫**异常**。不处理的话，程序当场终止：

```python
num = int(input("请输入数字："))
print(num * 2)
```

```text
请输入数字：abc
ValueError: invalid literal for int() with base 10: 'abc'
```

输入 abc，int() 转不了，程序崩溃。用 try/except 接住异常，程序不崩：

```python
try:
    num = int(input("请输入数字："))
    print(num * 2)
except ValueError:
    print("输入的不是数字")
```

```text
请输入数字：abc
输入的不是数字
```

except 只接住指定的异常类型，其他异常照常抛出。多个 except 从上到下匹配，异常继承关系决定谁接住谁：

![异常继承关系示意](http://public.file.lvshuhuai.cn/images\exception-hierarchy.png)

ValueError 和 TypeError 都继承自 Exception，Exception 再往上继承 BaseException。匹配规则：except ValueError 接不住 TypeError；except Exception 能接住几乎所有常规异常。范围越大的 except 越靠后放：

```python
try:
    x = int("abc")
except ValueError:
    print("值不对")
except Exception as e:
    print(f"其他错误： {e}")
```

`as e` 拿到异常对象，f 字符串打印它的描述。

try 的完整结构是 try/except/else/finally，执行顺序看例子：

```python
def divide(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        print("除数不能为零")
    else:
        print(f"结果是 {result}")
    finally:
        print("清理结束")
```

```python
divide(10, 2)
```

```text
结果是 5.0
清理结束
```

```python
divide(10, 0)
```

```text
除数不能为零
清理结束
```

执行顺序：try 正常跑完、没抛异常时走 else；抛出异常时走 except；finally 不管什么情况都执行，放清理代码，比如关文件、释放资源。else 和 finally 都可以省略。

两种坏习惯。裸 except 吞掉一切：

```python
try:
    num = int(input())
except:
    pass
```

裸 except 连 KeyboardInterrupt(Ctrl+C 中断）都吞，程序可能没法用 Ctrl+C 停下。真正的 bug 也被一起吞掉，排查时看不到任何报错。至少要写具体类型：

```python
try:
    num = int(input())
except ValueError:
    pass
```

另一种坏习惯是捕获后不处理也不记录。except 里 pass 或空 return 都算「吞异常」，报错信息彻底丢失，出了问题无迹可寻。至少要打印或记日志。

异常也可以主动抛出。raise 重新抛出接住的异常，留给上层处理：

```python
try:
    num = int(input("数字："))
except ValueError:
    print("输入格式不对，转告上层")
    raise
```

接不住某个异常时，raise 原样抛出去。自定义异常继承 Exception：

```python
class AgeError(Exception):
    pass


def check_age(age):
    if age < 0:
        raise AgeError("年龄不能是负数")


try:
    check_age(-1)
except AgeError as e:
    print(f"参数有问题： {e}")
```

```text
参数有问题： 年龄不能是负数
```

常见异常速查：

| 异常 | 触发场景 | 例子 |
| --- | --- | --- |
| ValueError | 类型对，值不对 | `int("abc")` |
| TypeError | 类型不对 | `"a" + 1` |
| IndexError | 下标越界 | `[1, 2][5]` |
| KeyError | 字典键不存在 | `{"a": 1}["b"]` |
| ZeroDivisionError | 除数为零 | `1 / 0` |
| FileNotFoundError | 文件不存在 | `open("nofile.txt")` |
| AttributeError | 属性不存在 | `"abc".append(1)` |
| ImportError | 模块导入失败 | `import nosuch` |

调试建议：看 Traceback 从最后一行读起，最后一行写着异常类型和原因；往上找文件与行号，定位出错位置。报错信息读不懂就整行复制到搜索引擎，大概率有同款问题。

> 报错不是代码的敌人，是排查线索。Traceback 最后一行是结论，前面的文件与行号是路径。

## 练手题

在 PowerShell 里用 `python 文件名.py` 运行写好的答案。每题都能在前文找到对应写法。

1. 创建列表 [“苹果”， “香蕉”， “橘子”]，逐行写进 fruit.txt(UTF-8 编码），再读回来打印每一行，确认和写入一致。
2. 统计日志行数：造一个 5 行的 log.txt，用 for line in f 的方式统计总行数和包含 "error" 的行数。
3. 联系人 JSON：三个人的姓名和电话存成字典列表，json.dump 写进 contacts.json(ensure_ascii=False，indent=2)，再 json.load 读回来打印每个人的姓名。
4. 带异常处理的猜数字：random 生成 1 到 10 的随机数，input 读猜测，int 转换用 try/except 接 ValueError，提示输入的不是数字，猜对退出。
