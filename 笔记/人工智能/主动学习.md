# 主动学习

## 基本概念

主动学习（**Active Learning**）是一种机器学习策略，其核心思想是：**模型可以主动选择最有价值的数据来学习，以最小的代价获得最大性能提升**。

### 主动学习的基本动机

在很多实际应用中，**获取标注数据的成本很高**（比如医学图像、法律文本、人脸识别等），而**未标注的数据却很容易获取**。主动学习试图通过以下方式来提高学习效率：

- 不是随机选取样本去标注
- 而是**由模型自己挑选“最值得标注”的样本**

### 主动学习的基本流程

1. **初始训练集**：先用一小部分已标注的数据训练一个初始模型。
2. **选择策略（query strategy）**：模型从大量未标注的数据中选出“最不确定”或“最有代表性”的样本。
3. **人工标注**：把选出的样本交给专家标注。
4. **模型更新**：用新标注的数据更新模型。
5. **重复上述步骤**，直到达到期望的性能或资源耗尽。

### 常见的样本选择策略

| 策略名称                             | 描述                                                 |
| ------------------------------------ | ---------------------------------------------------- |
| 不确定性采样（Uncertainty Sampling） | 选择模型最不确定的样本（比如分类概率最接近 0.5 的）  |
| 熵采样（Entropy Sampling）           | 选取熵最大的样本（信息量最多）                       |
| 查询实例化（Query by Committee）     | 使用多个模型，选择模型意见分歧最大的样本             |
| 密度加权（Density Weighted）         | 综合样本的不确定性和其代表性（在特征空间中是否常见） |

### 应用场景：

- **医学诊断**（标注需要医生）
- **自然语言处理**（人工标注文本很费时）
- **图像识别**（尤其是细粒度图像）
- **推荐系统**（收集用户反馈很难）

### 举个简单例子：

假设你在做一个人脸情绪识别模型，但每张图片的情绪需要心理专家来标注，非常昂贵。你用主动学习：

- 首先用 100 张已标注的图像训练一个初始模型。
- 然后从几千张未标注的图像中，模型挑选它“最难判断”的10张。
- 你请专家只标注这10张图像，再用它们训练模型。
- 不断重复，模型准确率快速上升，而总共只用了几百张标注图。
