# 多实例学习

## MIL 简介

### 什么是多实例学习？

多实例学习是一种弱监督学习方法，其特点是：

- 训练数据不是单个样本，而是一个**样本包（bag）**；
- 每个 bag 包含若干个实例（instance），但：
    - **只给出 bag 的标签**；
    - **不提供实例的标签**。

### 为什么使用 MIL？

- 某些问题中，标注粒度只能到达 bag 级别（如医学图像、文本分类等）；
- 降低标注成本；
- 可用于处理不完全标注、不确定性等实际问题。

## 形式化定义

设训练集为：

$\mathcal{D} = \{(X_1, y_1), (X_2, y_2), ..., (X_n, y_n)\}$

其中：

- 每个 $X_i = \{x_{i1}, x_{i2}, ..., x_{im_i}\}$ 是一个 bag；
- xij∈Xx_{ij} \in \mathcal{X}xij∈X 是第 iii 个 bag 中的第 jjj 个实例；
- yi∈{0,1}y_i \in \{0, 1\}yi∈{0,1} 是 bag 的标签。

### 经典假设（标准 MIL 假设）：

- 如果 bag 为正（yi=1y_i = 1yi=1），则 **至少存在一个正实例**；
- 如果 bag 为负（yi=0y_i = 0yi=0），则 **所有实例都为负**。

## 三、MIL 与传统监督学习的区别

| 方面     | 传统监督学习     | 多实例学习                   |
| -------- | ---------------- | ---------------------------- |
| 输入样本 | 单个实例         | 一个实例集合（bag）          |
| 标签粒度 | 实例级           | bag 级                       |
| 假设     | 每个输入都有标签 | 只有集合有标签，实例标签未知 |
| 适用场景 | 标注完备         | 弱监督、部分标注             |

## 四、MIL 方法分类

### 1. 基于实例的方法（Instance-level）

- 假设存在一个实例分类器 f(x)f(x)f(x)，最终预测 bag 标签：
    - 例如：bag 的得分为 max⁡jf(xj)\max_j f(x_j)maxjf(xj)；
- 学习目标是推断出哪些实例是关键的（正实例）；
- 代表方法：
    - Diverse Density (DD)
    - EM-DD
    - MI-SVM（多实例支持向量机）

### 2. 基于 bag 的方法（Bag-level）

- 把整个 bag 看作一个整体，提取表示后用于分类；
- 特征抽取方式：
    - Pooling（mean, max, attention）
    - 聚类 + 统计
- 代表方法：
    - miGraph / miSVM
    - MIL pooling network (mean/max pooling)
    - Attention-based MIL（Ilse et al., 2018）

### 3. 深度学习中的 MIL（现代方法）

- 使用神经网络（如 CNN、transformer）提取实例特征；
- 结合 MIL pooling 层做 bag-level 分类；
- 支持端到端训练；
- 代表方法：
    - Attention MIL（2018 NeurIPS）
    - CLAM（用于病理图像分类）

## 六、应用领域

- 🧬 医学图像分析（病理图像、WSSS）
- 📄 文本分类（句子为实例，段落为 bag）
- 🐭 药物活性预测（一个化合物的多种构型）
- 📷 图像识别（图像切块作为实例）
- 🎯 异常检测（视频帧中异常点作为关键实例）

------

## 七、评价指标

- 和标准分类一样，通常使用 bag-level 精度、AUC；
- 在某些任务中，也关注实例级准确率（辅助指标）；
- MIL 特有的 challenge：如何正确识别关键实例。

------

## 八、常见挑战与研究进展

### 1. 多实例表示学习（representation learning）

- 如何有效表达 bag（聚合方式、结构信息等）

### 2. 注意力机制 & 可解释性

- 使用注意力机制发现关键实例；
- 可用于定位（例如在医学图像中指出病变区域）

### 3. 弱监督标签不一致性问题

- Bag 标签与实际实例标签偏差；
- 研究噪声鲁棒性、多标签 MIL 等方向。
