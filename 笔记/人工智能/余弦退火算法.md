# 余弦退火算法

## 介绍
余弦退火（Cosine Annealing）是一种常用的学习率调度（Learning Rate Schedule）方法，用来在训练过程中**平滑地降低学习率**。相比于阶梯下降（StepLR）这类“突然降一档”的策略，余弦退火让学习率按照**半个余弦曲线**从较大值逐渐下降到较小值，从而在训练前期更充分探索、训练后期更稳定收敛。

它广泛用于 CNN、Transformer、ViT 等模型，常与 SGD / AdamW 配合使用。

## 原理
设：
- 初始（最大学习率）：$\eta_{\max}$
- 最小学习率：$\eta_{\min}$
- 当前训练进度（步或 epoch）：$t$
- 总训练长度（步或 epoch）：$T$

余弦退火学习率公式为：
$$
\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max}-\eta_{\min})
\left(1 + \cos\left(\pi \frac{t}{T}\right)\right)
$$

### 直观解释
- 当 $t=0$：$\cos(0)=1$，所以 $\eta_0 \approx \eta_{\max}$
- 当 $t=T$：$\cos(\pi)=-1$，所以 $\eta_T = \eta_{\min}$
- 中间过程：学习率**平滑**下降，越到后期下降越慢（更利于精细收敛）

### 选择步还是 epoch

- **按 epoch**：适合每个 epoch 的 step 数相对稳定、训练流程简单
- **按 step**：更精确，适合梯度累积、动态长度 dataloader、或需要严格对齐总更新次数的情况  
> 实践中很多框架（如 HuggingFace）默认按 optimizer step 调度。

## 使用

### 典型参数建议
- $\eta_{\max}$：你的基础学习率（base lr）
- $\eta_{\min}$：常设为 0，或设为一个很小值（如 $1e{-6}$、$1e{-5}$）以避免学习率“归零”导致后期完全不更新
- $T$：总训练长度（epoch 数或总 step 数）

### PyTorch 示例（按 epoch 调度）
```python
import torch

optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer,
    T_max=100,      # 总 epoch 数
    eta_min=1e-6    # 最小 lr
)

for epoch in range(100):
    train_one_epoch(...)
    scheduler.step()
```

### PyTorch 示例（按 step 调度）
```python
import torch

optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
total_steps = 20000

scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer,
    T_max=total_steps,
    eta_min=1e-6
)

global_step = 0
for epoch in range(num_epochs):
    for batch in loader:
        loss = ...
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
        scheduler.step()
        global_step += 1
```

## 变体

### 余弦退火 + 重启
余弦退火 + 重启（Cosine Annealing with Warm Restarts, SGDR）会让学习率在训练过程中**周期性地回到较大值**，再按余弦曲线下降。这样可以：
- 在多个周期中反复“探索 → 收敛”
- 有机会跳出局部最优
- 常用于训练时间较长、或希望更强探索能力的任务

#### 简化形式
把训练划分为若干周期，第 $i$ 个周期长度为 $T_i$，周期内使用余弦下降；周期结束时重置到 $\eta_{\max}$。

#### PyTorch 示例
```python
import torch

optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
scheduler = torch.optim.lr_scheduler.CosineAnnealingWarmRestarts(
    optimizer,
    T_0=10,      # 第一个周期长度（epoch 或 step）
    T_mult=2,    # 后续周期长度倍增
    eta_min=1e-6
)

for epoch in range(100):
    train_one_epoch(...)
    scheduler.step()
```

> 注意：`scheduler.step()` 的调用频率要与你的 `T_0` 单位一致（按 epoch 就每个 epoch step；按 step 就每个 step step）。

### 余弦退火 + 预热
余弦退火 + 预热（Cosine with Warmup）是目前非常常见的组合：**先 warmup（学习率从很小线性升到 $\eta_{\max}$）**，然后再进行余弦下降。

这么做的原因是：
- 训练初期参数随机、梯度噪声大，直接用较大学习率可能不稳定（尤其是 Transformer / 大 batch / AdamW）
- warmup 能让训练更平稳、更不容易出现 loss 发散

#### 分段公式（常见实现）
设 warmup 长度为 $W$，总长度为 $T$：

- Warmup（$0 \le t < W$）线性上升：
$$
\eta_t = \eta_{start} + (\eta_{\max}-\eta_{start})\cdot \frac{t}{W}
$$

- Cosine（$W \le t \le T$）余弦下降：
$$
\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max}-\eta_{\min})
\left(1 + \cos\left(\pi \frac{t-W}{T-W}\right)\right)
$$

#### 参数经验
- `warmup_ratio`：常用 0.03 ~ 0.10（总 step 的 3%~10%）
- $\eta_{start}$：常取 0 或一个很小值
- $\eta_{\min}$：0 或很小值（如 1e-6）

#### HuggingFace 示例（最常见）
```python
from transformers import get_cosine_schedule_with_warmup

optimizer = ...
num_training_steps = total_steps
num_warmup_steps = int(0.05 * total_steps)

scheduler = get_cosine_schedule_with_warmup(
    optimizer,
    num_warmup_steps=num_warmup_steps,
    num_training_steps=num_training_steps
)

for step, batch in enumerate(loader):
    loss = ...
    loss.backward()
    optimizer.step()
    scheduler.step()
    optimizer.zero_grad()
```
