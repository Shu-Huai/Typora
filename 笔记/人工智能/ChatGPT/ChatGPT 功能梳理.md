# ChatGPT 功能梳理

这可能是全网最全的 ChatGPT 功能梳理  自 GPT-5 推出，ChatGPT 更新了许多功能，来看看你的订阅费用有哪些还没有用上

## GPT‑5

### 功能

#### 多模型系统

ChatGPT 中的 GPT-5 是所有登录用户的默认模型

GPT‑5 由一个统一系统提供支持，它根据任务难度自动在快速响应模型与深度推理模型之间切换

新系统减少了幻觉、增强了指令遵循能力，并在数学、编程、多模态理解和健康问答等方面表现明显优于上一代模型

#### 思考模式

当 GPT-5 使用其推理模式时，可以在它工作时看到一个精简的推理视图，并可以选择**跳过** 。点击**跳过**即可切换回 GPT-5 聊天模式，立即获得答案，而无需等待响应。

<img src="Z:\Public\images\1760162913980-71.png" alt="img" style="zoom: 33%;" />

也可以直接从模型选择器的顶部选择其他 GPT-5 选项：

- **Instant——即刻回答**
- **Thinking mini——快速思考**
- **Thinking——思考更充分，回答更优质**
- **Pro——研究级智能模型**

Pro 和 Business 等级的用户可以使用 GPT-5 Thinking Pro，它需要更长的思考时间，但能为复杂任务提供所需的准确性。

**GPT-5 Pro 不支持 Canvas 和图像生成功能**

#### 编程与写作能力提升

GPT‑5 在**复杂前端代码**生成与**调试大型仓库**方面表现出色

它还能生成**更具情感和结构性的写作**，并在**诗歌创作**中表现出丰富的意象

#### 视频分析（GPT‑5 新增）

GPT‑5 支持原生影片分析

用户可以上传短视频（≤512MB）让模型识别并回答相关问题

### 使用技巧

#### 选择模式

在对话框左上角通过“模型选择器”切换：

1. **GPT‑5 Thinking** 以处理**复杂分析**
2. 需要快速回答时选择 **Instant 模式**
3. 默认 Auto 模式适合大部分问题
4. **Pro** 用户可获得两个额外选项： **Light**（最快）和**Heavy** （更深层次的推理）。
5. 所有查询默认使用 **Auto** 模式，除非选择更改。一旦选择了不同的思考时间，偏好将被保存并用于未来的查询，直到再次切换。

可以根据当下需求进行选择：

- **Light / Standard** → 更快的答案，同时仍运用推理，平衡速度与智能。
- **Extended / Heavy** → 在风险较高或问题较难时，有更多时间进行更深入、更全面的回复。

此功能仅在 ChatGPT 网页版上可用。在网页版上选择的设置不会同步到移动端。

#### 旧模型

对于付费用户，GPT-4o 仍位于模型选择器中的**旧模型**下。

付费账户可以在 **ChatGPT 设置**中启用**显示其他模型** ，以添加 **Thinking mini 模式**以实现更快的推理，并显示其他旧选项：

- **Plus / 商业版：**o3、o4-mini、GPT-4.1
- **Pro：**o3、o4-mini、GPT-4.1、GPT-4.5

<img src="Z:\Public\images\1760162913980-73.png" alt="img" style="zoom:33%;" />

如果关闭**显示其他模型** ，使用这些模型的旧聊天将转而使用最接近的 GPT-5 版本打开。具体来说：

- 4o、4.1、4.5、4.1-mini、o4-mini 或 o4-mini-high 将在 **GPT-5** 中打开
- o3 将在 **GPT-5 Thinking** 中开启
- o3-Pro 将在 **GPT-5 Pro** 中开启（仅适用于 Pro 和和商业计划）

由于这些旧聊天现在运行在等效的 GPT-5 上，因此输出可能会有所不同。

#### 网页版对话分支功能

现在你可以在 ChatGPT 中创建对话分支，这让你更容易探索不同的方向，而不会丢失原始对话线索

将鼠标悬停在消息上，点击**更多操作** （⋯），然后选择**在新聊天中分支** ，即可从该点开始一个独立的对话。

## 记忆（Memory）

### 两种记忆来源

1. **保存的记忆（Saved memory）** 是用户明确要求模型记住的信息；
2. **聊天历史引用（Reference chat history）** 允许模型根据过去的对话自动提取有用信息

### 项目记忆

在创建项目时可以启用“项目专用记忆”，让 ChatGPT 仅参考该项目内的对话和文件；不会调用其他项目或全局记忆。

### 使用技巧

直接在对话中说明“记住我不吃肉”等，即可创建保存的记忆

在对话中通过“记住……”“忘记……”来更新或删除记忆

要查看已保存的记忆，可询问“你记得我什么？”

## ChatGPT Agent 与自主代理

### 功能

#### 统一代理系统

2025 年 7 月推出的“智能体模式”整合了此前的 Operator（视觉浏览器）和深入研究工具，赋予模型思考与行动能力

它可以在虚拟电脑上浏览网页、过滤信息、运行代码、使用终端，并结合 API 调用完成复杂任务

<img src="Z:\Public\images\1760162913980-77.png" alt="img" style="zoom: 67%;" />

#### 自动选择工具

智能体可根据任务需要，在文字浏览器、视觉浏览器、终端和 API 之间切换，并**借助 Gmail、GitHub 等连接器获取资料**

任务包括**总结日历与新闻**、**分析竞争对手**并**制作演示文稿**等

#### 日程化任务

支持将完成的任务设置为定期自动执行，例如每周生成指标报告

若任务需要重复执行，可将其设为定期任务（见“Tasks”）

## 自动化排程（Tasks）

### 功能

Tasks 允许用户让 ChatGPT 在特定时间或条件下自动运行提示，并在完成后通过推送或电子邮件通知用户

### 管理和编辑

1. 在设置→通知→管理任务可以查看、暂停或删除任务
2. 也可在对话中的三点菜单编辑名称、指令和时间

<img src="Z:\Public\images\1760162913980-78.png" alt="img" style="zoom:50%;" />

### 限制

**每个账户**最多同时有 **10 个激活的任务**

Tasks 目前**不支持语音聊天、文件上传和 GPTs** 等功能

## Canvas 编辑器

### 功能简介

Canvas 是新的协作界面，适用于需要编辑和修订的写作或编程任务

用户可以**直接编辑文本或代码**，并让 ChatGPT 提供**行内反馈**和建议

Canvas 支持**版本历史**和**撤销**

### 打开方式

当 ChatGPT 生成超过 10 行内容或检测到需要编辑的情况时会自动打开 Canvas

也可以在提示中加上“使用 Canvas”或通过工具栏命令 `/canvas` 打开空白 Canvas

### 编程快捷方式

提供“添加日志”、“添加注释”、“修复错误”、“代码移植（至 JavaScript/Java/Python 等）”、“代码审查”等功能，帮助调试和优化代码

## Record Mode（录制模式）

### 概述

Record 模式目前在 **macOS 桌面应用**提供，允许用户录制会议或语音便条并由 ChatGPT 实时转录和总结为 Canvas

### 使用方法

在聊天窗口下方点击 **“Record”** 按钮开始录音；暂停、继续或结束后选择发送即可上传并生成摘要

按下“X”可取消录制或删除音频

### 编辑与输出

录音结束后，ChatGPT 会在 Canvas 中提供结构化摘要，用户可进一步编辑或让 ChatGPT 把摘要转换为计划、电子邮件或代码

### 限制与隐私

每个录音最长 120 分钟，超过时会自动结束并生成摘要

音频仅用于转录后即删除，不用于模型训练（除非用户开启“改善模型”设置）

支持多说话人

非英语准确度仍在提升

## 连接器（Connectors）

### 功能

#### 将外部数据导入 ChatGPT

连接器允许 ChatGPT 安全地连接第三方应用（如 Google Drive、GitHub、Dropbox、SharePoint 等），在聊天中查询文件、抓取实时数据或做深入研究

<img src="Z:\Public\images\1760162913980-80.png" alt="img" style="zoom:67%;" />

#### 使用方式

打开 Settings → Connectors → 选择应用并授权登录

然后在聊天中点击 “Tools → Use connectors” 或 **“Deep research” 选择数据源**

#### 自动引用

通过 GPT‑5 ，ChatGPT 可以自动使用 Gmail、Google Calendar 和 Google Contacts 连接器

启用后无需每次选择

#### 类型

连接器分为

1. **Chat connectors** 用于快速检索文件或信息

    <img src="Z:\Public\images\1760162913981-81.png" alt="img" style="zoom:33%;" />

2. **Deep research connectors** 用于**跨多个来源进行深度分析并提供带引文的报告**

    <img src="Z:\Public\images\1760162913981-82.png" alt="img" style="zoom: 33%;" />

3. **Synced connectors** 提前同步和索引选定的文件，使回答更快并可脱机访问

4. **Custom connectors** 允许 Pro、Business、Enterprise 和 Edu 用户连接自定义应用；仅工作区管理员可添加

### 使用技巧

1. 在授权前查看连接器允许访问的数据范围，完成任务后可在设置中禁用或删除连接器。
2. Gmail 和 Google Calendar 等连接器启用后会在聊天自动引用，可在设置中关闭自动使用
3. 深度研究模式适用于需要引用文档来源的复杂报告，快速搜索任务可使用 Chat connectors

## Search 与购物结果

## 图像生成

### GPT‑4o 图像生成升级

#### 字符一致性与文本渲染

新模型可以在多张图片中保持角色的一致性，适合制作漫画和故事板

支持输出**透明背景 PNG**，可将照片风格转换为动画或插画风格

免费用户使用的是 4o‑mini，图片生成较慢且功能有限

Plus 用户可使用 GPT‑4o，支持更高质量图像、更多风格和更快生成

### 使用技巧

1. 在提示中清晰描述场景和人物，可通过**明确设定姿势、表情和服装**来**保持角色一致性**
2. 若需要多张连贯图片，可告诉 ChatGPT “**在之后的几张图中保持人物外貌一致**”
3. 为了让模型准确渲染文字，在提示中**要求“清晰打印”**或提供内容示例
4. 如果**需要中文文字，可指定字体和位置**
5. 如需透明背景，请在提示中注明“**透明背景**”或“**PNG 无背景**”。
6. 想将某张照片转换为卡通风格，可上传参考图片并要求“将此照片转为漫画风格”

#### 高级图像生成提示技巧

1. **明确具体是关键：** 描述越详细，结果越精准。避免使用模糊的词汇，例如，用“一只毛茸茸的、小型的棕色小狗”代替“一只狗”
2. **控制构图与风格：** 使用专业术语来指导AI的创作。例如，通过“特写”、“广角镜头”、“梵高风格”或“赛博朋克”等关键词，可以精确控制画面的视角和艺术风格
3. **迭代式优化：** 利用ChatGPT的对话能力，将初次生成的图像作为基础，通过追问的方式进行逐步优化。例如，可以对一张图片说：“把天空的颜色变得更暖一些”
4. **正面引导而非负面排除：** 与其告诉AI“不要做什么”，不如清晰地指示“要做什么”。这一通用的提示工程原则在图像生成中尤为有效

## Codex（编程助手）

### 概述

Codex 是一款 AI 编码代理，可帮助您更快地编写、审查和交付代码。您可以在本地工具中与它配对，或将工作委托给它在云端完成。可在终端或 IDE 中**导航仓库**、**编辑文件**、**运行测试并自动完成任务**

### 连接方式与使用模式

Codex **包含在 Plus/Pro/Business/Edu/Enterprise 计划**

Codex CLI 和 IDE 扩展

IDE 中用户**需登录并授权**后才能在 VSCode、Cursor 和 Windsurf 等 IDE 中使用

Codex 支持**本地配对**（在本地代码环境与 AI 共同编辑）和**云端委托**（在沙箱环境中生成代码，然后同步到本地）

### 使用提示

在 IDE 中调用 Codex CLI 或扩展，描述需要的功能（如“实现快速排序并写单元测试”），Codex 会在代码库中创建或修改文件

完成后应仔细审查、运行测试并根据需要调整

Codex Web 使用 **GPT-5-codex**，这是 GPT-5 的一个变体，专为代理式编码优化。

Codex CLI 和 IDE 扩展会自动选择 GPT-5-codex 作为默认模型，可以在应用中自定义此选择。

*注意：GPT-5-codex 目前无法通过 API 获取。*

### 各套餐的使用限制

Codex 的使用限制取决于套餐以及执行的任务。在此限制内可以发送的 Codex 消息数量因编码任务的大小和复杂性而异。

小型脚本或简单函数可能只消耗配额的一小部分，而大型代码库、多文件项目或需要 Codex 保持更多上下文的长时间会话每条消息将消耗更多。

#### Plus

- **本地任务：** 普通用户每 5 小时可发送 30-150 条消息，每周有上限。
- **云任务：** 限时大放送，额度超大。
- **最适合：** 希望每周进行几次专注编程的开发者。

#### 专业版

- **本地任务：** 普通用户每 5 小时可发送 300-1,500 条消息，并设有每周上限。
- **云任务：** 限时大放送，额度超大。
- **最适合：** 希望在多个项目中为整个工作日提供支持的开发者。

#### 商业

商业套餐包含与 Plus 套餐相同的按席位使用限制。采用灵活定价的商业套餐可以购买积分，以增加超出规定限制的本地任务访问权限。更多信息参阅 **ChatGPT 费率卡** 。

#### 企业版和教育版

对于采用灵活定价的企业版和教育版套餐，使用量将从工作区的共享额度池中扣除。更多信息参阅 **ChatGPT 价目表** 。

没有灵活定价的企业版和教育版套餐包含与 Plus 版相同的按席位使用限制。

#### 达到使用限制后

当达到使用上限时，将无法使用 Codex，直到使用窗口重置。

如果需要更多用量，可以使用 API 密钥运行额外的本地任务（用量根据**标准 API 费率**计费）。对于采用灵活定价的商业版、教育版和企业版套餐，还可以考虑购买额外的用户积分。

### 配置

## 其它

### 人员角色与语气更新

GPT‑5 默认的语气在 2025 年 8 月 15 日更新为更温暖、更亲切的风格

OpenAI 为 ChatGPT 和相关工具带来了大量更新：从新一代 GPT‑5 模型、智能代理、记忆、自动任务，到专用的 Canvas 与 Projects 协作空间，再到丰富的连接器、学习模式和语音体验。这些功能使 ChatGPT 不仅是聊天机器人，更是可执行复杂工作流程的智能助理。

为了充分利用这些功能，可以参考以下建议：

### 个性化设置

在设置中配置自定义指令、记忆和个性化人格，使 ChatGPT 在各个对话中更贴近你的风格和需求

### 善用智能代理与任务

针对需要多步骤操作的工作（如收集资料、生成报告或进行采购），启用智能体模式，让 ChatGPT 代为浏览网页、汇总信息并生成文件

使用 Tasks 安排定期提醒或每日/每周摘要

### 用 Canvas 迭代改进

在撰写长文或编写程序时，通过 Canvas 提示 ChatGPT 提供修改建议、调试代码，并使用版本历史回溯迭代

### 整理项目与资料

使用 Projects 将相关的聊天、文件和指令集中存放

启用项目专用记忆让讨论更聚焦

配合连接器可直接搜索和引用外部资料

### 利用 Study Mode 促进学习

在学习新知识时启用 Study Mode，让 ChatGPT 用提问方式引导思考、检查理解，并结合记忆提供个性化练习

### 尝试多模态

通过语音模式进行双向对话，使用 GPT‑4o 生成图片，提高创作效率

注意为图片提供详细的场景描述以获得更准确的结果

### 安全与隐私

在使用连接器或智能体模式时谨慎授权，定期检查浏览数据和记忆设置

对于含敏感信息的项目，启用项目专用记忆或使用临时聊天
